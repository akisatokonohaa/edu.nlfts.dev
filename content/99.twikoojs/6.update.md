Cara pembaruan berbeda untuk setiap metode deploy, silakan sesuaikan dengan metode Anda. Setelah pembaruan berhasil, jangan lupa untuk memperbarui nomor versi `x.x.x` pada alamat CDN Twikoo di bagian frontend agar sesuai dengan versi fungsi cloud, kemudian deploy situs Anda.

## Cara Pembaruan untuk Deploy Satu Klik Tencent Cloud

Login ke [Lingkungan - Aplikasi Saya](https://console.cloud.tencent.com/tcb/apps/index), masukkan:

* Alamat sumber: `https://github.com/twikoojs/twikoo/tree/main`
* Cabang deploy: `main`

Direktori aplikasi tidak perlu diisi, klik "OK", dan deploy akan selesai.

## Cara Pembaruan untuk Deploy Manual Tencent Cloud

Login ke [Lingkungan - Fungsi Cloud](https://console.cloud.tencent.com/tcb/scf/index), klik twikoo, klik kode fungsi, buka file `package.json`, ubah versi pada `"twikoo-func": "x.x.x"` ke versi terbaru, lalu klik "Simpan dan Instal Dependensi".

::alert{type="info"}
Jika fungsi cloud Anda adalah versi sebelum 1.0.0, karena versi 1.0.0 mengubah langkah deploy, silakan merujuk terlebih dahulu ke [Deploy Manual](#deploy-manual-tencent-cloud), mulai dari langkah ke-5, buat ulang fungsi cloud, lalu ikuti langkah ini untuk memperbarui.

Jika setelah upgrade muncul error tidak dapat membaca daftar komentar, di halaman edit fungsi, hapus direktori `node_modules` (penghapusan membutuhkan sekitar setengah menit, harap tunggu hingga selesai), lalu klik simpan dan instal dependensi. Jika masih tidak teratasi, hapus dan buat ulang fungsi cloud Twikoo.
::

## Cara Pembaruan untuk Deploy Baris Perintah Tencent Cloud

Masuk ke direktori sumber Twikoo, jalankan perintah berikut untuk memperbarui fungsi cloud yang ada:

``` sh
yarn deploy -e id-lingkungan-anda
```

## Cara Pembaruan untuk Deploy Vercel

1. Masuk ke [Dasbor Vercel](https://vercel.com/dashboard) - twikoo - Settings - Git.
2. Klik alamat repositori di bawah Connected Git Repository.
3. Buka package.json, klik Edit.
4. Ubah `latest` pada `"twikoo-vercel": "latest"` menjadi nomor versi terbaru. Klik Commit changes.
5. Deploy akan berjalan otomatis, Anda dapat kembali ke [Dasbor Vercel](https://vercel.com/dashboard) untuk melihat status deploy.

## Cara Pembaruan untuk Deploy Railway dan Zeabur

1. Login ke GitHub, temukan repositori bernama twikoo-zeabur yang di-fork ke akun Anda saat deploy.
2. Buka package.json, klik Edit.
3. Ubah `latest` pada `"tkserver": "latest"` menjadi nomor versi terbaru. Klik Commit changes.
4. Deploy akan berjalan otomatis.

## Cara Pembaruan untuk Deploy Netlify

1. Login ke GitHub, temukan repositori bernama twikoo-netlify yang di-fork ke akun Anda saat deploy.
2. Edit package.json, karena `twikoo-netlify` menggunakan kembali implementasi `twikoo-vercel`, perbarui nomor versi keduanya secara bersamaan (ubah `new version` di bawah dengan versi terbaru):

```json
{
  "dependencies": {
    "twikoo-netlify": "new version",
    "twikoo-vercel": "new version"
  }
}
```

3. Klik Commit changes.
4. Deploy akan berjalan otomatis.

## Cara Pembaruan untuk Deploy Hugging Face

1. Login ke Hugging Face, temukan Space yang di-deploy, klik Settings di bagian atas, gulir ke bawah dan klik Factory rebuild.

## Cara Pembaruan untuk Deploy Privat

1. Hentikan versi lama: `kill $(ps -ef | grep tkserver | grep -v 'grep' | awk '{print $2}')`
2. Ambil versi terbaru: `npm i -g tkserver@latest`
3. Jalankan versi terbaru: `nohup tkserver >> tkserver.log 2>&1 &`

## Cara Pembaruan untuk Deploy Privat (Docker)

1. Ambil versi terbaru: `docker pull imaegoo/twikoo`
2. Hentikan kontainer versi lama: `docker stop twikoo`
3. Hapus kontainer versi lama: `docker rm twikoo`
4. [Jalankan kontainer versi baru](#deploy-privat-docker)

## Pembaruan Otomatis

Mengingat masalah ketersediaan dan keamanan, Twikoo tidak menerapkan pembaruan otomatis, dan tidak ada rencana untuk menerapkannya. Jika Anda ingin menerapkan pembaruan otomatis, Anda dapat merujuk pada implementasi [twikoo-update](https://github.com/MHuiG/twikoo-update) oleh MHuiG yang berbasis pada GitHub Actions.
