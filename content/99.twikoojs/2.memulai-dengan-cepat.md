Twikoo terdiri dari dua bagian: fungsi cloud dan frontend. Untuk mengintegrasikan Twikoo ke situs web Anda, Anda perlu menyebarkan kedua bagian tersebut, dan pastikan versi keduanya selaras.

* [Deploy Fungsi Cloud](/backend) tersedia dalam berbagai cara, pilihlah platform部署 yang sesuai dengan kebutuhan Anda.
* [Deploy Frontend](/frontend) memiliki 2 cara: jika tema situs web Anda mendukung Twikoo, Anda hanya perlu menentukan Twikoo di file konfigurasi jika tema tidak mendukung Twikoo, Anda perlu mengubah kode sumber dengan menambahkan file JS Twikoo secara manual dan melakukan inisialisasi.
* Jika Anda telah menyebarkan Twikoo versi lama, silakan lihat [Pembaruan Versi](/update) untuk meningkatkan versi fungsi cloud dan frontend.
