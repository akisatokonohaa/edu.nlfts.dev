MongoDB Atlas adalah layanan hosting database MongoDB yang disediakan oleh MongoDB Inc. Akun gratis dapat menggunakan database sebesar 500 MiB secara permanen, yang cukup untuk menyimpan komentar Twikoo.

1. Daftar akun [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register)
2. Buat database MongoDB gratis, pilih wilayah pusat data yang dekat secara geografis dengan backend Twikoo (Vercel / Netlify / AWS Lambda / VPS) untuk mendapatkan latensi koneksi database yang lebih rendah. Jika Anda tidak yakin di wilayah mana backend Anda berada, Anda juga dapat memilih `AWS / Oregon (us-west-2)`, karena pusat data ini memiliki infrastruktur yang matang, tingkat kegagalan rendah, dan menggunakan energi bersih dari negara bagian Oregon, sehingga lebih ramah lingkungan.
3. Pada halaman Database Access, klik **Add New Database User** untuk membuat pengguna database. Pilih **Password** sebagai Authentication Method. Di bagian Password Authentication, atur nama pengguna dan kata sandi database. Disarankan untuk mengklik **Auto Generate** agar menghasilkan kata sandi kuat tanpa karakter khusus secara otomatis, dan simpan dengan baik. Klik **Add Built In Role** di bawah Database User Privileges, pilih **Atlas Admin** pada Select Role, lalu klik **Add User**.
   
   ![](./static/mongodb-1.png)

4. Pada halaman Network Access, klik **Add IP Address** untuk menambahkan daftar putih jaringan. Karena alamat keluar Vercel / Netlify / Lambda tidak tetap, maka pada Access List Entry masukkan `0.0.0.0/0` (mengizinkan koneksi dari semua alamat IP). Jika Twikoo di-deploy di server sendiri, Anda dapat mengisi alamat IP tetap di sini. Klik **Confirm** untuk menyimpan.
   
   ![](./static/mongodb-2.png)

5. Pada halaman Database, klik **Connect**, pilih metode koneksi **Drivers**, dan catat string koneksi database. Ganti `<username>:<password>` dalam string koneksi dengan `nama pengguna:kata sandi` database yang baru saja dibuat.
   
   ![](./static/mongodb-3.png)

6. (Opsional) Secara default, string koneksi tidak menentukan nama database. Twikoo akan terhubung ke database default bernama `test`. Jika Anda perlu menjalankan bisnis lain atau menggunakan beberapa instance Twikoo dalam MongoDB yang sama, disarankan untuk menambahkan nama database dan mengkonfigurasi ACL yang sesuai.

String koneksi berisi semua informasi untuk terhubung ke database MongoDB. Jika bocor, komentar dapat ditambahkan, diubah, atau dihapus oleh siapa saja, dan juga dapat mengakibatkan token SMTP, gambar, dan informasi lainnya terekspos. Simpan string ini dengan aman, karena nanti akan dimasukkan ke dalam platform deploy Twikoo.
