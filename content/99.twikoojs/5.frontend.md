### Pada tema [Hexo NexT](https://github.com/next-theme/hexo-theme-next)

**Belum mendukung NexT versi di bawah 8**, harap upgrade ke NexT 8 terlebih dahulu. Kemudian di direktori root proyek Hexo, jalankan:

``` sh
# Untuk NexT versi >= 8.0.0 && < 8.4.0
npm install hexo-next-twikoo@1.0.0
# Untuk NexT versi >= 8.4.0
npm install hexo-next-twikoo@1.0.3
```

Kemudian tambahkan konfigurasi berikut:

``` yml
twikoo:
  enable: true
  visitor: true
  envId: xxxxxxxxxxxxxxx # Lingkungan Tencent Cloud isi envId; Lingkungan Vercel isi alamat (https://xxx.vercel.app)
  # region: ap-guangzhou # Wilayah lingkungan, default ap-shanghai, untuk Tencent Cloud isi ap-shanghai atau ap-guangzhou; untuk Vercel tidak diisi
```

## Pengenalan melalui CDN

::alert{type="info"}
Jika tema blog yang Anda gunakan tidak mendukung Twikoo, dan Anda tidak tahu cara mengenalkan Twikoo, Anda dapat mengajukan permintaan adaptasi kepada pengembang tema blog.
::

``` html
<div id="tcomment"></div>
<script src="https://cdn.jsdelivr.net/npm/twikoo@1.7.15/dist/twikoo.min.js"></script>
<script>
twikoo.init({
  envId: 'ID lingkungan Anda', // Lingkungan Tencent Cloud isi envId; Lingkungan Vercel isi alamat (https://xxx.vercel.app)
  el: '#tcomment', // Elemen wadah
  // region: 'ap-guangzhou', // Wilayah lingkungan, default ap-shanghai, untuk Tencent Cloud isi ap-shanghai atau ap-guangzhou; untuk Vercel tidak diisi
  // path: location.pathname, // Jalur js kustom untuk membedakan artikel yang berbeda, jika jalur artikel Anda bukan location.pathname, Anda perlu mengirimkan parameter ini
  // lang: 'zh-CN', // Untuk mengatur bahasa area komentar secara manual, daftar bahasa yang didukung https://github.com/twikoojs/twikoo/blob/main/src/client/utils/i18n/index.js
})
</script>
```

### Perbedaan antar versi

* `twikoo.all.min.js`: Versi lengkap yang mencakup Tencent Cloud Base (tcb). Jika Anda menggunakan deploy Tencent Cloud Base, pilih versi ini.
* `twikoo.min.js`: Versi ringan tanpa Tencent Cloud Base (tcb), ukuran lebih kecil, cocok untuk semua pengguna yang tidak menggunakan deploy Tencent Cloud Base.
* `twikoo.nocss.js`: Versi lengkap tanpa gaya bawaan, perlu menyertakan `twikoo.css` secara terpisah agar tampilan normal, cocok untuk pengguna yang ingin mengubah tampilan area komentar.

### Mengganti Mirror CDN

Jika kecepatan muat CDN default lambat, Anda dapat mengganti dengan mirror CDN lain. Berikut adalah CDN publik yang tersedia, beberapa di antaranya mungkin memerlukan waktu beberapa hari untuk menyinkronkan versi terbaru:

#### Direkomendasikan untuk digunakan di China

* `https://registry.npmmirror.com/twikoo/1.7.15/files/dist/twikoo.min.js`
* `https://s4.zstatic.net/npm/twikoo@1.7.15/dist/twikoo.min.js`

#### Direkomendasikan untuk digunakan secara global

* `https://cdn.jsdelivr.net/npm/twikoo@1.7.15/dist/twikoo.min.js`

#### Opsi cadangan

* `https://s4.zstatic.net/ajax/libs/twikoo/1.6.41/twikoo.min.js`
* `https://lib.baomitu.com/twikoo/1.6.39/twikoo.min.js`

::alert{type="warning"}
Pengguna yang menggunakan CDN untuk mengenalkan Twikoo disarankan untuk mengunci versi pada tautan, agar terhindar dari dampak pembaruan yang tidak kompatibel di masa mendatang.
::

::alert{type="warning"}
Pengguna yang menggunakan CDN untuk mengenalkan Twikoo disarankan untuk menambahkan [SRI](https://developer.mozilla.org/id/docs/Web/Security/Subresource_Integrity) pada kode untuk memastikan integritas, contoh:
```html
<script
  src="https://cdn.jsdelivr.net/npm/twikoo@1.6.36/dist/twikoo.all.min.js"
  integrity="sha384-4KfOjEinLSkv1i1J8TzlkC/RTnuiLoR1OLerVgjEKoH5djYtbf7mzEFsz9p3nfuA"
  crossorigin="anonymous"></script>
```
Nilai `integrity` dapat dicari di [SRI Hash Generator](https://www.srihash.org/).
::

## Mengaktifkan Panel Admin (Lingkungan Tencent Cloud)

1. Masuk ke [Lingkungan - Otorisasi Login](https://console.cloud.tencent.com/tcb/env/login), klik "Unduh Kunci Privat" di sebelah kanan "Login Kustom", unduh file kunci privat.
2. Buka file kunci privat dengan editor teks, salin seluruh isinya.
3. Klik ikon "Roda Gigi Kecil" di jendela komentar, tempelkan isi file kunci privat, dan atur kata sandi admin.

Setelah mengonfigurasi kunci privat login, tidak perlu menyimpan file kunci privat. Jangan unduh kunci privat login lagi, karena dapat menyebabkan kunci privat login yang telah dikonfigurasi sebelumnya menjadi tidak berlaku.

## Mengaktifkan Panel Admin (Lingkungan Non-Tencent Cloud)

Klik ikon "Roda Gigi Kecil" di jendela komentar, lalu atur kata sandi admin.
