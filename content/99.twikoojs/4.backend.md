## Deploy Satu Klik Tencent Cloud

1. Klik tombol di bawah untuk deploy Twikoo ke cloud development dengan satu klik<br>
[![Deploy ke Cloud Development](https://main.qcloudimg.com/raw/67f5a389f1ac6f3b4d04c7256438e44f.svg)](https://console.cloud.tencent.com/tcb/env/index?action=CreateAndDeployCloudBaseProject&appUrl=https%3A%2F%2Fgithub.com%2Fimaegoo%2Ftwikoo&branch=main)
2. Masuk ke [Lingkungan - Otorisasi Login](https://console.cloud.tencent.com/tcb/env/login), aktifkan "Login Anonim"
3. Masuk ke [Lingkungan - Konfigurasi Keamanan](https://console.cloud.tencent.com/tcb/env/safety), tambahkan domain situs web ke "Domain Aman WEB"

## Deploy Manual Tencent Cloud

Jika Anda berencana untuk deploy ke lingkungan cloud development yang sudah ada, silakan mulai dari langkah ke-3.

1. Masuk ke halaman aktivitas [CloudBase Tencent Cloud](https://curl.qcloud.com/KnnJtUom), gulir ke bagian "Promosi Khusus Pengguna Baru", pilih paket yang sesuai, klik "Beli Sekarang", dan ikuti petunjuk untuk membuat lingkungan.

::alert{type="info"}
  # Tip
  * Disarankan untuk membuat lingkungan di Shanghai. Jika memilih lingkungan di Guangzhou, Anda perlu menambahkan parameter `region: "ap-guangzhou"` saat `twikoo.init()`.
  * Nama lingkungan diisi bebas.
  * Disarankan memilih metode penagihan `Paket Tahunan/Bulanan`, versi paket `Dasar 1`, tidak akan dikenakan biaya jika melebihi kuota gratis.
  * Jika diminta memilih "Template Aplikasi", pilih "Template Kosong".
::

2. Masuk ke [Konsol Cloud Development](https://console.cloud.tencent.com/tcb/)<br>
3. Masuk ke [Lingkungan - Otorisasi Login](https://console.cloud.tencent.com/tcb/env/login), aktifkan "Login Anonim"
4. Masuk ke [Lingkungan - Konfigurasi Keamanan](https://console.cloud.tencent.com/tcb/env/safety), tambahkan domain situs web ke "Domain Aman WEB"
5. Masuk ke [Lingkungan - Fungsi Cloud](https://console.cloud.tencent.com/tcb/scf/index), klik "Buat Fungsi Cloud Baru"
6. Nama fungsi isi: `twikoo`, metode pembuatan pilih: `Fungsi Kosong`, lingkungan runtime pilih: `Nodejs 16.13`, memori fungsi pilih: `128MB`, klik "Selanjutnya"
7. Kosongkan kode contoh di kotak input, salin kode berikut, tempel ke kotak input "Kode Fungsi", klik "OK"
``` js
exports.main = require('twikoo-func').main
```
8. Setelah pembuatan selesai, klik "twikoo" untuk masuk ke halaman detail fungsi cloud, masuk ke tab "Kode Fungsi", klik "File - Buat File Baru", masukkan `package.json`, tekan Enter.
9. Salin kode berikut, tempel ke kotak kode, klik "Simpan dan Instal Dependensi"
``` json
{ "dependencies": { "twikoo-func": "1.7.15" } }
```

## Deploy Baris Perintah Tencent Cloud

::alert{type="warning"}
 # Perhatian
* Pastikan Anda telah menginstal [Node.js](https://nodejs.org/en/download/)
* Ganti "id lingkungan Anda" dalam perintah dan kode dengan id lingkungan Anda sendiri.
* Langkah ke-7 akan membuka browser untuk meminta otorisasi, perlu dilakukan di sistem dengan antarmuka grafis.
* Jangan lakukan di Termux. Meskipun deploy dapat berhasil, saat digunakan akan muncul error `[FUNCTIONS_EXECUTE_FAIL] Error: EACCES: permission denied, open '/var/user/index.js'`
::

Jika Anda berencana untuk deploy ke lingkungan cloud development yang sudah ada, silakan mulai dari langkah ke-3.

1. Masuk ke halaman aktivitas [CloudBase Tencent Cloud](https://curl.qcloud.com/KnnJtUom), gulir ke bagian "Promosi Khusus Pengguna Baru", pilih paket yang sesuai (biasanya paket 0 yuan sudah cukup), klik "Beli Sekarang", dan ikuti petunjuk untuk membuat lingkungan.
2. Masuk ke [Konsol Cloud Development](https://console.cloud.tencent.com/tcb/)<br>
3. Masuk ke [Lingkungan - Otorisasi Login](https://console.cloud.tencent.com/tcb/env/login), aktifkan "Login Anonim"
4. Masuk ke [Lingkungan - Konfigurasi Keamanan](https://console.cloud.tencent.com/tcb/env/safety), tambahkan domain situs web ke "Domain Aman WEB"
5. Clone repositori ini
``` sh
git clone https://github.com/twikoojs/twikoo.git # atau git clone https://e.coding.net/imaegoo/twikoo/twikoo.git
cd twikoo
```
> Jika Anda tidak menginstal Git, Anda juga dapat mengunduh Source code terbaru dari halaman [Release](https://github.com/twikoojs/twikoo/releases)<br>
> Jika akses ke Github lambat di wilayah Anda, Anda dapat mencoba alamat repositori lain: [https://imaegoo.coding.net/public/twikoo/twikoo/git](https://imaegoo.coding.net/public/twikoo/twikoo/git)
6. Instal dependensi
``` sh
npm install -g yarn # jika sudah menginstal yarn, lewati langkah ini
yarn install
```
7. Otorisasi lingkungan cloud development (perintah ini akan membuka browser untuk meminta otorisasi, perlu dilakukan di sistem dengan antarmuka grafis)
``` sh
yarn run login
```
8. Deploy otomatis
``` sh
yarn deploy -e id-lingkungan-anda
```

## Deploy Vercel

::alert{type="warning"}
Lingkungan deploy Vercel harus digunakan dengan twikoo.js versi 1.4.0 ke atas.

Domain default `*.vercel.app` memiliki kecepatan akses lambat bahkan tidak dapat diakses di China daratan, mengikat domain sendiri dapat meningkatkan kecepatan akses.
::

[Lihat tutorial video](https://www.bilibili.com/video/BV1Fh411e7ZH)

1. Daftar akun [MongoDB Atlas](./mongodb-atlas.md), dapatkan string koneksi MongoDB.
2. Daftar akun [Vercel](https://vercel.com/signup).
3. Klik tombol di bawah untuk deploy Twikoo ke Vercel dengan satu klik.<br>

[![Deploy](https://vercel.com/button)](https://vercel.com/import/project?template=https://github.com/twikoojs/twikoo/tree/main/src/server/vercel-min)

4. Masuk ke Settings - Environment Variables, tambahkan variabel lingkungan `MONGODB_URI`, nilainya adalah string koneksi database yang dicatat sebelumnya.
5. Masuk ke Settings - Deployment Protection, atur Vercel Authentication menjadi Disabled, lalu Save.

![](./static/vercel-1.png)

6. Masuk ke Deployments, lalu di belakang item mana pun klik More (tiga titik), lalu klik Redeploy, dan terakhir klik Redeploy di bawah.
7. Masuk ke Overview, klik tautan di bawah Domains, jika konfigurasi lingkungan benar, akan muncul pesan "Twikoo cloud function runs normally".
8. Vercel Domains (termasuk awalan `https://`, misalnya `https://xxx.vercel.app`) adalah id lingkungan Anda.

## Deploy Railway

::alert{type="warning"}
Lingkungan deploy Railway harus digunakan dengan twikoo.js versi 1.4.0 ke atas.

Pastikan untuk membuat MongoDB, meskipun tanpa MongoDB tetap bisa digunakan, tetapi data akan hilang setelah deploy ulang!
::

1. Daftar dan login di [Railway](https://railway.app/dashboard), klik New Project - Provision MongoDB, nama bebas.
2. Buka [twikoojs/twikoo-zeabur](https://github.com/twikoojs/twikoo-zeabur) klik fork untuk memfork repositori ke akun Anda.
3. Kembali ke Railway, klik New - GitHub Repo - Configure GitHub App - otorisasi GitHub - pilih repositori yang baru di-fork, tunggu hingga deploy selesai.
4. Buka kartu lingkungan - Variables - New Variable, di kiri masukkan `PORT` dan di kanan masukkan `8080`, lalu Add.
5. Demikian pula, tambahkan variabel lingkungan MongoDB - New Variable - Add Reference - MONGO* - Add, ulangi langkah untuk menambahkan variabel `MONGOHOST`, `MONGOPASSWORD`, `MONGOPORT`, `MONGOUSER`, dan `MONGO_URL`.
6. Buka kartu lingkungan - Settings - Environment - Domains, ikat domain (misalnya `mytwikoo.up.railway.app`).
7. Di file konfigurasi blog, atur envId menjadi `https://` ditambah domain (misalnya `https://mytwikoo.up.railway.app`).

![](./static/hugging-5.png)

9. Klik ikon menu (tiga titik) di sebelah kanan tombol Settings di pojok kanan atas - Embed this Space, konten di bawah Direct URL (misalnya `https://xxx-xxx.hf.space`) adalah id lingkungan Anda.

## Deploy AWS Lambda

1. Daftar akun AWS dan konfigurasikan Terraform CLI.
2. Jika perlu menggunakan database MongoDB terkelola, dapat mendaftar akun [MongoDB Atlas](./mongodb-atlas.md).
3. Lihat kode Terraform di direktori `src/server/aws-lambda/terraform` untuk membuat sumber daya AWS.
4. Setelah deploy selesai, Terraform akan mencetak `lambda_function_url` di layar, Anda juga dapat menggunakan `terraform output` untuk mendapatkan URL ini, misalnya:

```
$ terraform output
lambda_function_url = "https://axtoiiithbcexamplegq7ozalu0cnkii.lambda-url.us-west-2.on.aws/"
```

URL tersebut adalah id lingkungan Anda, catat URL ini untuk konfigurasi frontend.

## Deploy Privat

::alert{type="warning"}
Lingkungan deploy privat harus digunakan dengan twikoo.js versi 1.6.0 atau di atasnya.

Deploy privat tidak memiliki persyaratan khusus untuk sistem server, semua sistem umum seperti Windows, Ubuntu, CentOS, macOS didukung.

Deploy privat melibatkan operasi terminal, pengurusan sertifikat, konfigurasi reverse proxy atau load balancing, dan operasi tingkat lanjut lainnya. Jika kurang memahami hal ini, disarankan untuk memilih metode deploy lain terlebih dahulu.
::

1. Di server, unduh dan instal [Node.js](https://nodejs.org/id/).
2. Instal Twikoo server: `npm i -g tkserver`.
3. Konfigurasikan variabel lingkungan sesuai kebutuhan, semua variabel lingkungan bersifat opsional.

| Nama | Deskripsi | Nilai Default |
| ---- | ---- | ---- |
| `MONGODB_URI` | String koneksi database MongoDB, jika tidak diatur maka menggunakan lokijs | `null` |
| `MONGO_URL` | String koneksi database MongoDB, jika tidak diatur maka menggunakan lokijs | `null` |
| `TWIKOO_DATA` | Jalur penyimpanan database lokijs | `./data` |
| `TWIKOO_HOST` | Nama host atau alamat IP yang didengarkan secara kustom (misalnya 0.0.0.0 atau 127.0.0.1), jika diatur maka akan mengabaikan TWIKOO_LOCALHOST_ONLY, nilai default null tetapi perilaku sebenarnya akan kembali ke `::` | `null` |
| `TWIKOO_PORT` | Nomor port | `8080` |
| `TWIKOO_THROTTLE` | Pembatasan permintaan IP, ketika permintaan dari IP yang sama melebihi ambang batas dalam waktu singkat, akan mengembalikan error untuk IP tersebut | `250` |
| `TWIKOO_LOCALHOST_ONLY` | Jika `true`, hanya mendengarkan permintaan lokal, sehingga setelah proxy balik oleh server seperti nginx, port asli tidak terekspos | `null` |
| `TWIKOO_LOG_LEVEL` | Tingkat log, mendukung `verbose` / `info` / `warn` / `error` | `info` |
| `TWIKOO_IP_HEADERS` | Digunakan dalam situasi khusus, misalnya jika menggunakan `CloudFlare CDN`, ia akan menulis IP permintaan ke bidang `cf-connecting-ip` di header permintaan. Untuk mendapatkan IP permintaan dengan benar, Anda dapat menulis `["headers.cf-connecting-ip"]` | `[]` |

4. Jalankan Twikoo server: `tkserver`.
5. Akses `http://IP-server:8080` untuk menguji apakah layanan berhasil berjalan.
6. Konfigurasikan proxy depan untuk mengaktifkan akses HTTPS (dapat menggunakan Nginx, load balancer, atau Cloudflare, dll.).
7. Di file konfigurasi blog, atur envId menjadi `https://` ditambah domain (misalnya `https://twikoo.yourdomain.com`).

::alert{type="info"}
1. Di server Linux, Anda dapat menggunakan perintah `nohup tkserver >> tkserver.log 2>&1 &` untuk menjalankan di latar belakang.
2. Data default berada di direktori data, harap rutin mencadangkan data.
3. Port default adalah 8080, untuk menggunakan port kustom, jalankan dengan `TWIKOO_PORT=1234 tkserver`.
4. Konfigurasikan layanan systemctl dengan `TWIKOO_PORT=1234 tkserver` untuk memulai otomatis saat boot.
::

## Deploy Privat (Docker)

::alert{type="warning"}
Lingkungan deploy privat harus digunakan dengan twikoo.js versi 1.6.0 atau di atasnya.

Deploy privat melibatkan operasi terminal, pengurusan sertifikat, konfigurasi reverse proxy atau load balancing, dan operasi tingkat lanjut lainnya. Jika kurang memahami hal ini, disarankan untuk memilih metode deploy lain terlebih dahulu.
::

### Docker

```sh
docker run --name twikoo -e TWIKOO_THROTTLE=1000 -p 8080:8080 -v ${PWD}/data:/app/data -d imaegoo/twikoo
```

### Docker Compose

```yml
version: '3'
services:
  twikoo:
    image: imaegoo/twikoo
    container_name: twikoo
    restart: unless-stopped
    ports:
      - 8080:8080
    environment:
      TWIKOO_THROTTLE: 1000
    volumes:
      - ./data:/app/data
```
