## 1. Cara Instal Git di Windows

Cara paling mudah dan populer di Windows adalah menggunakan penginstal resmi dari situs Git.

::steps
 ### Unduh Penginstal
  Kunjungi situs resmi [git-scm.com](https://git-scm.com/). Situs biasanya akan mendeteksi sistem operasi Anda secara otomatis dan menyediakan tombol unduh untuk Windows.

  ### Jalankan Berkas .exe
  Buka file yang sudah diunduh (misalnya `Git-2.xx.x-64-bit.exe`).

 ### Ikuti Proses Instalasi (Next hingga Finish):
* Anda bisa langsung mengeklik **Next** pada setiap pengaturan bawaan (*default*), karena pengaturan tersebut sudah disesuaikan untuk sebagian besar pengguna.
* *Catatan:* Pada bagian pilihan editor atau penamaan *branch* utama (biasanya disarankan `main`), Anda cukup biarkan pada opsi *default*.

  ### Verifikasi Instalasi:
   Buka aplikasi **Command Prompt** atau **PowerShell**, lalu ketik perintah berikut:
  ```bash
  git --version
  ```
::


Jika muncul versi Git (misalnya `git version 2.xx.x`), maka Git sudah berhasil terinstal.

## 2. Cara Instal Git di macOS

Ada beberapa cara untuk menginstal Git di macOS, yang paling mudah adalah menggunakan terminal bawaan atau *package manager*.

### Cara A: Menggunakan Xcode Command Line Tools (Paling Mudah)

1. Buka aplikasi **Terminal** (tekan `Cmd + Spasi`, ketik `Terminal`, lalu *Enter*).
2. Ketik perintah berikut:
```bash
xcode-select --install

```


3. Akan muncul jendela *pop-up* yang meminta konfirmasi. Klik **Install** dan tunggu hingga proses unduh serta instalasi selesai.

### Cara B: Menggunakan Homebrew (Bagi Pengguna *Homebrew*)

Jika Anda sudah memasang manajer paket Homebrew di Mac Anda, jalankan perintah ini di Terminal:

```bash
brew install git

```

**Verifikasi Instalasi:**
Ketik perintah ini di Terminal untuk memastikan:

```bash
git --version

```

---

## 3. Cara Instal Git di Linux

Perintah instalasi di Linux bergantung pada *distro* yang Anda gunakan.

### A. Ubuntu / Debian / Mint

Buka Terminal dan jalankan perintah:

```bash
sudo apt update
sudo apt install git

```

### B. Fedora / RHEL / CentOS

Buka Terminal dan jalankan perintah:

```bash
sudo dnf install git

```

*(Atau gunakan `sudo yum install git` untuk versi Fedora/CentOS yang lebih lama).*

**Verifikasi Instalasi:**
Ketik perintah ini di Terminal:

```bash
git --version

```

---

## 4. Konfigurasi Awal Setelah Instalasi

Setelah Git berhasil terinstal di komputer Anda, langkah wajib pertama adalah mengenalkan identitas Anda (nama dan email). Identitas ini akan tercatat setiap kali Anda melakukan penyimpanan kode (*commit*).

Buka Terminal (atau Git Bash di Windows) dan jalankan dua perintah berikut dengan data Anda sendiri:

```bash
git config --global user.name "Nama Lengkap Anda"
git config --global user.email "emailanda@domain.com"

```

Untuk mengecek apakah konfigurasi sudah benar, Anda bisa menjalankan perintah:

```bash
git config --list

```

# Membuat Akun Github

## Langkah 1: Membuat Akun di Situs GitHub

1. **Buka Browser:** Buka Google Chrome, Safari, atau *browser* apa pun di komputer Anda.
2. **Kunjungi Situs Resmi:** Ketik [github.com](https://github.com/) di kolom URL, lalu tekan **Enter**.
3. **Mulai Pendaftaran:** Di halaman utama GitHub, cari dan klik tombol **Sign up** (biasanya ada di pojok kanan atas atau di tengah layar).
4. **Ikuti Proses Pendaftaran (*Interactive Signup*):**
GitHub akan memandu Anda melalui halaman pendaftaran berbasis teks (*chat-like*):
* **Masukkan Email:** Ketik alamat email aktif Anda, lalu klik *Continue*.
* **Buat Kata Sandi (*Password*):** Masukkan kata sandi yang kuat dan aman, lalu klik *Continue*.
* **Buat Nama Pengguna (*Username*):** Pilih nama unik untuk akun Anda (nama ini akan menjadi bagian dari tautan profil Anda nantinya, misal: `[github.com/namakamu](https://github.com/namakamu)`).
* **Verifikasi Preferensi:** Pilih apakah Anda ingin menerima pembaruan email (bisa pilih "y" atau "n"), lalu lanjutkan.


5. **Verifikasi Kecepatan / Teka-teki:** GitHub akan meminta Anda menyelesaikan teka-teki sederhana (seperti mencocokkan gambar atau memutar objek) untuk membuktikan bahwa Anda bukan robot.
6. **Masukkan Kode Verifikasi (OTP):** Cek kotak masuk (*inbox*) email yang Anda daftarkan tadi. GitHub akan mengirimkan kode 6 digit. Ketik kode tersebut ke halaman GitHub.

---

## Langkah 2: Personalisasi Awal Akun

Setelah email terverifikasi, Anda akan dibawa masuk ke halaman *Welcome to GitHub!* (Selamat datang di GitHub). Di sini Anda akan ditanya beberapa hal opsional:

* Anda bisa memilih peran (misalnya: *Student*, *Developer*, atau *Hobbyist*).
* Pilih tingkat pengalaman Anda (pilih saja opsi untuk pemula).
* **Pilih Paket:** Pilih opsi **Free** (Gratis). Paket gratis ini sudah lebih dari cukup untuk kebutuhan belajar, membuat portofolio, hingga menyimpan banyak proyek pribadi.

Setelah melewati tahapan ini, Anda akan diarahkan ke halaman utama atau *Dashboard* akun GitHub Anda. Selamat! Akun Anda sudah resmi jadi.

---

## Langkah 3: Melakukan Pengaturan Penting Agar Akun "Memadai"

Agar akun Anda terlihat rapi dan siap digunakan untuk berkolaborasi atau melamar kerja di masa depan, lakukan beberapa pengaturan profil sederhana ini:

1. **Mengubah Foto Profil:**
* Klik ikon foto profil kecil di pojok kanan atas layar GitHub.
* Pilih **Settings**.
* Di menu sebelah kiri, pilih **Public profile**.
* Di bagian foto profil, klik **Upload a photo** dan pilih foto terbaik Anda (bisa foto wajah profesional atau logo/avatar pilihan Anda).


2. **Mengisi Informasi Profil:**
* Masih di halaman *Public profile*, Anda bisa mengisi:
* **Name:** Nama lengkap Anda.
* **Bio:** Kalimat singkat tentang diri Anda (contoh: *"Belajar Pemrograman Web dari nol"*).
* **Company / Location:** Lokasi Anda (misal: *Indonesia*).


* Klik tombol hijau **Update profile** di bagian bawah.



---

## Langkah 4: Menghubungkan Git Lokal dengan Akun GitHub

Agar komputer Anda bisa mengirim kode ke akun GitHub yang baru saja dibuat, Anda perlu menghubungkan identitas Git yang sudah diinstal sebelumnya. Buka Terminal (atau Git Bash di Windows) dan pastikan email dan nama yang Anda masukkan sama persis dengan yang Anda gunakan saat mendaftar di GitHub:

```bash
git config --global user.name "Nama Lengkap Anda"
git config --global user.email "email-github-anda@domain.com"

```

---

## Langkah 5: Membuat Repositori Pertama Anda!

Repositori (biasa disingkat **repo**) adalah "folder" atau "proyek" tempat Anda menyimpan file kode di GitHub. Mari buat repo pertama Anda:

1. Di halaman utama GitHub, klik tombol **New** (berwarna hijau) di sisi kiri atas, atau klik ikon **`+`** di pojok kanan atas lalu pilih **New repository**.
2. **Isi Detail Repositori:**
* **Repository name:** Beri nama proyek Anda, contoh: `proyek-pertama` (gunakan tanda hubung `-` spasi sebagai pengganti spasi).
* **Description:** Tulis deskripsi singkat tentang proyek ini (opsional).
* **Jenis Repo:** Pilih **Public** (siapa saja bisa melihat, bagus untuk portofolio) atau **Private** (hanya Anda yang bisa melihat). Pilih *Public* saja untuk awal belajar.
* **Add a README file:** **Centang kotak ini** (*Add a README file*). Ini penting agar repo Anda langsung memiliki halaman sambutan awal saat dibuka.


3. Klik tombol hijau **Create repository** di bagian bawah.

---

Selesai! Anda kini sudah memiliki akun GitHub yang aktif, profil yang rapi, dan repositori pertama Anda di awan (*cloud*).
