Nuxt sangat fleksibel soal urusan *styling*. Kamu bisa menulis *style* sendiri, atau mereferensikan *stylesheet* lokal maupun eksternal. Kamu juga bisa memakai *CSS preprocessor*, *CSS framework*, *UI library*, dan modul Nuxt untuk mempercantik tampilan aplikasimu.

## Stylesheet Lokal

Kalau kamu menulis *stylesheet* lokal, tempat yang paling tepat untuk menyimpannya adalah di [direktori `app/assets/`](/nuxt/directory-structure/app/assets).

### Mengimpor di Dalam Komponen

Kamu bisa mengimpor *stylesheet* langsung di halaman (*page*), *layout*, atau komponenmu. Caranya bisa memakai *import* JavaScript, atau pernyataan [`@import` milik CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@import).

```vue [app/pages/index.vue]
<script>
// Gunakan static import agar kompatibel dengan sisi server
import '~/assets/css/first.css'

// Perhatian: Dynamic import tidak kompatibel dengan sisi server
import('~/assets/css/first.css')
</script>

<style>
@import url("~/assets/css/second.css");
</style>
```

::tip
*Stylesheet* tersebut akan di-*inline* ke dalam HTML yang di-*render* oleh Nuxt.
::

### Properti `css`

Kamu juga bisa memanfaatkan properti `css` di konfigurasi Nuxt. Seperti sebelumnya, tempat paling wajar untuk menyimpan *stylesheet*-mu adalah di [direktori `app/assets/`](/nuxt/directory-structure/app/assets). Kamu tinggal merujuk ke path-nya, dan Nuxt akan menyertakannya ke seluruh halaman di aplikasimu.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['~/assets/css/main.css'],
})
```

::tip
*Stylesheet* ini akan di-*inline* ke dalam HTML yang di-*render* oleh Nuxt, disuntikkan secara global, dan ada di semua halaman.
::

### Bekerja dengan Font

Taruh file *font* lokalmu di direktori `public/`, misalnya di `public/fonts`. Setelah itu, kamu bisa mereferensikannya di *stylesheet* menggunakan `url()`.

```css [assets/css/main.css]
@font-face {
  font-family: 'FarAwayGalaxy';
  src: url('/fonts/FarAwayGalaxy.woff') format('woff');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

Lalu, panggil *font*-nya berdasarkan nama di *stylesheet*, halaman, atau komponenmu:

```vue
<style>
h1 {
  font-family: 'FarAwayGalaxy', sans-serif;
}
</style>
```

### Stylesheet yang Didistribusikan Melalui NPM

Kamu juga bisa mereferensikan *stylesheet* yang didistribusikan lewat npm. Sebagai contoh, aku akan pakai *library* yang cukup populer yaitu `animate.css`.

::code-group{sync="pm"}

```bash [npm]
npm install animate.css
```

```bash [yarn]
yarn add animate.css
```

```bash [pnpm]
pnpm install animate.css
```

```bash [bun]
bun install animate.css
```

```bash [deno]
deno install npm:animate.css
```

::

Setelah itu, kamu bisa langsung mereferensikannya di halaman, *layout*, atau komponenmu:

```vue [app/app.vue]
<script>
import 'animate.css'
</script>

<style>
@import url("animate.css");
</style>
```

Paket tersebut juga bisa direferensikan sebagai *string* di properti `css` pada konfigurasi Nuxt-mu.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['animate.css'],
})
```

## Stylesheet Eksternal

Kamu bisa menyertakan *stylesheet* eksternal ke dalam aplikasimu dengan menambahkan elemen *link* di bagian *head* pada file `nuxt.config`. Ada beberapa metode yang bisa kamu pakai untuk melakukannya. Perlu diingat, *stylesheet* lokal juga bisa disertakan dengan cara ini.

Kamu bisa memanipulasi bagian *head* menggunakan properti [`app.head`](/nuxt/api/nuxt-config#head) di konfigurasi Nuxt-mu:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      link: [{ rel: 'stylesheet', href: 'https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css' }],
    },
  },
})
```

### Menambahkan Stylesheet Secara Dinamis

Kamu bisa memakai composable `useHead` untuk mengatur nilai di bagian *head* secara dinamis langsung di kodemu.

:read-more{to="/nuxt/api/composables/use-head"}

```ts twoslash
useHead({
  link: [{ rel: 'stylesheet', href: 'https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css' }],
})
```

Di balik layar, Nuxt memakai `unhead`, dan kamu bisa merujuk ke [dokumentasi lengkapnya](https://unhead.unjs.io).

### Memodifikasi Head yang Di-render dengan Plugin Nitro

Kalau kamu butuh kendali yang lebih lanjut, kamu bisa menyadap (*intercept*) HTML yang sudah di-*render* menggunakan *hook* dan memodifikasi bagian *head*-nya secara terprogram.

Buatlah sebuah *plugin* di `~~/server/plugins/my-plugin.ts` seperti ini:

<!-- TODO: figure out how to use twoslash to inject types for a different context -->

```ts [server/plugins/my-plugin.ts]
import { definePlugin } from 'nitro'

export default definePlugin((nitro) => {
  nitro.hooks.hook('render:html', (html) => {
    html.head.push('<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css">')
  })
})
```

*Stylesheet* eksternal itu termasuk sumber daya yang memblokir *render* (*render-blocking resources*): mereka harus dimuat dan diproses terlebih dahulu sebelum peramban bisa me-*render* halaman. Halaman web yang mengandung *style* yang tidak perlu besar akan memakan waktu lebih lama untuk di-*render*. Kamu bisa baca lebih lanjut soal ini di [web.dev](https://web.dev/articles/defer-non-critical-css).

## Menggunakan Preprocessor

Kalau kamu mau memakai *preprocessor* seperti SCSS, Sass, Less, atau Stylus, kamu harus menginstalnya terlebih dahulu.

::code-group

```bash [Sass & SCSS]
npm install -D sass
```

```bash [Less]
npm install -D less
```

```bash [Stylus]
npm install -D stylus
```

::

Tempat paling wajar untuk menulis *stylesheet* berbasis *preprocessor* ini adalah direktori `app/assets`. Lalu, kamu bisa mengimpor file sumber tersebut di `app.vue`-mu (atau file *layout*) memakai sintaksis *preprocessor* yang kamu pilih.

```vue [app/pages/app.vue]
<style lang="scss">
@use "~/assets/scss/main.scss";
</style>
```

Sebagai alternatif, kamu bisa memakai properti `css` di konfigurasi Nuxt-mu.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['~/assets/scss/main.scss'],
})
```

::tip
Pada kedua kasus tersebut, *stylesheet* yang sudah dikompilasi akan di-*inline* ke dalam HTML yang di-*render* oleh Nuxt.
::

Kalau kamu perlu menyuntikkan kode ke dalam file yang sudah di-*pre-process*, misalnya *Sass partial* yang berisi variabel warna, kamu bisa melakukannya melalui [opsi *preprocessor* milik Vite](https://vite.dev/config/shared-options#css-preprocessoroptions).

Buat beberapa *partial* di direktori `app/assets`-mu:

::code-group{sync="preprocessor"}

```scss [assets/_colors.scss]
$primary: #49240F;
$secondary: #E4A79D;
```

```sass [assets/_colors.sass]
$primary: #49240F
$secondary: #E4A79D
```

::

Lalu di `nuxt.config`-mu:

::code-group

```ts twoslash [SCSS]
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorOptions: {
        scss: {
          additionalData: '@use "~/assets/_colors.scss" as *;',
        },
      },
    },
  },
})
```

```ts twoslash [SASS]
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorOptions: {
        sass: {
          additionalData: '@use "~/assets/_colors.sass" as *\n',
        },
      },
    },
  },
})
```

::

Nuxt memakai Vite secara bawaan. Kalau kamu lebih memilih webpack, kamu bisa merujuk ke [dokumentasi *loader* masing-masing *preprocessor*](https://webpack.js.org/loaders/sass-loader/).

### Preprocessor Workers (Eksperimental)

Vite menyediakan [opsi eksperimental](https://vite.dev/config/shared-options#css-preprocessormaxworkers) yang bisa mempercepat penggunaan *preprocessor*.

Kamu bisa mengaktifkannya di `nuxt.config`-mu:

```ts
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorMaxWorkers: true, // jumlah CPU dikurangi 1
    },
  },
})
```

::note
Ini adalah opsi eksperimental, jadi sebaiknya kamu sering-sering cek dokumentasi Vite dan [berikan masukan (*feedback*)](https://github.com/vitejs/vite/discussions/15835) mengenainya.
::

## Styling di Single File Components (SFC)

Salah satu hal terbaik dari Vue dan SFC adalah kemudahannya dalam menangani *styling*. Kamu bisa menulis kode CSS atau *preprocessor* langsung di blok *style* pada file komponenmu. Dengan begitu, kamu akan mendapat pengalaman pengembang yang luar biasa tanpa harus memakai solusi seperti CSS-in-JS. Tapi, kalau kamu memang ingin memakai CSS-in-JS, kamu bisa mencari *library* dan modul pihak ketiga yang mendukungnya, seperti [pinceau](https://github.com/Tahul/pinceau).

Kamu bisa merujuk ke [dokumentasi Vue](https://vuejs.org/api/sfc-css-features) untuk referensi lengkap soal *styling* komponen di SFC.

### Binding Class dan Style

Kamu bisa memanfaatkan fitur SFC milik Vue untuk memberi *style* pada komponen menggunakan atribut *class* dan *style*.

::code-group

```vue [Ref dan Reactive]
<script setup lang="ts">
const isActive = ref(true)
const hasError = ref(false)
const classObject = reactive({
  'active': true,
  'text-danger': false,
})
</script>

<template>
  <div
    class="static"
    :class="{ 'active': isActive, 'text-danger': hasError }"
  />
  <div :class="classObject" />
</template>
```

```vue [Computed]
<script setup lang="ts">
const isActive = ref(true)
const error = ref(null)

const classObject = computed(() => ({
  'active': isActive.value && !error.value,
  'text-danger': error.value && error.value.type === 'fatal',
}))
</script>

<template>
  <div :class="classObject" />
</template>
```

```vue [Array]
<script setup lang="ts">
const isActive = ref(true)
const errorClass = ref('text-danger')
</script>

<template>
  <div :class="[{ active: isActive }, errorClass]" />
</template>
```

```vue [Style]
<script setup lang="ts">
const activeColor = ref('red')
const fontSize = ref(30)
const styleObject = reactive({ color: 'red', fontSize: '13px' })
</script>

<template>
  <div :style="{ color: activeColor, fontSize: fontSize + 'px' }" />
  <div :style="[baseStyles, overridingStyles]" />
  <div :style="styleObject" />
</template>
```

::

Silakan merujuk ke [dokumentasi Vue](https://vuejs.org/guide/essentials/class-and-style) untuk info lebih lanjut.

### Style Dinamis dengan `v-bind`

Kamu bisa mereferensikan variabel dan ekspresi JavaScript di dalam blok *style* dengan fungsi `v-bind`. *Binding* ini bersifat dinamis, yang artinya kalau nilai variabelnya berubah, *style*-nya juga akan ikut diperbarui.

```vue
<script setup lang="ts">
const color = ref('red')
</script>

<template>
  <div class="text">
    hello
  </div>
</template>

<style>
.text {
  color: v-bind(color);
}
</style>
```

### Scoped Styles

Atribut `scoped` memungkinkan kamu memberi *style* pada komponen secara terisolasi. *Style* yang dideklarasikan dengan atribut ini hanya akan berlaku pada komponen itu sendiri.

```vue
<template>
  <div class="example">
    hi
  </div>
</template>

<style scoped>
.example {
  color: red;
}
</style>
```

### CSS Modules

Kamu bisa memakai [CSS Modules](https://github.com/css-modules/css-modules) dengan atribut `module`. Akseslah melalui variabel `$style` yang sudah disuntikkan secara otomatis.

```vue
<template>
  <p :class="$style.red">
    This should be red
  </p>
</template>

<style module>
.red {
  color: red;
}
</style>
```

### Dukungan Preprocessor

Blok *style* di SFC mendukung sintaksis *preprocessor*. Vite sudah mendukung file .scss, .sass, .less, .styl, dan .stylus secara bawaan tanpa perlu konfigurasi. Kamu tinggal instal dulu, lalu mereka bisa langsung dipakai di SFC memakai atribut `lang`.

::code-group

```vue [SCSS]
<style lang="scss">
  /* Tulis scss di sini */
</style>
```

```vue [Sass]
<style lang="sass">
  /* Tulis sass di sini */
</style>
```

```vue [LESS]
<style lang="less">
  /* Tulis less di sini */
</style>
```

```vue [Stylus]
<style lang="stylus">
  /* Tulis stylus di sini */
</style>
```

::

Kamu bisa merujuk ke [dokumentasi CSS Vite](https://vite.dev/guide/features#css) dan [dokumentasi @vitejs/plugin-vue](https://github.com/vitejs/vite-plugin-vue/tree/main/packages/plugin-vue). Untuk pengguna webpack, bisa cek [dokumentasi *vue loader*](https://vue-loader.vuejs.org).

## Menggunakan PostCSS

Nuxt sudah menyertakan PostCSS secara bawaan di dalamnya. Kamu bisa mengonfigurasinya lewat file `nuxt.config`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  postcss: {
    plugins: {
      'postcss-nested': {},
      'postcss-custom-media': {},
    },
  },
})
```

Supaya *syntax highlighting* di SFC-mu bekerja dengan benar, kamu bisa memakai atribut `lang="postcss"`.

```vue
<style lang="postcss">
  /* Tulis postcss di sini */
</style>
```

Secara bawaan, Nuxt sudah memasang dan mengonfigurasi *plugin* berikut ini:

- [postcss-import](https://github.com/postcss/postcss-import): Memperbaiki aturan `@import`
- [postcss-url](https://github.com/postcss/postcss-url): Mengubah pernyataan `url()`
- [autoprefixer](https://github.com/postcss/autoprefixer): Menambahkan *vendor prefix* secara otomatis
- [cssnano](https://cssnano.github.io/cssnano/): Untuk *minifikasi* dan *purge*

## Memanfaatkan Layout untuk Banyak Style

Kalau kamu perlu memberi *style* yang benar-benar berbeda pada bagian-bagian tertentu di aplikasimu, kamu bisa memanfaatkan *layout*. Gunakan *style* yang berbeda untuk *layout* yang berbeda pula.

```vue
<template>
  <div class="default-layout">
    <h1>Default Layout</h1>
    <slot />
  </div>
</template>

<style>
.default-layout {
  color: red;
}
</style>
```

## Library dan Modul Pihak Ketiga

Nuxt tidak memaksakan satu cara tertentu soal *styling* dan memberimu banyak sekali pilihan. Kamu bebas memakai alat *styling* apa saja yang kamu mau, seperti *library* populer [UnoCSS](https://unocss.dev) atau [Tailwind CSS](https://tailwindcss.com).

Komunitas dan tim Nuxt sudah mengembangkan banyak modul Nuxt untuk mempermudah proses integrasi ini. Kamu bisa menjelajahinya di [bagian modul](/modules) di *website* ini. Berikut beberapa modul yang bisa kamu coba pertama kali:

- [UnoCSS](/modules/unocss): Mesin *atomic CSS* sesuai permintaan (*on-demand*) secara instan
- [Tailwind CSS](/modules/tailwindcss): *CSS framework* berbasis *utility-first*
- [Fontaine](https://github.com/nuxt-modules/fontaine): *Fallback* metrik *font*
- [Pinceau](https://github.com/Tahul/pinceau): *Styling framework* yang dapat beradaptasi
- [Nuxt UI](https://ui.nuxt.com): *UI Library* untuk Aplikasi Web Modern
- [Panda CSS](https://panda-css.com/docs/installation/nuxt): Mesin CSS-in-JS yang menghasilkan *atomic CSS* saat proses *build*

Modul Nuxt memang menawarkan pengalaman pengembang yang sudah bagus langsung pakai (*out of the box*), tapi ingatlah bahwa kalau alat favoritmu belum punya modul, bukan berarti kamu tidak bisa memakainya di Nuxt! Kamu bisa mengonfigurasinya sendiri di proyekmu. Tergantung alatnya, kamu mungkin perlu menggunakan [plugin Nuxt](/nuxt/directory-structure/app/plugins) dan/atau [membuat modulmu sendiri](/nuxt/guide/modules). Kalau sudah jadi, jangan lupa bagikan ke [komunitas](/modules) ya!

### Memuat Webfont dengan Mudah

Kamu bisa memakai [modul Nuxt Google Fonts](https://github.com/nuxt-modules/google-fonts) untuk memuat *Google Fonts*.

Kalau kamu memakai [UnoCSS](https://unocss.dev/integrations/nuxt), perlu kamu tahu bahwa dia sudah memiliki [*preset web fonts*](https://unocss.dev/presets/web-fonts) yang memudahkan pemuatan *font* dari penyedia umum, termasuk *Google Fonts* dan lainnya.

### Optimasi Lanjutan untuk LCP

Kamu bisa melakukan hal-hal berikut untuk mempercepat proses unduh file CSS global-mu:

- Gunakan CDN supaya file-filenya secara fisik lebih dekat dengan penggunamu
- Kompres asetmu, sebaiknya memakai Brotli
- Gunakan HTTP2/HTTP3 untuk proses pengirimannya
- *Host* asetmu di *domain* yang sama (hindari memakai *subdomain* yang berbeda)

Sebagian besar hal di atas seharusnya sudah dikerjakan secara otomatis kalau kamu memakai platform modern seperti Cloudflare, Netlify, atau Vercel. Kamu bisa menemukan panduan optimasi LCP di [web.dev](https://web.dev/articles/optimize-lcp).

Kalau semua CSS-mu sudah di-*inline* oleh Nuxt, kamu bisa (secara eksperimental) menghentikan sepenuhnya file CSS eksternal agar tidak direferensikan di HTML yang di-*render*. Kamu bisa melakukannya dengan *hook*, yang bisa kamu taruh di sebuah modul, atau di file konfigurasi Nuxt-mu.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    'build:manifest': (manifest) => {
      // cari entri app, daftar css
      const css = Object.values(manifest).find(options => options.isEntry)?.css
      if (css) {
        // mulai dari akhir array dan bergerak ke awal
        for (let i = css.length - 1; i >= 0; i--) {
          // jika dimulai dengan 'entry', hapus dari daftar
          if (css[i].startsWith('entry')) {
            css.splice(i, 1)
          }
        }
      }
    },
  },
})
```
