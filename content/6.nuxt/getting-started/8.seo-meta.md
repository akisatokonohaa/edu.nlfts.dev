Manajemen *head tag* di Nuxt didukung oleh [Unhead](https://unhead.unjs.io). Ia menyediakan *default* yang sudah masuk akal, beberapa *composable* yang keren, dan banyak opsi konfigurasi untuk mengelola *head* dan *SEO meta tag* pada aplikasimu.

## Konfigurasi Nuxt

Menyediakan properti [`app.head`](/nuxt/api/nuxt-config#head) di file [`nuxt.config.ts`](/nuxt/directory-structure/nuxt-config) memungkinkanmu untuk mengkustomisasi *head* secara statis untuk seluruh aplikasimu.

::important
Metode ini tidak mengizinkanmu untuk memberikan data yang reaktif. Kami menyarankan untuk memakai `useHead()` di `app.vue` saja.
::

Ini adalah praktik yang bagus untuk mengatur *tag* yang bersifat tetap di sini, seperti *default* judul situs, bahasa, dan *favicon*.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      title: 'Nuxt', // judul fallback bawaan
      htmlAttrs: {
        lang: 'en',
      },
      link: [
        { rel: 'icon', type: 'image/x-icon', href: '/favicon.ico' },
      ],
    },
  },
})
```

::note
Saat kamu mengatur [`app.cdnURL`](/nuxt/api/nuxt-config#cdnurl), aset di [direktori `public/`](/nuxt/directory-structure/public)-mu (termasuk `favicon.ico`) akan disajikan dari CDN tersebut. Nuxt akan menyelesaikan (*resolve*) aset publik berdasarkan `cdnURL`, atau jatuh kembali ke `app.baseURL` jika tidak ada. Namun, *link* statis pada `app.head` seperti `href: '/favicon.ico'` di atas adalah *path* literal dan **tidak** diselesaikan berdasarkan `cdnURL`. Untuk mengarahkan *favicon* ke lokasi yang sudah diselesaikan, bangunlah *href*-nya dari *runtime config* menggunakan [`useHead()`](/nuxt/api/composables/use-head) di `app.vue`:

```vue [app/app.vue]
<script setup lang="ts">
const { cdnURL, baseURL } = useRuntimeConfig().app
useHead({
  link: [
    { rel: 'icon', type: 'image/x-icon', href: `${cdnURL || baseURL}favicon.ico` },
  ],
})
</script>
```
::

Kamu juga bisa menyediakan kunci apa saja yang tercantum di bawah ini pada bagian [Tipe](/nuxt/getting-started/seo-meta#types).

### Tag Bawaan (*Default Tags*)

Beberapa *tag* sudah disediakan oleh Nuxt secara bawaan untuk memastikan *website*-mu bisa berjalan dengan baik langsung pakai (*out of the box*).

- `viewport`: `width=device-width, initial-scale=1`
- `charset`: `utf-8`

Meskipun sebagian besar situs tidak perlu menimpa *default* ini, kamu bisa memperbaruinya menggunakan jalan pintas berdasarkan kuncinya.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      // perbarui default Nuxt
      charset: 'utf-16',
      viewport: 'width=device-width, initial-scale=1, maximum-scale=1',
    },
  },
})
```

## `useHead`

Fungsi *composable* [`useHead`](/nuxt/api/composables/use-head) mendukung inputan yang reaktif, yang memungkinkanmu mengelola *head tag* secara terprogram.

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  title: 'My App',
  meta: [
    { name: 'description', content: 'My amazing site.' },
  ],
  bodyAttrs: {
    class: 'test',
  },
  script: [{ innerHTML: 'console.log(\'Hello world\')' }],
})
</script>
```

Aku sarankan kamu untuk melihat-lihat *composable* [`useHead`](/nuxt/api/composables/use-head) dan [`useHeadSafe`](/nuxt/api/composables/use-head-safe).

## `useSeoMeta`

*Composable* [`useSeoMeta`](/nuxt/api/composables/use-seo-meta) memungkinkanmu mendefinisikan *SEO meta tag* situsmu sebagai sebuah objek dengan keamanan tipe (*type safety*) yang lengkap.

Ini membantumu menghindari kesalahan ketik dan kesalahan umum lainnya, seperti menggunakan `name` alih-alih `property`.

```vue twoslash [app/app.vue]
<script setup lang="ts">
useSeoMeta({
  title: 'My Amazing Site',
  ogTitle: 'My Amazing Site',
  description: 'This is my amazing site, let me tell you all about it.',
  ogDescription: 'This is my amazing site, let me tell you all about it.',
  ogImage: 'https://example.com/image.png',
  twitterCard: 'summary_large_image',
})
</script>
```

:read-more{to="/nuxt/api/composables/use-seo-meta"}

## Komponen

Meskipun penggunaan [`useHead`](/nuxt/api/composables/use-head) sangat kami sarankan dalam kondisi apa pun, mungkin kamu punya preferensi sendiri untuk mendefinisikan *head tag* di dalam *template* menggunakan komponen.

Untuk keperluan ini, Nuxt menyediakan komponen-komponen berikut: `<Title>`, `<Base>`, `<NoScript>`, `<Style>`, `<Meta>`, `<Link>`, `<Body>`, `<Html>`, dan `<Head>`. Perhatikan penggunaan huruf kapital pada komponen-komponen ini untuk memastikan kita tidak menggunakan *tag* HTML native yang tidak valid.

`<Head>` dan `<Body>` bisa menerima *meta tag* bersarang (untuk alasan estetika), tapi ini tidak mempengaruhi _di mana_ *meta tag* bersarang tersebut akan di-*render* di HTML akhir.

<!-- @case-police-ignore html -->

```vue [app/app.vue]
<script setup lang="ts">
const title = ref('Hello World')
</script>

<template>
  <div>
    <Head>
      <Title>{{ title }}</Title>
      <Meta
        name="description"
        :content="title"
      />
      <Style>
        body { background-color: green; }
      </Style>
    </Head>

    <h1>{{ title }}</h1>
  </div>
</template>
```

Aku sarankan untuk membungkus komponen-komponenmu di dalam komponen `<Head>` atau `<Html>` karena *tag*-nya akan di-*dedupe* (dihapus jika duplikat) dengan cara yang lebih intuitif.

::warning
Kalau kamu perlu menduplikasi *tag* di batas *client-server*, berikan atribut `key` pada komponen `<Head>`.
::

## Tipe

Di bawah ini adalah tipe yang tidak reaktif yang dipakai untuk [`useHead`](/nuxt/api/composables/use-head), [`app.head`](/nuxt/api/nuxt-config#head), dan komponen-komponen.

```ts [Tipe]
interface MetaObject {
  title?: string
  titleTemplate?: string | ((title?: string) => string)
  templateParams?: Record<string, string | Record<string, string>>
  base?: Base
  link?: Link[]
  meta?: Meta[]
  style?: Style[]
  script?: Script[]
  noscript?: Noscript[]
  htmlAttrs?: HtmlAttributes
  bodyAttrs?: BodyAttributes
}
```

Lihat [@unhead/vue](https://github.com/unjs/unhead/blob/main/packages/vue/src/types/schema.ts) untuk tipe yang lebih detail.

## Fitur

### Reaktivitas

Reaktivitas didukung di semua properti, dengan cara memberikan nilai *computed*, *getter*, atau objek reaktif.

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  const description = ref('My amazing site.')

  useHead({
    meta: [
      { name: 'description', content: description },
    ],
  })
  </script>
  ```

  ```vue twoslash [useSeoMeta]
  <script setup lang="ts">
  const description = ref('My amazing site.')

  useSeoMeta({
    description,
  })
  </script>
  ```

  ```vue [app/Components]
  <script setup lang="ts">
  const description = ref('My amazing site.')
  </script>

  <template>
    <div>
      <Meta
        name="description"
        :content="description"
      />
    </div>
  </template>
  ```

::

### Template Judul (*Title Template*)

Kamu bisa memakai opsi `titleTemplate` untuk menyediakan *template* dinamis guna mengkustomisasi judul situsmu. Misalnya, kamu bisa menambahkan nama situsmu ke judul setiap halaman.

`titleTemplate` bisa berupa *string*, di mana `%s` akan diganti dengan judulnya, atau bisa berupa sebuah fungsi.

Kalau kamu ingin memakai fungsi (untuk kendali penuh), maka ini tidak bisa diatur di `nuxt.config`-mu. Sebagai gantinya, aku sarankan untuk mengaturnya di dalam file `app.vue` di mana ia akan berlaku untuk semua halaman di situsmu:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} - Site Title` : 'Site Title'
    },
  })
  </script>
  ```

::

Sekarang, kalau kamu mengatur judulnya menjadi `My Page` dengan [`useHead`](/nuxt/api/composables/use-head) di halaman lain situsmu, maka judulnya akan muncul sebagai 'My Page - Site Title' di tab peramban. Kamu juga bisa memberikan nilai `null` untuk kembali ke judul *default* yaitu 'Site Title'.

### Parameter Template

Kamu bisa memakai `templateParams` untuk menyediakan *placeholder* tambahan di `titleTemplate`-mu selain `%s` bawaan. Ini memungkinkan pembuatan judul yang lebih dinamis.

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} %separator %siteName` : '%siteName'
    },
    templateParams: {
      siteName: 'Site Title',
      separator: '-',
    },
  })
  </script>
  ```

::

### Tag Body

Kamu bisa memakai opsi `tagPosition: 'bodyClose'` pada *tag* yang berlaku untuk menambahkannya di akhir *tag* `<body>`.

Misalnya:

```vue twoslash
<script setup lang="ts">
useHead({
  script: [
    {
      src: 'https://third-party-script.com',
      // opsi yang valid adalah: 'head' | 'bodyClose' | 'bodyOpen'
      tagPosition: 'bodyClose',
    },
  ],
})
</script>
```

## Contoh

### Dengan `definePageMeta`

Di dalam [direktori `app/pages/`](/nuxt/directory-structure/app/pages)-mu, kamu bisa memakai `definePageMeta` bersama dengan [`useHead`](/nuxt/api/composables/use-head) untuk mengatur *metadata* berdasarkan *route* yang sedang aktif.

Misalnya, kamu bisa mengatur judul halaman saat ini terlebih dahulu (ini diekstrak saat proses *build* melalui *macro*, jadi tidak bisa diatur secara dinamis):

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  title: 'Some Page',
})
</script>
```

Lalu, di file *layout*-mu, kamu bisa menggunakan *metadata route* yang sudah kamu atur sebelumnya:

```vue twoslash [layouts/default.vue]
<script setup lang="ts">
const route = useRoute()

useHead({
  meta: [{ property: 'og:title', content: `App Name - ${route.meta.title}` }],
})
</script>
```

### Judul Dinamis

Pada contoh di bawah ini, `titleTemplate` diatur baik sebagai *string* dengan *placeholder* `%s` atau sebagai `fungsi`, yang memberikan fleksibilitas lebih besar dalam mengatur judul halaman secara dinamis untuk setiap *route* di aplikasi Nuxt-mu:

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  // sebagai string,
  // di mana `%s` akan diganti dengan judul
  titleTemplate: '%s - Site Title',
})
</script>
```

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  // atau sebagai fungsi
  titleTemplate: (productCategory) => {
    return productCategory
      ? `${productCategory} - Site Title`
      : 'Site Title'
  },
})
</script>
```

`nuxt.config` juga bisa dipakai sebagai cara alternatif untuk mengatur judul halaman. Namun, `nuxt.config` tidak mengizinkan judul halaman untuk bersifat dinamis. Oleh karena itu, sangat disarankan untuk memakai `titleTemplate` di file `app.vue` untuk menambahkan judul dinamis, yang nantinya akan diterapkan ke semua *route* di aplikasi Nuxt-mu.

### CSS Eksternal

Contoh di bawah ini menunjukkan bagaimana cara kamu mengaktifkan *Google Fonts* menggunakan properti `link` dari *composable* [`useHead`](/nuxt/api/composables/use-head) atau dengan memakai komponen `<Link>`:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    link: [
      {
        rel: 'preconnect',
        href: 'https://fonts.googleapis.com',
      },
      {
        rel: 'stylesheet',
        href: 'https://fonts.googleapis.com/css2?family=Roboto&display=swap',
        crossorigin: '',
      },
    ],
  })
  </script>
  ```

  ```vue [app/Components]
  <template>
    <div>
      <Link
        rel: 'preconnect'
        href: 'https://fonts.googleapis.com'
      />
      <Link
        rel: 'stylesheet'
        href: 'https://fonts.googleapis.com/css2?family=Roboto&display=swap'
        crossorigin=""
      />
    </div>
  </template>
  ```
