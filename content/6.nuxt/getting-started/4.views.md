## `app.vue`

![File app.vue adalah titik masuk (entrypoint) dari aplikasimu](https://i.ibb.co/xqZSCL2H/image.png)

Secara bawaan, Nuxt akan memperlakukan file ini sebagai **titik masuk (*entrypoint*)** dan me-*render* isinya di setiap *route* aplikasi yang kamu buat.

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
  </div>
</template>
```

::tip
Kalau kamu sudah terbiasa dengan Vue, mungkin kamu bertanya-tanya kemana file `main.js` itu (file yang biasanya bertugas membuat aplikasi Vue). Di Nuxt, urusan itu sudah kami tangani di balik layar.
::

## Komponen (Components)

![Komponen adalah bagian dari UI yang bisa digunakan ulang](https://i.ibb.co/n87Xnhzy/image.png
)

Sebagian besar komponen adalah bagian dari UI yang bisa dipakai berulang kali, seperti *button* atau *menu*. Di Nuxt, kamu bisa membuat komponen-komponen ini di dalam direktori [`app/components/`](/nuxt/directory-structure/app/components). Nantinya, komponen tersebut akan langsung tersedia di seluruh aplikasimu tanpa perlu repot-repot melakukan *import* secara manual.

::code-group

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component.
    </AppAlert>
  </div>
</template>
```

```vue [app/components/AppAlert.vue]
<template>
  <span>
    <slot />
  </span>
</template>
```

::

## Halaman (Pages)

![Halaman adalah tampilan yang terikat pada route tertentu](https://i.ibb.co/pvcb24bN/image.png)


*Pages* merepresentasikan tampilan untuk setiap pola *route* tertentu. Setiap file yang ada di dalam direktori [`app/pages/`](/nuxt/directory-structure/app/pages) akan menjadi *route* yang berbeda dan menampilkan isinya masing-masing.

Untuk mulai memakai *pages*, buatlah file `app/pages/index.vue` lalu tambahkan komponen `<NuxtPage />` ke dalam [`app/app.vue`](/nuxt/directory-structure/app/app) (atau hapus saja file `app/app.vue` jika kamu ingin memakai *entry* bawaan). Sekarang, kamu bisa membuat halaman-halaman lain beserta *route*-nya hanya dengan menambahkan file baru di dalam direktori [`app/pages/`](/nuxt/directory-structure/app/pages).

::code-group

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

::

## Tata Letak (Layouts)

![Layouts adalah pembungkus (wrapper) di sekitar halaman](https://i.ibb.co/WWhc83JD/image.png)

*Layout* berfungsi sebagai pembungkus (*wrapper*) di sekitar halaman yang berisi UI umum untuk beberapa halaman, misalnya seperti tampilan *header* dan *footer*. *Layout* itu sendiri adalah file Vue yang memanfaatkan komponen `<slot />` untuk menampilkan konten **halaman**. Secara bawaan, Nuxt akan menggunakan file `app/layouts/default.vue`. Kamu juga bisa mengatur *layout* kustom sebagai bagian dari *metadata* halamanmu.

::note
Kalau aplikasimu hanya punya satu *layout* saja, kami menyarankan untuk memakai [`app/app.vue`](/nuxt/directory-structure/app/app) yang dipasangi [`<NuxtPage />`](/nuxt/api/components/nuxt-page) saja.
::

::code-group

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </div>
</template>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <AppHeader />
    <slot />
    <AppFooter />
  </div>
</template>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

::

Kalau kamu ingin membuat *layout* lainnya dan belajar cara menggunakannya di halamanmu, aku sudah menyiapkan informasi lebih lengkapnya di [bagian Layouts](/nuxt/directory-structure/app/layouts).

## Lanjutan: Memperluas Templat HTML

::note
Kalau kamu cuma perlu mengubah bagian `<head>`, aku sarankan untuk langsung melihat [bagian SEO dan *meta*](/nuxt/getting-started/seo-meta).
::

Kamu bisa menguasai penuh templat HTML-mu dengan menambahkan *plugin* Nitro yang mendaftarkan sebuah *hook*. Fungsi *callback* dari *hook* `render:html` ini memungkinkanmu untuk mengubah (memutasi) HTML sebelum akhirnya dikirim ke sisi *client*.

<!-- TODO: figure out how to use twoslash to inject types for a different context -->

```ts [server/plugins/extend-html.ts]
import { definePlugin } from 'nitro'

export default definePlugin((nitroApp) => {
  nitroApp.hooks.hook('render:html', (html, { event }) => {
    // Ini akan menjadi representasi objek dari templat html.
    console.log(html)
    html.head.push(`<meta name="description" content="My custom description" />`)
  })
  // Kamu juga bisa menyadap (intercept) respons di sini.
  nitroApp.hooks.hook('render:response', (response, { event }) => { console.log(response) })
})
```
