Biar aku jelaskan, Nuxt itu merupakan sebuah framework gratis dan sumber terbuka yang menawarkan cara intuitif serta mudah diperluas untuk membangun aplikasi web full-stack dan situs web berkelas produksi. Semua ini dibangun di atas [Vue.js](https://vuejs.org), sehingga hasilnya terjamin *type-safe* dan berperforma tinggi.

Kami sudah menyiapkan semuanya dari awal, sehingga kamu bisa langsung mulai menulis file `.vue` sambil menikmati fitur *hot module replacement* (HMR) saat proses pengembangan. Nanti di lingkungan produksi, aplikasinya akan berjalan dengan performa maksimal karena fitur *server-side rendering* (SSR) sudah aktif secara bawaan.

Yang menarik, Nuxt tidak mengikat kamu pada satu *vendor* tertentu (*vendor lock-in*). Kamu bebas untuk melakukan *deploy* aplikasimu [**di mana saja, bahkan hingga ke edge**](https://nuxt.com/blog/nuxt-on-the-edge).

::tip
Kalau kamu mau sekadar mencoba-coba Nuxt langsung di peramban, aku sarankan untuk [mengujinya di salah satu *sandbox* online milik kami](/nuxt/getting-started/installation#play-online).
::

## Automasi dan Konvensi

Nuxt memanfaatkan berbagai konvensi dan struktur direktori yang sudah terstandar untuk mengotomatiskan tugas-tugas yang repetitif. Dengan begitu, kamu bisa lebih fokus mengerjakan fitur-fitur baru. Meski begitu, kamu tetap bisa mengkustomisasi atau menimpa perilaku bawaannya lewat file konfigurasi.

- **Routing berbasis file:** kamu bisa menentukan rute hanya berdasarkan struktur di [direktori `app/pages/`](/nuxt/directory-structure/app/pages). Cara ini memudahkan pengorganasian aplikasi dan menghilangkan kebutuhan untuk mengonfigurasi *routing* secara manual.
- ***Code splitting*:** Nuxt secara otomatis memecah kode kamu menjadi bagian-bagian kecil (*chunks*). Ini sangat membantu memangkas waktu muat awal aplikasi.
- **SSR langsung pakai (*out of the box*):** Nuxt sudah dibekali kemampuan SSR di dalamnya, jadi kamu tidak perlu repot-repot menyiapkan server secara terpisah.
- ***Auto-imports*:** tulis komponen dan composable Vue di direktori masing-masing, lalu langsung pakai saja tanpa harus menuliskan perintah *import*. Manfaatnya, proses *tree-shaking* dan ukuran bundel JS menjadi lebih optimal.
- **Utilitas pengambilan data:** Nuxt menyediakan composable khusus untuk menangani pengambilan data yang kompatibel dengan SSR, lengkap dengan berbagai strategi pilihan.
- **Dukungan TypeScript tanpa konfigurasi (*zero-config*):** kamu bisa menulis kode yang *type-safe* tanpa harus pusing belajar konfigurasi TypeScript, berkat file `tsconfig.json` dan tipe data yang kami buatkan secara otomatis.
- ***Build tools* yang sudah dikonfigurasi:** secara bawaan, kami menggunakan [Vite](https://vite.dev) untuk mendukung HMR saat pengembangan, sekaligus mem-*bundle* kode untuk produksi menggunakan praktik terbaik di industri.

Nuxt menangani semua urusan teknis di atas sekaligus menyediakan fungsionalitas *frontend* dan *backend*. Jadi, kamu tinggal fokus pada hal yang paling penting: **membangun aplikasi webmu**.

## Server-Side Rendering

Seperti yang sudah aku singgung, Nuxt hadir dengan fitur *server-side rendering* (SSR) bawaan. Kamu tidak perlu mengonfigurasi server sendiri karena ada banyak sekali keuntungan yang bisa didapatkan untuk aplikasi web:

- **Waktu muat halaman awal yang lebih cepat:** Nuxt mengirimkan halaman HTML yang sudah ter-*render* penuh ke peramban, sehingga bisa langsung ditampilkan. Ini menciptakan persepsi kecepatan muat yang lebih baik dan meningkatkan pengalaman pengguna (UX), terutama pada jaringan atau perangkat yang lambat.
- **SEO yang lebih baik:** mesin pencari bisa mengindeks halaman SSR dengan jauh lebih baik karena konten HTML-nya langsung tersedia, alih-alih menunggu JavaScript untuk me-*render* konten di sisi klien.
- **Performa lebih stabil di perangkat kelas rendah:** beban JavaScript yang harus diunduh dan dieksekusi di sisi klien menjadi berkurang. Ini sangat membantu perangkat dengan spesifikasi rendah yang biasanya kesulitan memproses aplikasi JavaScript berat.
- **Aksesibilitas yang lebih baik:** konten langsung muncul saat halaman pertama kali dimuat, sehingga sangat membantu pengguna yang mengandalkan *screen reader* atau teknologi bantuan lainnya.
- ***Caching* yang lebih mudah:** halaman bisa di-*cache* di sisi server, yang mana ini akan mempercepat performa secara keseluruhan karena memangkas waktu yang dibutuhkan untuk membuat dan mengirim konten ke klien.

Secara keseluruhan, SSR mampu memberikan pengalaman pengguna yang lebih cepat dan efisien, sekaligus mendongkrak optimasi mesin pencari dan aksesibilitas.

Karena Nuxt adalah framework yang sangat fleksibel, kamu punya kebebasan untuk merender seluruh aplikasimu menjadi statis menggunakan perintah `nuxt generate`, menonaktifkan SSR secara global lewat opsi `ssr: false`, atau memanfaatkan *hybrid rendering* dengan mengatur opsi `routeRules`.

### Mesin Server

Mesin server Nuxt, yang kami beri nama [Nitro](https://nitro.build/), membuka berbagai kemampuan *full-stack* yang baru.

Saat di tahap pengembangan, Nitro memanfaatkan Rollup dan *Node.js workers* untuk kode server serta isolasi konteksmu. Ia juga secara otomatis membuat server API dengan membaca file di folder `server/api/`, dan mengambil *server middleware* dari `server/middleware/`.

Nanti saat di lingkungan produksi, Nitro akan membangun aplikasi beserta servermu ke dalam satu direktori universal bernama `.output`. Hasil *build* ini sangat ringan karena sudah di-*minify* dan dibebaskan dari modul Node.js (kecuali *polyfills*). Kamu bisa melakukan *deploy* output ini di sistem apa pun yang mendukung JavaScript, mulai dari Node.js, Serverless, Workers, *Edge-side rendering*, hingga hosting statis murni.

:read-more{title="Mesin server Nuxt" to="/nuxt/guide/concepts/server-engine"}

Aplikasi berbasis Nuxt bisa kamu *deploy* di server Node atau Deno, di-*pre-render* untuk dihosting di lingkungan statis, atau bahkan di-*deploy* ke penyedia layanan *serverless* dan *edge*.

### Arsitektur

Nuxt terbentuk dari kumpulan [paket inti](https://github.com/nuxt/nuxt/tree/main/packages) yang berbeda:

- Mesin inti: [nuxt](https://github.com/nuxt/nuxt/tree/main/packages/nuxt)
- *Bundler*: [@nuxt/vite-builder](https://github.com/nuxt/nuxt/tree/main/packages/vite), [@nuxt/rspack-builder](https://github.com/nuxt/nuxt/tree/main/packages/rspack), dan [@nuxt/webpack-builder](https://github.com/nuxt/nuxt/tree/main/packages/webpack)
- Antarmuka baris perintah (CLI): [@nuxt/cli](https://github.com/nuxt/cli)
- Mesin server: [nitro](https://github.com/nitrojs/nitro)
- Perangkat pengembangan (*Development kit*): [@nuxt/kit](https://github.com/nuxt/nuxt/tree/main/packages/kit)

Aku sangat menyarankan kamu untuk membaca setiap konsepnya agar punya gambaran utuh mengenai kemampuan Nuxt dan cakupan dari masing-masing paket tersebut.
