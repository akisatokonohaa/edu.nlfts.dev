::note
Nuxt memanfaatkan komponen [`<Transition>`](https://vuejs.org/guide/built-ins/transition#the-transition-component) milik Vue untuk menerapkan transisi di antara halaman dan *layout*.
::

::important
Karena Nuxt memakai komponen `<Transition>` dari Vue, halaman atau *layout* yang ingin kamu animasikan **harus memiliki satu elemen root saja**. Halaman atau *layout* dengan banyak elemen root (*fragment*) tidak bisa dianimasikan, jadi transisinya tidak akan berjalan dan navigasi antar *route* bisa mengalami error. Nuxt akan memberikan peringatan soal ini di mode pengembangan. Bungkuslah *template*-mu di dalam satu elemen root (misalnya sebuah `<div>`).
::

## Transisi Halaman (*Page Transitions*)

Kamu bisa mengaktifkan *page transition* untuk menerapkan transisi otomatis di semua [halamanmu](/nuxt/directory-structure/app/pages).

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'page', mode: 'out-in' },
  },
})
```

::note
Kalau kamu mengganti *layout* sekaligus halaman, *page transition* yang kamu atur di sini tidak akan berjalan. Sebagai gantinya, kamu harus mengatur [*layout transition*](/nuxt/getting-started/transitions#layout-transitions).
::

Untuk mulai menambahkan transisi di antara halaman-halamanmu, tambahkan CSS berikut ke [`app.vue`](/nuxt/directory-structure/app/app)-mu:

::code-group

```vue [app/app.vue]
<template>
  <NuxtPage />
</template>

<style>
.page-enter-active,
.page-leave-active {
  transition: all 0.4s;
}
.page-enter-from,
.page-leave-to {
  opacity: 0;
  filter: blur(1rem);
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Home page</h1>
    <NuxtLink to="/about">About page</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <div>
    <h1>About page</h1>
    <NuxtLink to="/">Home page</NuxtLink>
  </div>
</template>
```

## Transisi Layout (*Layout Transitions*)

Kamu bisa mengaktifkan *layout transition* untuk menerapkan transisi otomatis di semua [*layout*mu](/nuxt/directory-structure/app/layouts).

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    layoutTransition: { name: 'layout', mode: 'out-in' },
  },
})
```

Untuk mulai menambahkan transisi di antara halaman dan *layout*mu, tambahkan CSS berikut ke [`app.vue`](/nuxt/directory-structure/app/app)-mu:

::code-group

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>

<style>
.layout-enter-active,
.layout-leave-active {
  transition: all 0.4s;
}
.layout-enter-from,
.layout-leave-to {
  filter: grayscale(1);
}
</style>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <pre>default layout</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: lightgreen;
}
</style>
```

```vue [app/layouts/orange.vue]
<template>
  <div>
    <pre>orange layout</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: #eebb90;
  padding: 20px;
  height: 100vh;
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Home page</h1>
    <NuxtLink to="/about">About page</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'orange',
})
</script>

<template>
  <div>
    <h1>About page</h1>
    <NuxtLink to="/">Home page</NuxtLink>
  </div>
</template>
```

## Pengaturan Global

Kamu bisa mengkustomisasi nama transisi bawaan ini secara global melalui `nuxt.config`.

Kedua kunci `pageTransition` dan `layoutTransition` menerima [`TransitionProps`](https://vuejs.org/api/built-in-components#transition) sebagai nilai yang bisa diserialisasi ke JSON, di mana kamu bisa memberikan `name`, `mode`, dan *transition-props* valid lainnya dari transisi CSS kustommu.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: {
      name: 'fade',
      mode: 'out-in', // bawaan
    },
    layoutTransition: {
      name: 'slide',
      mode: 'out-in', // bawaan
    },
  },
})
```

::warning
Kalau kamu mengubah properti `name`, kamu juga harus mengubah nama kelas CSS-nya sesuai dengan yang baru.
::

Untuk menimpa properti transisi global, gunakan `definePageMeta` untuk mendefinisikan transisi halaman atau *layout* pada satu halaman Nuxt tertentu. Ini akan menimpa transisi halaman atau *layout* apa pun yang sudah didefinisikan secara global di file `nuxt.config`.

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'bounce',
    mode: 'out-in', // bawaan
  },
})
</script>
```

## Menonaktifkan Transisi

`pageTransition` dan `layoutTransition` bisa dinonaktifkan untuk *route* tertentu:

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: false,
  layoutTransition: false,
})
</script>
```

Atau secara global di `nuxt.config`:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: false,
    layoutTransition: false,
  },
})
```

## JavaScript Hooks

Untuk kasus penggunaan yang lebih lanjut, kamu bisa memakai *JavaScript hooks* untuk membuat transisi yang sangat dinamis dan kustom untuk halaman Nuxt-mu.

Cara ini sangat cocok untuk kasus penggunaan *library* animasi JavaScript seperti [GSAP](https://gsap.com).

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'custom-flip',
    mode: 'out-in',
    onBeforeEnter: (el) => {
      console.log('Sebelum masuk...')
    },
    onEnter: (el, done) => {},
    onAfterEnter: (el) => {},
  },
})
</script>
```

::tip
Pelajari lebih lanjut tentang [*JavaScript hooks* tambahan](https://vuejs.org/guide/built-ins/transition#javascript-hooks) yang tersedia di komponen `Transition`.
::

## Transisi Dinamis

Untuk menerapkan transisi dinamis menggunakan logika kondisional, kamu bisa memanfaatkan [*middleware inline*](/nuxt/directory-structure/app/middleware) untuk menetapkan nama transisi yang berbeda ke `to.meta.pageTransition`.

::code-group

```vue twoslash [pages/[id\\].vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'slide-right',
    mode: 'out-in',
  },
  middleware (to, from) {
    if (to.meta.pageTransition && typeof to.meta.pageTransition !== 'boolean') {
      to.meta.pageTransition.name = +to.params.id! > +from.params.id! ? 'slide-left' : 'slide-right'
    }
  },
})
</script>

<template>
  <h1>#{{ $route.params.id }}</h1>
</template>

<style>
.slide-left-enter-active,
.slide-left-leave-active,
.slide-right-enter-active,
.slide-right-leave-active {
  transition: all 0.2s;
}
.slide-left-enter-from {
  opacity: 0;
  transform: translate(50px, 0);
}
.slide-left-leave-to {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-enter-from {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-leave-to {
  opacity: 0;
  transform: translate(50px, 0);
}
</style>
```

```vue [app/layouts/default.vue]
<script setup lang="ts">
const route = useRoute()
const id = computed(() => Number(route.params.id || 1))
const prev = computed(() => '/' + (id.value - 1))
const next = computed(() => '/' + (id.value + 1))
</script>

<template>
  <div>
    <slot />
    <div v-if="$route.params.id">
      <NuxtLink :to="prev">⬅️</NuxtLink> |
      <NuxtLink :to="next">➡️</NuxtLink>
    </div>
  </div>
</template>
```

::

Sekarang, halaman tersebut akan menerapkan transisi `slide-left` saat berpindah ke *id* selanjutnya, dan `slide-right` untuk *id* sebelumnya:

## Transisi dengan NuxtPage

Ketika `<NuxtPage />` dipakai di `app.vue`, transisi bisa dikonfigurasi dengan prop `transition` untuk mengaktifkannya secara global.

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage
        :transition="{
          name: 'bounce',
          mode: 'out-in',
        }"
      />
    </NuxtLayout>
  </div>
</template>
```

::note
Ingat, *page transition* ini tidak bisa ditimpa menggunakan `definePageMeta` di masing-masing halaman.
::

## View Transitions API (Eksperimental)

Nuxt sudah dibekali dengan implementasi eksperimental dari [**View Transitions API**](https://developer.chrome.com/docs/web-platform/view-transitions) (lihat [MDN](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)). Ini adalah cara baru yang menarik untuk mengimplementasikan transisi bawaan peramban yang (antara lain) memiliki kemampuan untuk bertransisi antar elemen yang tidak terkait di halaman yang berbeda.

Kamu bisa lihat demonya [di StackBlitz](https://stackblitz.com/edit/nuxt-view-transitions).

Integrasi Nuxt ini bisa diaktifkan melalui opsi `experimental.viewTransition` di file konfigurasimu:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  experimental: {
    viewTransition: true,
  },
})
```

Nilai yang bisa dipakai adalah: `false`, `true`, atau `'always'`.

Kalau diatur `true`, Nuxt tidak akan menerapkan transisi jika peramban pengguna mencocoki `prefers-reduced-motion: reduce` (ini yang direkomendasikan). Kalau diatur `always`, Nuxt akan selalu menerapkan transisi dan terserah kamu untuk menghormati preferensi pengguna.

Secara bawaan, *view transitions* diaktifkan untuk semua [halaman](/nuxt/directory-structure/app/pages), tapi kamu bisa mengatur *default* global yang berbeda.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    // Nonaktifkan view transitions secara global, dan aktifkan per halaman
    viewTransition: false,
  },
})
```

Kamu bisa menimpa nilai `viewTransition` bawaan untuk suatu halaman dengan mengatur kunci `viewTransition` di dalam [`definePageMeta`](/nuxt/api/utils/define-page-meta) halaman tersebut:

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: false,
})
</script>
```

::warning
Menimpa *view transitions* per halaman hanya akan berpengaruh kalau kamu sudah mengaktifkan opsi `experimental.viewTransition`.
::

### Tipe View Transition :badge[v4.4]{color="info" size="xs" class="align-middle"}

[*View transition types*](https://developer.chrome.com/blog/view-transitions-update-io24#view-transition-types) memungkinkanmu menerapkan animasi CSS yang berbeda tergantung pada jenis navigasinya. Ini berguna untuk membuat transisi asimetris (misalnya, animasi yang berbeda saat menavigasi ke depan vs. ke belakang).

*Type* diatur pada [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) dan bisa ditargetkan di CSS menggunakan *pseudo-class selector* [`:active-view-transition-type()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:active-view-transition-type).

Kamu bisa mengatur *type* bawaan secara global di `nuxt.config.ts`-mu:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    viewTransition: {
      enabled: true,
      types: ['slide'],
    },
  },
})
```

Atau konfigurasi *type* per halaman menggunakan `definePageMeta`. *Type* per halaman mendukung baik *array* statis maupun fungsi untuk perilaku dinamis:

```vue twoslash [pages/detail.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    // Type yang diterapkan ke transisi apa pun yang melibatkan halaman ini
    types: ['slide'],
    // Type yang diterapkan hanya saat menavigasi KE halaman ini
    toTypes: ['slide-in'],
    // Type yang diterapkan hanya saat menavigasi DARI halaman ini
    fromTypes: ['slide-out'],
  },
})
</script>
```

Kamu juga bisa memakai fungsi untuk `types`, `toTypes`, dan `fromTypes` di `definePageMeta` untuk menentukan *type* secara dinamis berdasarkan *route*-nya:

```vue twoslash [pages/[id].vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    toTypes: (to, from) => {
      // Geser ke kiri saat menuju ID yang lebih tinggi, sebaliknya geser ke kanan
      return Number(to.params.id) > Number(from.params.id)
        ? ['slide-left']
        : ['slide-right']
    },
  },
})
</script>
```

Lalu, targetkan *type*-type tersebut di CSS-mu:

```css
/* Crossfade bawaan */
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 0.3s;
}

/* Animasi geser ke kiri */
html:active-view-transition-type(slide-left) {
  &::view-transition-old(root) {
    animation: slide-out-left 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-right 0.3s ease-in-out;
  }
}

/* Animasi geser ke kanan */
html:active-view-transition-type(slide-right) {
  &::view-transition-old(root) {
    animation: slide-out-right 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-left 0.3s ease-in-out;
  }
}
```

::note
Nilai fungsi untuk `types`, `toTypes`, dan `fromTypes` hanya bisa bekerja di `definePageMeta`, dan tidak bisa di `nuxt.config.ts` (di mana hanya `string[]` statis yang didukung).
::

*Hook* `page:view-transition:start` memberikan akses ke objek [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition), yang menyertakan properti [`types`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition/types) (`ViewTransitionTypeSet`) yang bisa dibaca atau dimodifikasi saat *runtime*:

```ts [plugins/view-transition.client.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('page:view-transition:start', (transition) => {
    // Baca atau modifikasi types saat runtime
    console.log([...transition.types])
  })
})
```

Kalau kamu juga memakai transisi Vue seperti `pageTransition` dan `layoutTransition` (lihat di atas) untuk mencapai hasil yang sama dengan *View Transitions API* yang baru, kamu mungkin ingin _menonaktifkan_ transisi Vue kalau peramban pengguna mendukung *web API* native yang lebih baru. Kamu bisa melakukannya dengan membuat file `~/middleware/disable-vue-transitions.global.ts` yang isinya seperti ini:

```ts
export default defineNuxtRouteMiddleware((to) => {
  if (import.meta.server || !document.startViewTransition) {
    return
  }

  // Nonaktifkan transisi Vue bawaan
  to.meta.pageTransition = false
  to.meta.layoutTransition = false
})
```

### Masalah yang Diketahui (*Known Issues*)

- Kalau kamu melakukan pengambilan data di dalam fungsi *setup* halamanmu, mungkin kamu perlu mempertimbangkan kembali penggunaan fitur ini untuk saat ini. (Berdasarkan desainnya, *View Transitions* akan membekukan pembaruan DOM sepenuhnya saat transisi sedang berlangsung.) Kami sedang melihat kemungkinan untuk membatasi *View Transition* hanya pada momen-momen akhir sebelum `<Suspense>` selesai (*resolve*), tapi untuk sementara ini, kamu mungkin ingin mempertimbangkan dengan matang apakah akan mengadopsi fitur ini kalau kondisinya seperti yang aku sebutkan tadi.
