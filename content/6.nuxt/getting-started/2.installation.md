## Proyek Baru

<steps>

### Prasyarat

- **Node.js** - Versi [`22.x`](https://nodejs.org/en) atau yang lebih baru (tapi kami menyarankan untuk pakai [rilis *Active LTS*](https://github.com/nodejs/release#release-schedule)).
- **Editor teks** - Sebenarnya bebas pakai IDE apa saja, tapi kami merekomendasikan [Visual Studio Code](https://code.visualstudio.com/) yang sudah dipasangi [ekstensi Vue resmi](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (dulu namanya Volar) atau [WebStorm](https://www.jetbrains.com/webstorm/). WebStorm beserta [IDE JetBrains lainnya](https://www.jetbrains.com/ides/) sudah mendukung Nuxt dengan sangat baik langsung di dalamnya (*out-of-the-box*). Kalau kamu pakai editor lain seperti Neovim, kamu bisa mengatur dukungan [Vue Language Server](https://github.com/vuejs/language-tools) dengan mengikuti [panduan *setup* Vue Language Tools](https://github.com/vuejs/language-tools/wiki).
- **Terminal** - Untuk menjalankan perintah-perintah Nuxt nantinya.

<callout>

::collapsible
#title 
catatan tambahan untuk setup yang optimal

#content
**Node.js**: Pastikan kamu memakai versi bernomor genap (22, 24, dst.).

- **Neovim**: Saat mengonfigurasi plugin Vue TypeScript, pastikan bagian `location` menunjuk ke direktori paket `@vue/language-server`, bukan ke *binary*-nya. Cek [panduan *setup* Neovim](https://github.com/vuejs/language-tools/wiki/Neovim) untuk contoh konfigurasi yang bisa langsung dipakai.

- **WSL**: Kalau kamu pengguna Windows dan merasa HMR-nya lambat, coba deh pakai [WSL (Windows Subsystem for Linux)](https://learn.microsoft.com/en-us/windows/wsl/install). Cara ini biasanya bisa mengatasi masalah performa tersebut.

**Resolusi DNS lambat di Windows**: Alih-alih memakai `localhost:3000` untuk *local dev server* di Windows, gunakan saja `127.0.0.1` supaya proses muatnya di peramban jadi jauh lebih cepat.
::collapsible

</callout>

### Membuat Proyek Baru

Buka terminal kamu (kalau kamu pakai [Visual Studio Code](https://code.visualstudio.com), kamu bisa buka [terminal terintegrasi](https://code.visualstudio.com/docs/terminal/basics) di dalamnya), lalu aku sarankan untuk menjalankan perintah berikut guna membuat proyek *starter* baru:

<code-group sync="pm">

```bash [npm]
npm create nuxt@latest <project-name>
```

```bash [yarn]
yarn create nuxt <project-name>
```

```bash [pnpm]
pnpm create nuxt@latest <project-name>
```

```bash [bun]
bun create nuxt@latest <project-name>
```

```bash [deno]
deno -A npm:create-nuxt@latest <project-name>
```

</code-group>

Buka folder proyekmu di Visual Studio Code:

```bash [Terminal]
code <project-name>
```

Atau, pindah ke direktori proyek barumu lewat terminal:

```bash
cd <project-name>
```

### Server Pengembangan

Sekarang, aku akan tunjukkan cara menjalankan aplikasi Nuxt-mu dalam mode pengembangan:

<code-group sync="pm">

```bash [npm]
npm run dev -- -o
```

```bash [yarn]
yarn dev --open
```

```bash [pnpm]
pnpm dev -o
```

```bash [bun]
bun run dev -o

# Untuk menggunakan runtime Bun saat pengembangan
# bun --bun run dev -o
```

```bash [deno]
deno run dev -o
```

</code-group>

<tip icon="i-lucide-circle-check">

Kerja bagus! Secara otomatis, jendela peramban akan terbuka menuju [http://localhost:3000](http://localhost:3000).

</tip>

<tip icon="i-lucide-container">

Kalau kamu memakai Docker atau butuh lingkungan pengembangan yang konsisten di berbagai mesin, pertimbangkan untuk menggunakan *dev container*.

[Pelajari lebih lanjut tentang *dev containers*](/docs/4.x/guide/best-practices/devcontainers)

</tip>
</steps>
