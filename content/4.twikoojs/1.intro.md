## Fitur

### Sederhana

* Bisa dipakai gratis (menggunakan cloud development / Vercel /Server sendiri untuk backend komentar)
* Mudah dipasang (mendukung one-click deploy di cloud development atau Vercel)

### Mudah Dipakai

* Mendukung balasan dan suka ( like )
* Otomatis cocok dengan tema terang maupun gelap, tanpa konfigurasi tambahan
* Menyediakan API untuk mengambil jumlah komentar per artikel atau komentar terbaru secara batch
* Pengunjung cukup masukkan nomor QQ di kolom nama, akan otomatis terisi nama QQ dan email QQ
* Jika mengisi email berupa angka (QQ email), avatar komentar akan menggunakan foto profil QQ
* Bisa tempel gambar langsung di kotak komentar (bisa dinonaktifkan)
* Bisa sisipkan gambar (bisa dinonaktifkan juga)
* Mendukung upload ke Qiniu image hosting atau cloud development image hosting
* Bisa pakai emoji (bisa dinonaktifkan)
* Dukungan pintasan `Ctrl + Enter` untuk kirim komentar cepat
* Isi kotak komentar otomatis tersimpan sebagai draft, tidak hilang meski di-refresh
* [Mendukung rumus KaTeX](https://twikoo.js.org/faq.html#%E5%A6%82%E4%BD%95%E5%90%AF%E7%94%A8-katex-%E6%94%AF%E6%8C%81)
* Pewarnaan sintaks kode sesuai bahasa pemrograman

### Aman

* Data pribadi terjaga (melalui cloud function, field sensitif seperti email, IP, konfigurasi lingkungan, dll. tidak bocor)
* Mendukung deteksi komentar spam dengan Akismet (daftar sendiri di [akismet.com](https://akismet.com/))
* Mendukung deteksi spam dengan Tencent Cloud Content Security (daftar sendiri di [Tencent Cloud CMS](https://console.cloud.tencent.com/cms/text/overview))
* Mendukung mode moderasi manual (komentar ditahan dulu)
* Perlindungan terhadap serangan XSS
* Bisa batasi jumlah komentar per IP dalam 10 menit

### Real-time

* Notifikasi via email (untuk pengunjung dan admin)
* Notifikasi WeChat (khusus admin, menggunakan [Server酱](https://sc.ftqq.com/3.version), daftar sendiri)
* Notifikasi QQ (khusus admin, menggunakan [Qmsg酱](https://qmsg.zendee.cn/), daftar sendiri)

### Kustomisasi

* Bisa pasang gambar latar di kotak komentar
* Bisa ubah label "博主" (admin) sesuai keinginan
* Bisa ubah template email notifikasi
* Bisa ubah teks placeholder di kotak komentar
* Bisa ubah daftar emoji (kompatibel dengan [format data OwO](https://cdn.jsdelivr.net/npm/owo@1.0.2/demo/OwO.json))
* Bisa atur kolom 【Nama】【Email】【Website】wajib diisi atau tidak
* Bisa pilih tema pewarnaan sintaks sesuai selera

### Mudah Dikelola

* Panel admin terintegrasi, login dengan password, bisa lihat, sembunyikan, hapus komentar, dan ubah konfigurasi dengan mudah
* Bisa sembunyikan pintu masuk admin, muncul dengan memasukkan kata sandi rahasia
* Bisa impor komentar dari Valine, Artalk, atau Disqus

### Kekurangan

* Tidak mendukung Internet Explorer
