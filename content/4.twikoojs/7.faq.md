## Bagaimana cara mengubah foto profil?

Silakan kunjungi [https://weavatar.com](https://weavatar.com) untuk mendaftar dengan email dan mengatur foto profil. Saat berkomentar, gunakan email yang sama.

Pengunjung juga dapat menggunakan avatar QQ dengan memasukkan alamat email QQ berupa angka.

## Bagaimana cara mengubah atau mereset kata sandi admin?

Untuk Tencent Cloud, buka [Konsol Cloud Development](https://console.cloud.tencent.com/tcb/database/collection/config). Untuk Vercel, buka MongoDB. Untuk deploy privat, edit langsung file `data/db.json.1`, hapus item konfigurasi `config.ADMIN_PASS`, lalu buka panel admin Twikoo dan atur ulang kata sandi.

## Bagaimana cara mendapatkan file kunci privat untuk panel admin?

1. Masuk ke [Lingkungan - Otorisasi Login](https://console.cloud.tencent.com/tcb/env/login), klik "Unduh Kunci Privat" di sebelah kanan "Login Kustom".
2. Buka file kunci privat dengan editor teks, salin seluruh isinya.
3. Klik ikon "Roda Gigi Kecil" di jendela komentar, tempelkan isi file kunci privat, dan atur kata sandi admin.

## Lupa kode rahasia, bagaimana cara masuk ke panel admin?

Di halaman yang berisi kotak komentar, buka alat pengembang browser (pintasan F12 di Windows), klik tab Network, muat ulang halaman, klik ikon kaca pembesar (Search), di kolom pencarian yang muncul masukkan `HIDE_ADMIN_CRYPT`, klik ikon refresh di samping kolom pencarian (Refresh), maka Anda akan menemukan kode rahasia Anda.

![](https://twikoo.js.org/assets/faq-1.CGQdkUsI.png)

Perlu diperhatikan, kode rahasia bukanlah metode enkripsi untuk panel admin, hanya digunakan untuk menyembunyikan panel admin dari pengunjung biasa. Jangan gunakan string yang sama untuk kode rahasia dan kata sandi panel admin.

## Bagaimana cara mengaktifkan statistik jumlah pengunjung artikel?

Anda dapat menambahkan kode berikut di tempat yang ingin menampilkan jumlah pengunjung artikel:

``` html
<span id="twikoo_visitors">0</span>
```

Untuk menampilkan jumlah pengunjung. Statistik jumlah pengunjung seluruh situs belum didukung.

## Bagaimana cara mengaktifkan dukungan Katex?

Twikoo mendukung formula Katex, tetapi untuk membatasi ukuran paket Twikoo, Twikoo tidak menyertakan Katex lengkap secara bawaan. Anda perlu [memuat katex.js secara terpisah di halaman](https://katex.org/docs/browser.html).

``` html
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.12.0/dist/katex.min.css" integrity="sha384-AfEj0r4/OFrOo5t7NnNe46zW/tFgW6x/bCJG8FqQCEo3+Aro6EYUG4+cU+KJWu/X" crossorigin="anonymous">
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.12.0/dist/katex.min.js" integrity="sha384-g7c+Jr9ZivxKLnZTDUhnkOnsh30B4H0rpLUpJ4jAIKs4fnJI+sEnkvrMWph2EDg4" crossorigin="anonymous"></script>
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.12.0/dist/contrib/auto-render.min.js" integrity="sha384-mll67QQFJfxn0IYznZYonOWZ644AWYC+Pt2cHqMaRhXVrursRwvLnLaebdGIlYNa" crossorigin="anonymous"></script>
</head>
```

Setelah dimuat, Anda dapat mengirim `$$c = \pm\sqrt{a^2 + b^2}$$` untuk menguji efeknya.

![katex](https://twikoo.js.org/assets/katex.D3zUHQ6F.png)

Anda juga dapat mengirimkan konfigurasi katex kustom saat `twikoo.init`, untuk konfigurasi detail silakan lihat [Katex Auto-render Extension](https://katex.org/docs/autorender.html).

``` js
twikoo.init({
  envId: 'ID lingkungan Anda',
  el: '#tcomment',
  katex: {
    delimiters: [
      { left: '$$', right: '$$', display: true },
      { left: '$', right: '$', display: false },
      { left: '\\(', right: '\\)', display: false },
      { left: '\\[', right: '\\]', display: true }
    ],
    throwOnError: false
  }
});
```

## Bagaimana cara mengonfigurasi anti-spam?

### Menggunakan Layanan Keamanan Konten Tencent Cloud

Twikoo mendukung integrasi dengan deteksi konten teks Tencent Cloud, menggunakan teknologi pembelajaran mendalam untuk mengidentifikasi konten berbahaya seperti pornografi, politik sensitif, terorisme, serta mendukung konfigurasi kamus kata kustom untuk menangani teks yang melanggar aturan.

Layanan deteksi konten teks Tencent Cloud adalah layanan berbayar, menyediakan uji coba gratis selama 1 bulan, dengan harga setelahnya 25 yuan per 10.000 item. Jika Anda tidak memerlukan anti-spam yang ketat, Anda juga dapat menggunakan Akismet gratis.

Cara mengajukan layanan deteksi konten teks Tencent Cloud:

1. Kunjungi [Konsol Tencent Cloud - Keamanan Konten Teks](https://console.cloud.tencent.com/cms/text/overview), aktifkan layanan keamanan konten teks.
2. Kunjungi [Konsol Tencent Cloud - Daftar Pengguna](https://console.cloud.tencent.com/cam), klik Buat Pengguna Baru, klik Buat Cepat.
3. Masukkan nama pengguna, pilih "Akses Pemrograman" sebagai metode akses, hapus "AdministratorAccess" pada izin pengguna, dan hanya centang "QcloudTMSFullAccess".
4. Klik "Buat Pengguna".
5. Salin "SecretId" dan "SecretKey" dari halaman "Berhasil Membuat Pengguna Baru", dan konfigurasikan di modul "Anti-Spam" panel admin Twikoo.
6. Uji efek anti-spam.

Setelah berhasil, admin dapat mengonfigurasi filter konten teks kustom di [Konsol Tencent Cloud - Manajemen Kamus Kustom](https://console.cloud.tencent.com/cms/text/lib).

### Menggunakan Layanan Anti-Spam Akismet

Akismet (Automattic Kismet) adalah sistem filtrasi komentar spam yang banyak digunakan, dibuat oleh pendiri WordPress yang terkenal, Matt Mullenweg. Akismet juga merupakan plugin bawaan WordPress, sangat populer, dan dirancang untuk membantu situs blog memfilter komentar spam.

1. Daftar di [akismet.com](https://akismet.com).
2. Pilih langganan Akismet Personal, salin Akismet API Key yang diperoleh, dan konfigurasikan di modul "Anti-Spam" panel admin Twikoo.

### Bagaimana cara menguji apakah konfigurasi Akismet berfungsi?

Isi `viagra-test-123` sebagai nama panggilan, atau `akismet-guaranteed-spam@example.com` sebagai email, lalu kirim komentar. Komentar ini pasti akan dianggap sebagai komentar spam.

Perlu diperhatikan, karena layanan Akismet merespons agak lambat (sekitar 6 detik) yang mempengaruhi pengalaman pengguna, Twikoo menerapkan strategi "izinkan dulu, periksa kemudian", sehingga komentar spam akan terlihat sebentar setelah diposting.

### Mengonfigurasi Layanan Anti-Spam dengan LLM

Gunakan API yang kompatibel dengan [OpenAI SDK](https://www.npmjs.com/package/openai) (seperti DeepSeek, OpenAI, dll.) untuk mendeteksi komentar spam secara lebih cerdas. Admin dapat menyesuaikan prompt untuk mendefinisikan apa yang dimaksud dengan "komentar spam".

- `LLM_API_KEY`: Masukkan kunci API Anda.
- `LLM_API_ENDPOINT`: Masukkan alamat endpoint API (default `https://api.deepseek.com`).
- `LLM_MODEL`: Masukkan nama model (default `deepseek-v4-pro`).
- `LLM_MAX_RETRIES`: Jumlah maksimum percobaan ulang deteksi LLM (default 3 kali).

**(Opsional)** Konfigurasikan `LLM_SPAM_PROMPT`: Prompt kustom.

## Mengalami error AUTH_INVALID_CUSTOM_LOGIN_TICKET saat login panel admin

Biasanya terjadi setelah mengonfigurasi kunci privat login, lalu mengunduh ulang kunci privat login, menyebabkan kunci privat login yang dikonfigurasi sebelumnya menjadi tidak berlaku.<br>
Solusi: Buka [Konsol Cloud Development](https://console.cloud.tencent.com/tcb/database/collection/config), database, hapus config, lalu konfigurasi ulang kunci privat.

## Tidak menerima email notifikasi?

Jika menggunakan fungsi cloud di Vercel, konfigurasikan penyedia email internasional untuk menghindari dianggap sebagai spam oleh penyedia email. Jika karena alasan lain, buka panel admin Twikoo, temukan fitur uji email, masukkan email pribadi, dan periksa penyebabnya berdasarkan hasil uji.

Jika menggunakan fungsi cloud di Vercel, uji email berhasil, tetapi tidak menerima notifikasi instan / email untuk komentar yang sebenarnya, buka halaman manajemen fungsi cloud Vercel, masuk ke Settings - Deployment Protection, atur Vercel Authentication menjadi Disabled, lalu Save.

![](https://twikoo.js.org/assets/vercel-1.Czytea8u.png)

Untuk menghindari masalah kinerja akibat pengecekan email yang terlalu sering, konfigurasi email memiliki cache sekitar 10 menit. Jika yakin konfigurasi sudah benar tetapi uji gagal, tunggu 10 menit lalu uji kembali.

Karena admin tidak akan menerima notifikasi saat memposting komentar sendiri, jika Anda ingin menguji fungsi notifikasi secara nyata, logout dari panel admin lalu gunakan email non-admin untuk memposting atau membalas komentar.

## Tidak bisa mengunggah gambar di Vercel atau deploy privat?

Lingkungan Tencent Cloud menyediakan penyimpanan cloud sendiri, sehingga di lingkungan Tencent Cloud gambar dapat langsung diunggah dan disimpan di penyimpanan cloud. Namun lingkungan Vercel tidak memiliki fitur ini, fungsi unggah gambar bergantung pada layanan penyimpanan gambar pihak ketiga. Silakan konfigurasikan penyimpanan gambar di panel admin. Twikoo mendukung penyimpanan gambar berikut:

| Penyimpanan Gambar | Alamat | Karakteristik |
| ---- | ---- | ---- |
| qcloud | Tidak ada | Bawaan lingkungan Tencent Cloud, dapat dilihat di Cloud Development - Cloud Storage |
| 7bu | https://7bu.top | Penyimpanan gambar Qubu, didukung oleh Du Laoshi, tidak ada paket gratis |
| see | https://s.ee | Penyimpanan gambar S.EE, tersedia paket gratis, daftar akun sendiri, `IMAGE_CDN_TOKEN` dapat diperoleh di [Dashboard](https://s.ee/user/developers/) |
| [lsky-pro](https://www.lsky.pro) | Deploy privat | Versi 2.0 Lankong Gambar, `IMAGE_CDN` konfigurasikan alamat URL beranda penyimpanan gambar (misal `https://7bu.top`), cara mendapatkan `IMAGE_CDN_TOKEN` silakan merujuk tutorial [Du Laoshi Shuo Tuchuang: Cara Mendapatkan dan Menghapus Token Versi Baru Qubu Tuchuang](https://dusays.com/454/), format token yang didapat harus `1\|1bJbwlqBfnggmOMEZqXT5XusaIwqiZjCDs7r1Ob5` |

| [Chevereto](https://chevereto.com) | Deploy privat | Versi Chevereto v4, `IMAGE_CDN_URL` konfigurasikan alamat URL penyimpanan gambar (misal `https://your-chevereto.com`), `IMAGE_CDN_TOKEN` isi API Key (dapatkan di Dashboard admin → Settings → API). ## Apakah deploy privat dapat terhubung ke database sendiri?

Versi deploy privat Twikoo secara default menggunakan database bawaan: LokiJS, dengan kapasitas sekitar 1 GB, tidak perlu terhubung ke database eksternal. Data disimpan di direktori data di bawah direktori tempat twikoo dijalankan. Anda dapat menyalin direktori tersebut untuk mencadangkan data.

Jika Anda memiliki instance MongoDB, Anda dapat menghubungkan MongoDB sebagai database eksternal, cukup konfigurasikan variabel lingkungan MONGODB_URI ke alamat koneksi database, misal: `mongodb://<username>:<password>@<host>/`.

## Setelah deploy, komentar gagal: 0, panel admin tidak bisa masuk?

Di halaman yang berisi kotak komentar, buka alat pengembang browser (pintasan F12 di Windows), klik tab Console, cari error yang mengandung kata kunci twikoo.

Jika melihat ERR_BLOCKED_BY_CLIENT, nonaktifkan plugin pemblokir iklan browser atau tambahkan situs saat ini ke daftar putih, lalu refresh dan coba lagi.

Jika melihat ERR_CONNECTION_CLOSED / ERR_CONNECTION_TIMED_OUT / ERR_CONNECTION_RESET, periksa apakah lingkungan jaringan di wilayah Anda normal dan dapat terhubung ke fungsi cloud. Beberapa wilayah tidak dapat mengakses layanan seperti Vercel, coba ganti metode deploy.

Jika melihat `Access to XMLHttpRequest at 'https://tcb-api.tencentcloudapi.com/web?env=...' from origin '...' has been blocked by CORS policy...`: periksa apakah versi file js frontend terbaru, dan pastikan envId diawali dengan `https://`.

Jika melihat `Access to XMLHttpRequest at ... No 'Access-Control-Allow-Origin' header is present on the requested resource.`: coba akses envId untuk melihat apakah fungsi cloud berjalan normal. Jika tidak ada indikasi berjalan normal, deploy ulang fungsi cloud, pastikan tidak ada langkah yang terlewat. Jika indikasi berjalan normal, jalankan situs secara lokal (localhost) dan akses panel admin - Manajemen Konfigurasi - Umum, kosongkan kolom `CORS_ALLOW_ORIGIN` dan simpan, lalu refresh dan coba lagi.

Jika melihat error lain, silakan [ajukan issue](https://github.com/twikoojs/twikoo/issues/new) dengan menyertakan informasi error.
