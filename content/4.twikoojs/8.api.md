Melalui API Twikoo, pengembang tema dapat mengimplementasikan beberapa fungsi khusus, misalnya: menampilkan jumlah komentar artikel di daftar artikel, menampilkan komentar terbaru di beranda, dll.

Sebelum memanggil API Twikoo, **tidak perlu** menjalankan `twikoo.init()`.

## Mendapatkan Jumlah Komentar

Mendapatkan jumlah komentar beberapa artikel secara batch.

### Versi

`>= 0.2.7`

### Contoh

``` js
twikoo.getCommentsCount({
  envId: 'ID lingkungan Anda', // ID lingkungan
  // region: 'ap-guangzhou', // Wilayah lingkungan, default ap-shanghai, jika wilayah lingkungan Anda bukan Shanghai, kirim parameter ini
  urls: [ // Daftar jalur artikel tanpa protokol, domain, dan parameter, parameter wajib
    '/2020/10/post-1.html',
    '/2020/11/post-2.html',
    '/2020/12/post-3.html'
  ],
  includeReply: false // Apakah jumlah komentar termasuk balasan, default: false
}).then(function (res) {
  console.log(res);
  // Contoh output: [
  //   { url: '/2020/10/post-1.html', count: 10 },
  //   { url: '/2020/11/post-2.html', count: 0 },
  //   { url: '/2020/12/post-3.html', count: 20 }
  // ]
}).catch(function (err) {
  // Terjadi error
  console.error(err);
});
```

## Mendapatkan Komentar Terbaru

Mendapatkan komentar terbaru.

### Versi

`>= 0.2.7`

### Contoh

``` js
twikoo.getRecentComments({
  envId: 'ID lingkungan Anda', // ID lingkungan
  // region: 'ap-guangzhou', // Wilayah lingkungan, default ap-shanghai, jika wilayah lingkungan Anda bukan Shanghai, kirim parameter ini
  urls: [ // Memerlukan versi fungsi cloud >= 1.6.27. Daftar jalur artikel tanpa protokol, domain, dan parameter, jika tidak dikirim maka akan mengambil semua komentar terbaru
    '/2020/10/post-1.html',
    '/2020/11/post-2.html',
    '/2020/12/post-3.html'
  ],
  pageSize: 10, // Jumlah yang diambil, default: 10, maksimal: 100
  includeReply: false // Apakah termasuk balasan terbaru, default: false
}).then(function (res) {
  console.log(res);
  // Mengembalikan Array, berisi komentar terbaru dengan:
  //   * id:           ID komentar
  //   * url:          Alamat komentar
  //   * nick:         Nama panggilan
  //   * mailMd5:      Nilai MD5 email, dapat digunakan untuk menampilkan avatar
  //   * link:         Situs web
  //   * comment:      Konten komentar dalam format HTML
  //   * commentText:  Konten komentar dalam format teks biasa
  //   * created:      Waktu komentar, format timestamp milidetik
  //   * avatar:       Alamat avatar (ditambahkan di 0.2.9)
  //   * relativeTime: Waktu relatif komentar, misal "1 jam yang lalu" (ditambahkan di 0.2.9)
  // Contoh output: [ // Urutan dari terbaru ke terlama
  //   { id: '', url: '', nick: '', mailMd5: '', link: '', comment: '', commentText: '', created: 0 },
  //   { id: '', url: '', nick: '', mailMd5: '', link: '', comment: '', commentText: '', created: 0 },
  //   { id: '', url: '', nick: '', mailMd5: '', link: '', comment: '', commentText: '', created: 0 }
  // ]
}).catch(function (err) {
  // Terjadi error
  console.error(err);
});
```

## Saat Twikoo Dimuat

Fungsi balik (callback) setelah Twikoo berhasil dipasang.<br>
Tidak akan dipicu jika terjadi kesalahan ID lingkungan, gangguan jaringan, atau kegagalan pemasangan.

### Versi

`>= 0.5.2`

### Contoh

``` js
twikoo.init({
  ......
}).then(function () {
  console.log('Twikoo berhasil dimuat');
});
```

## Saat Komentar Dimuat

Fungsi balik setelah komentar berhasil dimuat.<br>
Juga akan dipicu saat komentar otomatis diperbarui setelah mengirim komentar, atau saat memuat halaman komentar berikutnya.<br>
Tidak akan dipicu jika pemuatan komentar gagal.

### Versi

`>= 0.5.2`

### Contoh

``` js
twikoo.init({
  ......,
  onCommentLoaded: function () {
    console.log('Komentar berhasil dimuat');
  }
});
```
