## 1. Glosarium Istilah

::tabs
::tabs-item{label="A – J"}
| Istilah | Arti Singkat |
| :--- | :--- |
| **Annotation** | Tanda `@...` di atas class/method/field yang memberi instruksi ke Spring atau compiler |
| **Bean** | Objek yang dibuat dan dikelola oleh Spring IoC Container |
| **Bean Validation** | Spesifikasi validasi Jakarta — `@NotBlank`, `@Email`, dst. |
| **Constructor Injection** | Dependency disuntikkan lewat constructor (cara yang direkomendasikan) |
| **Controller** | Komponen yang menerima HTTP request dan menghasilkan response |
| **CRUD** | Create, Read, Update, Delete — empat operasi dasar data |
| **DTO** | Data Transfer Object — objek khusus untuk membawa data antar lapisan (mis. request/response) |
| **Dependency** | Objek yang dibutuhkan class lain agar bisa bekerja |
| **DI (Dependency Injection)** | Mekanisme Spring menyediakan dependency, bukan kita yang `new` |
| **Entity** | Class Java yang dipetakan ke tabel database |
| **Environment Variable** | Nilai dari lingkungan eksekusi (OS/terminal) yang bisa dipakai sebagai konfigurasi |
| **Hibernate** | Implementasi JPA — ORM yang menerjemahkan objek ↔ SQL |
| **IoC (Inversion of Control)** | Prinsip: framework yang mengontrol pembuatan objek, bukan programmer |
| **JDBC** | API standar Java untuk koneksi database level rendah (driver) |
| **JPA** | Jakarta Persistence API — spesifikasi ORM/standar persistence |
| **JSON** | Format data teks standar pertukaran data di REST API |
::

::tabs-item{label="J – R"}
| Istilah | Arti Singkat |
| :--- | :--- |

| **Maven Wrapper** | Skrip `mvnw` yang membawa Maven versi proyek — tanpa install global |
| **MockMvc** | Alat test Spring MVC tanpa menjalankan server sungguhan |
| **Mockito** | Library membuat mock (tiruan dependency) untuk test |
| **ORM** | Object-Relational Mapping — teknik memetakan objek ↔ tabel |
| **Package** | Namespace Java — `com.example.app`; mengikuti struktur folder |
| **Profile** | Kumpulan konfigurasi per lingkungan (`dev`, `prod`) |
| **Query Method** | Method repository yang query-nya dibuat otomatis dari namanya |
| **REST API** | API berbasis HTTP untuk pertukaran data (umumnya JSON) |

| **Root Package** | Package utama tempat main class — dasar component scanning |

## 2. Kamus Error: Dari Pesan ke Solusi

Format setiap entri: **pesan error** → penyebab → solusi.

::tabs
::tabs-item{label="Compile & Package"}
**`package com.example.belajarspringboot.controller does not exist`**
- **Penyebab:** file berada di folder yang tidak cocok dengan deklarasi `package`-nya, atau import salah tulis
- **Solusi:** cocokkan baris `package` dengan struktur folder; periksa import class yang dipakai

**`cannot find symbol: class HelloService`**
- **Penyebab:** class belum dibuat, salah package, atau import hilang
- **Solusi:** pastikan class ada di lokasi yang benar lalu import sesuai package-nya

**`class UserControl is public, should be declared in a file named UserControl.java`**
- **Penyebab:** nama file ≠ nama public class
- **Solusi:** samakan keduanya
::

::tabs-item{label="Startup Spring"}
**`APPLICATION FAILED TO START — Port 8080 was already in use`**
- **Penyebab:** proses lain (sering: instance Spring lama) memakai port
- **Solusi:** hentikan prosesnya (`netstat -ano | findstr :8080` di Windows / `lsof -i :8080` di Unix) atau ubah `server.port`

**`UnsatisfiedDependencyException / NoSuchBeanDefinitionException`**
- **Penyebab:** Spring tidak menemukan bean untuk dependency — class tidak ber-annotation, atau di luar component scan
- **Solusi:** cek annotation (`@Service`, `@RestController`), dan pastikan class berada **di bawah root package**

**`Failed to configure a DataSource: 'url' attribute is not specified`**
- **Penyebab:** dependency JPA ada, tetapi konfigurasi database tidak terbaca (placeholder tak tergantikan / file properties salah nama)
- **Solusi:** cek `application.properties`, dan default `${DB_URL:...}` untuk placeholder

**`Could not resolve placeholder 'DB_PASSWORD'`**
- **Penyebab:** environment variable tidak ada dan tidak ada default
- **Solusi:** set variabelnya, atau beri default: `${DB_PASSWORD:rahasia}`
::

::tabs-item{label="Database"}
**`Communications link failure`**
- **Penyebab:** MySQL tidak jalan / salah host-port / firewall
- **Solusi:** `docker compose ps` harus *healthy*; cocokkan URL dengan mapping port compose

**`Unknown database 'belajar_spring_boot'`**
- **Penyebab:** container dibuat sebelum `MYSQL_DATABASE` diatur
- **Solusi:** `docker compose down -v && docker compose up -d` (volume di-reset)

**`Access denied for user 'root'@'localhost'`**
- **Penyebab:** password di `application.properties` ≠ `MYSQL_ROOT_PASSWORD` di compose
- **Solusi:** samakan keduanya (jangan lupa healthcheck)

**`Table 'users' doesn't exist`**
- **Penyebab:** entity belum dibuat / `ddl-auto` di-set `none` saat tabel belum ada
- **Solusi:** pastikan `@Entity` ada dan `spring.jpa.hibernate.ddl-auto=update` di development
::

::tabs-item{label="HTTP & Runtime"}
**`404 Not Found` padahal endpoint "sudah dibuat"**
- **Penyebab (urut dari yang sering):** package controller salah → tidak ikut scan; URL salah ketik; aplikasi belum di-restart setelah menambah controller
- **Solusi:** verifikasi package = `com.example.belajarspringboot.controller`, URL persis sama dengan mapping, lalu restart

**`405 Method Not Allowed`**
- **Penyebab:** HTTP method tidak cocok — `POST` ke endpoint `@GetMapping`
- **Solusi:** gunakan method yang benar sesuai mapping

**`415 Unsupported Media Type`**
- **Penyebab:** request body tanpa header `Content-Type: application/json`
- **Solusi:** tambahkan header di API client / curl

**`400 Bad Request` tak terduga saat GET**
- **Penyebab:** `@RequestParam` wajib tidak dikirim
- **Solusi:** kirim parameter `?name=...`, atau beri `defaultValue`

**`500 Internal Server Error` untuk data tidak ditemukan**
- **Penyebab:** `RuntimeException`/exception tak tertangani — handler belum dibuat
- **Solusi:** buat custom exception + `@RestControllerAdvice` (lihat [Bab 10](/spring-boot/validation-dan-error-handling))

**`409 Conflict` saat create**
- **Penyebab:** `existsByEmail` menolak email duplikat — perilaku yang kita rancang
- **Solusi:** bukan bug; gunakan email lain atau tangani di sisi client
::

::tabs-item{label="Testing"}
**Test gagal: `Communications link failure`**
- **Penyebab:** `@SpringBootTest` butuh database, container MySQL mati
- **Solusi:** `docker compose up -d` sebelum `./mvnw test`

**`IllegalStateException: MockMvc is null` / tidak tersedia**
- **Penyebab:** `@AutoConfigureMockMvc` hilang
- **Solusi:** tambahkan annotation tersebut di samping `@SpringBootTest`

**`BUILD FAILURE — Tests run: 1, Failures: 1`**
- **Penyebab:** asertif tidak cocok dengan perilaku aktual — bisa bug kode **atau** ekspektasi test yang keliru
- **Solusi:** baca pesan failure: bandingkan `expected` vs `actual`, putuskan mana yang harus berubah

**Test tidak dijalankan sama sekali**
- **Penyebab:** file di `src/main/java`, atau nama class tidak mengikuti konvensi Surefire (`*Test.java`, `*Tests.java`)
- **Solusi:** pindahkan ke `src/test/java` dan ikuti konvensi penamaan
::
::

## 3. Ritual Debugging 5 Menit

Sebelum panik saat error, jalankan urutan ini — 90% kasus selesai di sini:

```text
1. BACA pesan errornya sampai habis (baris paling atas & paling bawah)
   → error Java menyebut class, baris, dan penyebab

2. Aplikasi/container masih hidup?
   → cek terminal aplikasi & `docker compose ps`

3. Kode persis seperti modul?
   → bandingkan package, annotation, dan import dulu — bukan logikanya

4. Restart: stop aplikasi (Ctrl+C) → jalankan lagi
   → perubahan kode/konfigurasi baru terbaca saat start

5. Kalau masih macet: catat error-nya, cari di dokumentasi resmi
   → docs.spring.io atau issue tracker Spring di GitHub
```

::tip
Keterampilan debugging adalah keterampilan membaca, bukan menebak. Semakin sering membaca pesan error sampai selesai, semakin cepat menemukan polanya.
::
