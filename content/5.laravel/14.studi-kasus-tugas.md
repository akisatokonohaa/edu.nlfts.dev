# Studi Kasus & Praktikum Relasi Database

Pada bab praktikum ini, kita akan menggabungkan seluruh materi yang telah dipelajari dengan membangun modul **Sistem Informasi Siswa dan Kelas** dengan relasi relasional *One-to-Many* (Satu Kelas memiliki Banyak Siswa).

---

## 1. Perancangan Skema Database

Berikut adalah spesifikasi kolom untuk kedua tabel:

```
┌───────────────────────────┐         ┌─────────────────────────────────────┐
│       TABEL KELAS         │         │            TABEL SISWAS             │
├───────────────────────────┤         ├─────────────────────────────────────┤
│ id (PK)                   │ 1     N │ id (PK)                             │
│ nama_kelas (VARCHAR)      │◄────────┤ id_kelas (FK -> kelas.id)           │
│ created_at / updated_at   │         │ nama_lengkap (VARCHAR)              │
└───────────────────────────┘         │ jenis_kelamin (ENUM: l/p)           │
                                      │ tanggal_lahir (DATE)                │
                                      │ tempat_lahir (VARCHAR)              │
                                      │ agama (VARCHAR)                     │
                                      │ alamat (TEXT)                       │
                                      │ email (VARCHAR, UNIQUE)             │
                                      │ created_at / updated_at             │
                                      └─────────────────────────────────────┘
```

## 2. Langkah 1: Membuat File Migrasi

Jalankan perintah Artisan untuk membuat file migrasi kedua tabel:

```bash [Terminal]
php artisan make:migration create_kelas_table
php artisan make:migration create_siswas_table
```

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration

## 3. Langkah 2: Membuat Model & Definisi Relasi

Buat model untuk `Kelas` dan `Siswa`:

```bash [Terminal]
php artisan make:model Kelas
php artisan make:model Siswa
```

::tabs
::tabs-item{label="1. Model Kelas"}
```php [app/Models/Kelas.php]
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Kelas extends Model
{
    use HasFactory;

    protected $table = 'kelas';
    protected $fillable = ['nama_kelas'];

    /**
     * Relasi One-to-Many: Satu kelas memiliki banyak siswa.
     */
    public function siswas(): HasMany
    {
        return $this->hasMany(Siswa::class, 'id_kelas');
    }
}
```
::

::tabs-item{label="2. Model Siswa"}
```php [app/Models/Siswa.php]
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Siswa extends Model
{
    use HasFactory;

    protected $table = 'siswas';
    protected $fillable = [
        'nama_lengkap',
        'jenis_kelamin',
        'tanggal_lahir',
        'tempat_lahir',
        'agama',
        'alamat',
        'email',
        'id_kelas',
    ];

    /**
     * Relasi Inverse: Satu siswa dimiliki oleh satu kelas.
     */
    public function kelas(): BelongsTo
    {
        return $this->belongsTo(Kelas::class, 'id_kelas');
    }
}
```

## 4. Langkah 3: Mengisi Data Dummy dengan Seeder

Buat seeder untuk mengisi data kelas dan siswa secara otomatis:

```bash [Terminal]
php artisan make:seeder SekolahSeeder
```

```php [database/seeders/SekolahSeeder.php]
namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\Kelas;
use App\Models\Siswa;

class SekolahSeeder extends Seeder
{
    public function run(): void
    {
        // 1. Buat Data Kelas
        $kelasRPL1 = Kelas::create(['nama_kelas' => 'XI RPL 1']);
        $kelasRPL2 = Kelas::create(['nama_kelas' => 'XI RPL 2']);

        // 2. Buat Data Siswa
        Siswa::create([
            'nama_lengkap'  => 'Kina SaQina',
            'jenis_kelamin' => 'perempuan',
            'tanggal_lahir' => '2009-06-12',
            'tempat_lahir'  => 'Bandung',
            'agama'         => 'Islam',
            'alamat'        => 'Jl. Buah Batu No. 12, Bandung',
            'email'         => 'kina@example.com',
            'id_kelas'      => $kelasRPL1->id,
        ]);

        Siswa::create([
            'nama_lengkap'  => 'Davin Pratama',
            'jenis_kelamin' => 'laki-laki',
            'tanggal_lahir' => '2008-11-20',
            'tempat_lahir'  => 'Jakarta',
            'agama'         => 'Islam',
            'alamat'        => 'Jl. Sudirman No. 88, Jakarta',
            'email'         => 'davin@example.com',
            'id_kelas'      => $kelasRPL1->id,
        ]);
    }
}
```

Jalankan seeder:
```bash [Terminal]
php artisan db:seed --class=SekolahSeeder
```

## 5. Langkah 4: Menampilkan Data di Route & View Blade

Gunakan teknik **Eager Loading** (`with('kelas')`) untuk menghindari N+1 Query Problem:

```php [routes/web.php]
use App\Models\Siswa;

Route::get('/siswa', function () {
    $daftarSiswa = Siswa::with('kelas')->latest()->get();

    return view('siswa.index', compact('daftarSiswa'));
});
```

Buat tampilan tabel di template Blade:

## 6. Tantangan Latihan Mandiri 🎯

Untuk menguji pemahaman Anda, cobalah beberapa tantangan berikut:

1. **Tambahkan Fitur Tambah Siswa:** Buat formulir untuk menambahkan data siswa baru beserta dropdown pilihan kelas.
2. **Filter Berdasarkan Kelas:** Buat rute `/kelas/{id}/siswa` untuk menampilkan siswa yang hanya berada di kelas tertentu.
3. **Validasi Form Request:** Buat Form Request khusus (`php artisan make:request StoreSiswaRequest`) untuk memvalidasi kolom email agar unik dan tanggal lahir tidak boleh di masa depan.
