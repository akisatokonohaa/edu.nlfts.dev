**Blade Components** adalah fitur bawaan Laravel yang memungkinkan pengembang memecah antarmuka pengguna (*UI* ) menjadi potongan-potongan komponen kecil yang dapat digunakan kembali (*reusable*), seperti tombol, kartu, modal, alert, atau navbar.

---

## 1. Keuntungan Menggunakan Blade Components

::card-group
::card{title="Prinsip DRY (Don't Repeat Yourself)" icon="lucide:copy-slash"}
Menghindari duplikasi kode HTML dan styling yang sama di banyak tempat.
::
::card{title="Konsistensi Desain" icon="lucide:palette"}
Perubahan desain pada satu file komponen akan otomatis berdampak ke seluruh halaman yang menggunakannya.
::
::card{title="Sintaks Bersih ala Custom HTML Tag" icon="lucide:code"}
Komponen dipanggil seperti tag HTML asli menggunakan awalan `<x-...>`, membuat kode template Blade sangat mudah dibaca.
::
::card{title="Dukungan Props & Slot Fleksibel" icon="lucide:sliders"}
Mendukung pengiriman data (*props*), injeksi konten (*default slot*), serta pemisahan bagian (*named slots*).
::
::

## 2. Cara Membuat Blade Component

Terdapat dua tipe komponen Blade di Laravel: **Class-based Component** dan **Anonymous Component**.

### Tipe 1: Class-based Component (Direkomendasikan dengan Logika)

Gunakan perintah Artisan berikut untuk membuat komponen baru:

```bash [Terminal]
php artisan make:component AlertCard
```

Perintah di atas akan menghasilkan dua file:
1. **Class Logika:** `app/View/Components/AlertCard.php`
2. **Template Tampilan:** `resources/views/components/alert-card.blade.php`

### Tipe 2: Anonymous Component (Hanya File View)

Jika komponen Anda hanya berupa tampilan murni tanpa logika PHP di class, Anda cukup membuat file blade langsung di dalam direktori `resources/views/components/` (misalnya `resources/views/components/badge.blade.php`).

## 3. Struktur & Implementasi Komponen

Mari kita buat komponen **AlertCard** yang dinamis:

::tabs
::tabs-item{label="1. Class Logika"}
```php [app/View/Components/AlertCard.php]
namespace App\View\Components;

use Closure;
use Illuminate\Contracts\View\View;
use Illuminate\View\Component;

class AlertCard extends Component
{
    /**
     * Membuat instance komponen baru.
     */
    public function __construct(
        public string $type = 'info',
        public string $title = 'Pemberitahuan'
    ) {}

    /**
     * Menentukan class CSS berdasarkan tipe alert.
     */
    public function alertClass(): string
    {
        return match ($this->type) {
            'success' => 'bg-green-50 border-green-500 text-green-800',
            'warning' => 'bg-yellow-50 border-yellow-500 text-yellow-800',
            'danger'  => 'bg-red-50 border-red-500 text-red-800',
            default   => 'bg-blue-50 border-blue-500 text-blue-800',
        };
    }

    public function render(): View|Closure|string
    {
        return view('components.alert-card');
    }
}
```
::

::tabs-item{label="2. Template Blade"}
```blade [resources/views/components/alert-card.blade.php]
<div {{ $attributes->merge(['class' => "p-4 border-l-4 rounded-r shadow-sm {$alertClass()}"]) }}>
    <div class="flex items-center justify-between mb-1">
        <h4 class="font-semibold text-base">{{ $title }}</h4>
    </div>
    <div class="text-sm leading-relaxed">
        {{ $slot }}
    </div>
</div>
```

## 4. Cara Menampilkan & Menggunakan Komponen

Komponen dipanggil di file view mana saja menggunakan sintaks tag `<x-nama-komponen>`:

```blade [resources/views/welcome.blade.php]
<!-- Pemanggilan Komponen Sederhana -->
<x-alert-card type="success" title="Registrasi Berhasil!">
    Selamat datang di program pengembang. Akun Anda telah aktif.
</x-alert-card>

<!-- Mengirimkan Variabel PHP Dinamis (Gunakan tanda titik dua :) -->
<x-alert-card :type="$statusTipe" :title="$judulPesan">
    {{ $isiPesan }}
</x-alert-card>

<!-- Komponen dengan class tambahan dari luar (akan di-merge otomatis) -->
<x-alert-card type="warning" title="Perhatian" class="mt-6 mb-4">
    Pastikan Anda telah mencadangkan file konfigurasi database.
</x-alert-card>
```

## 5. Menggunakan Named Slots

Jika komponen Anda memiliki beberapa area konten (misalnya Header, Body, dan Footer), Anda dapat menggunakan **Named Slots**:

```blade [resources/views/components/modal.blade.php]
<div class="modal-box p-6 bg-white rounded-lg shadow-xl">
    <div class="modal-header border-b pb-3 mb-4">
        {{ $header }}
    </div>

    <div class="modal-body mb-4">
        {{ $slot }}
    </div>

    <div class="modal-footer border-t pt-3 flex justify-end gap-2">
        {{ $footer }}
    </div>
</div>
```

Cara mengisinya di view:

```blade [resources/views/dashboard.blade.php]
<x-modal>
    <x-slot:header>
        <h3 class="text-lg font-bold">Konfirmasi Hapus Data</h3>
    </x-slot:header>

    Apakah Anda yakin ingin menghapus data siswa ini secara permanen?

    <x-slot:footer>
        <button class="btn-cancel">Batal</button>
        <button class="btn-danger">Hapus</button>
    </x-slot:footer>
</x-modal>
```
