Dalam pengembangan aplikasi Laravel, aset frontend dibagi menjadi dua kategori utama:
1. **Aset Statis Langsung:** File yang disajikan apa adanya tanpa kompilasi (disimpan di folder `public/`).
2. **Aset Terkompilasi (*Bundled*):** File source code CSS/JS/Vue/React yang diproses melalui Vite (disimpan di folder `resources/`).

---

## 1. Memanggil File dari Folder `public/`

Folder `public/` adalah *web root* dari aplikasi Laravel. Semua file di dalam direktori ini dapat diakses langsung oleh browser publik.

### Struktur Folder `public/` yang Rapi

```
public/
├── images/
│   ├── logo.svg
│   └── hero.webp
├── css/
│   └── custom-style.css
├── js/
│   └── custom-script.js
├── favicon.ico
└── robots.txt
```

### Menggunakan Helper `asset()`

Untuk menghasilkan URL aset yang absolut dan sesuai dengan protokol (`http` atau `https`) aplikasi, selalu gunakan fungsi pembantu (*helper*) `asset()`:

```blade [resources/views/layouts/app.blade.php]
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Aplikasi Saya</title>

    <!-- Memanggil file CSS statis -->
    <link rel="stylesheet" href="{{ asset('css/custom-style.css') }}">
    <link rel="icon" href="{{ asset('favicon.ico') }}">
</head>
<body>
    <!-- Memanggil Gambar -->
    <img src="{{ asset('images/logo.svg') }}" alt="Logo Komunitas" width="160">

    <!-- Memanggil Script JS -->
    <script src="{{ asset('js/custom-script.js') }}"></script>
</body>
</html>
```

::alert{type="info" icon="lucide:info"}
Fungsi `asset('images/logo.svg')` secara otomatis menghasilkan URL lengkap seperti `https://namadomain.com/images/logo.svg` atau `http://127.0.0.1:8000/images/logo.svg` pada saat pengujian lokal.
::

## 2. Aset Modern dengan Vite Bundler

Pada Laravel modern, pengelolaan CSS dan JavaScript utama (seperti Tailwind CSS, Alpine.js, Vue, atau React) ditangani secara otomatis oleh **Vite**.

File sumber diletakkan di dalam folder `resources/`:
- `resources/css/app.css`
- `resources/js/app.js`

### Menyertakan Vite di Template Blade

Cukup tambahkan directive `@vite` pada tag `<head>` template utama:

```blade [resources/views/layouts/app.blade.php]
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{{ $title ?? 'Laravel App' }}</title>

    <!-- Directive Vite Otomatis Menangani Hot Module Replacement (HMR) -->
    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
```

### Menjalankan Vite Server

Gunakan perintah npm untuk memulai server pengembangan aset:

::tabs
::tabs-item{label="1. Mode Pengembangan (Dev Server)"}
```bash [Terminal]
npm run dev
```
> Mendukung *Hot Module Replacement (HMR)*: setiap kali Anda mengubah file CSS/JS/Blade, browser akan ter-refresh secara instan tanpa reload penuh.
::

::tabs-item{label="2. Mode Produksi (Build Bundle)"}
```bash [Terminal]
npm run build
```
> Mengompilasi dan mengompresi seluruh aset ke dalam folder `public/build/` dengan *versioning* / *cache-busting* otomatis.
::
::

## 3. Menghubungkan Folder Storage Publik (*Symlink*)

Jika aplikasi Anda memiliki fitur upload file oleh pengguna (misalnya avatar atau berkas dokumen), file tersebut idealnya disimpan di direktori `storage/app/public/` demi keamanan.

Agar file di folder storage tersebut dapat diakses melalui web browser, buat *symbolic link* dengan perintah Artisan:

```bash [Terminal]
php artisan storage:link
```

Perintah ini akan membuat tautan virtual dari `public/storage` mengarah ke `storage/app/public`. Di view, Anda dapat memanggilnya dengan:

```blade [resources/views/user/profile.blade.php]
<img src="{{ asset('storage/' . $user->avatar) }}" alt="Avatar">
```
