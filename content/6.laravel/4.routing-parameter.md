Seringkali rute aplikasi memerlukan segmen dinamis dari URL untuk memfilter atau mengidentifikasi entitas tertentu, seperti ID pengguna, nomor pesanan, atau slug artikel.

---

## 1. Parameter Rute Wajib (*Required Parameters*)

Parameter dinamis ditandai dengan tanda kurung kurawal `{nama_parameter}` di dalam URI. Parameter tersebut akan otomatis di-pass ke dalam callback function atau controller sesuai urutan deklarasinya:

```php [routes/web.php]
Route::get('/users/{id}', function (string $id) {
    return "Profil Pengguna dengan ID: " . $id;
});
```

### Beberapa Parameter Sekaligus (*Multiple Parameters*)

Anda dapat mendefinisikan lebih dari satu parameter dalam satu rute:

```php [routes/web.php]
Route::get('/posts/{post}/comments/{comment}', function (string $postId, string $commentId) {
    return "Menampilkan Komentar #{$commentId} untuk Artikel #{$postId}";
});
```

::alert{type="warning" icon="lucide:alert-triangle"}
Nama parameter di URL tidak boleh mengandung tanda hubung (`-`). Gunakan format *camelCase* atau *snake_case* (misalnya `{userId}` atau `{user_id}`).
::

---

## 2. Parameter Rute Opsional (*Optional Parameters*)

Jika suatu segmen URL tidak selalu wajib ada, tambahkan tanda tanya `?` setelah nama parameter dan berikan nilai default pada argumen fungsinya:

```php [routes/web.php]
Route::get('/katalog/{kategori?}', function (?string $kategori = 'semua') {
    return "Menampilkan katalog produk kategori: " . $kategori;
});
```

- Mengakses `/katalog` akan menghasilkan: *"Menampilkan katalog produk kategori: semua"*
- Mengakses `/katalog/elektronik` akan menghasilkan: *"Menampilkan katalog produk kategori: elektronik"*

---

## 3. Validasi Format Parameter (*Route Constraints*)

Untuk mencegah bug atau input berbahaya, Anda dapat membatasi format karakter yang diterima parameter menggunakan method `where()` atau helper bawaan:

::tabs
::tabs-item{label="Menggunakan Helper Bawaan"}
```php [routes/web.php]
// Parameter id hanya boleh berupa angka (numeric)
Route::get('/user/{id}', function (string $id) {
    return "User ID: {$id}";
})->whereNumber('id');

// Parameter nama hanya boleh berupa huruf alfabet
Route::get('/halo/{nama}', function (string $nama) {
    return "Halo, {$nama}";
})->whereAlpha('nama');

// Parameter slug hanya boleh berupa karakter alfanumerik & dash
Route::get('/artikel/{slug}', function (string $slug) {
    return "Artikel: {$slug}";
})->whereAlphaNumeric('slug');
```
::

::tabs-item{label="Menggunakan Regex Kustom"}
```php [routes/web.php]
Route::get('/order/{orderId}', function (string $orderId) {
    return "Nomor Order: {$orderId}";
})->where('orderId', 'ORD-[0-9]{5}');
```
> Rute di atas hanya akan cocok jika format URL adalah `/order/ORD-12345`. Jika tidak cocok, Laravel otomatis mengembalikan respon **404 Not Found**.
::
::

## 4. Penamaan Rute (*Named Routes*)

Memberi nama pada rute memudahkan Anda dalam mereferensikan URL di seluruh aplikasi. Jika di kemudian hari struktur URL diubah, Anda tidak perlu mengganti tautan di banyak file view secara manual.

```php [routes/web.php]
Route::get('/user/dashboard/overview', function () {
    return view('dashboard');
})->name('dashboard');

Route::get('/artikel/{id}', function (string $id) {
    return view('artikel.detail', ['id' => $id]);
})->name('artikel.show');
```

### Menggunakan Named Route di View Blade & Controller

```blade [resources/views/navbar.blade.php]
<!-- Menghasilkan URL dinamis ke dashboard -->
<a href="{{ route('dashboard') }}" class="nav-link">Dashboard</a>

<!-- Menghasilkan URL dengan parameter: /artikel/42 -->
<a href="{{ route('artikel.show', ['id' => 42]) }}">Baca Artikel</a>
```

Di Controller untuk pengalihan (*redirect*):

```php [app/Http/Controllers/AuthController.php]
return redirect()->route('dashboard');
```

## 5. Pengelompokan Rute (*Route Groups*)

Route Groups memungkinkan Anda berbagi atribut rute—seperti middleware, prefix URL, atau controller—ke banyak rute sekaligus tanpa redundansi kode:

```php [routes/web.php]
use App\Http\Controllers\AdminController;

Route::prefix('admin')->middleware(['auth'])->group(function () {
    Route::get('/dashboard', [AdminController::class, 'dashboard'])->name('admin.dashboard');
    Route::get('/users', [AdminController::class, 'users'])->name('admin.users');
    Route::get('/settings', [AdminController::class, 'settings'])->name('admin.settings');
});
```

URL yang dihasilkan otomatis diawali dengan `/admin` (misal `/admin/dashboard`) dan diproteksi oleh middleware `auth`.
