**Routing** adalah mekanisme yang menentukan bagaimana aplikasi web merespons permintaan (*HTTP Request*) dari pengguna berdasarkan URI (alamat URL) dan metode HTTP yang dikirimkan.

Di Laravel, seluruh rute web utama didefinisikan di dalam file `routes/web.php`.

---

## 1. Anatomi Dasar Routing

Berikut adalah contoh rute dasar bawaan Laravel:

```php [routes/web.php]
use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});
```

::tabs
::tabs-item{label="Penjelasan Komponen"}
- `Route::` &mdash; Facade utama Laravel untuk mendaftarkan rute.
- `get(...)` &mdash; Metode HTTP yang diterima oleh rute ini.
- `'/'` &mdash; Jalur URI (endpoint) yang diakses oleh pengguna.
- `function () { ... }` &mdash; Callback closure atau handler logika yang dieksekusi saat URI cocok.
- `view('welcome')` &mdash; Helper function untuk merender file view `resources/views/welcome.blade.php`.
::

::tabs-item{label="Metode HTTP Lainnya"}
Laravel mendukung semua metode HTTP standar untuk arsitektur RESTful:

```php [routes/web.php]
Route::get('/users', [UserController::class, 'index']);       // Menampilkan data
Route::post('/users', [UserController::class, 'store']);      // Menyimpan data baru
Route::put('/users/{id}', [UserController::class, 'update']); // Memperbarui seluruh data
Route::patch('/users/{id}', [UserController::class, 'updateStatus']); // Memperbarui sebagian data
Route::delete('/users/{id}', [UserController::class, 'destroy']);     // Menghapus data
```

## 2. Cara Mengirimkan Data ke Halaman (View)

Ketika ingin menyajikan data dinamis ke pengguna, Anda dapat mengoper (*pass*) variabel dari Route ke template Blade. Terdapat 3 cara standar di Laravel:

### Cara A: Menggunakan Array Asosiatif

Anda dapat mengirimkan data sebagai argumen kedua pada helper `view()` berupa pasangan key-value array:

```php [routes/web.php]
Route::get('/profil', function () {
    return view('profil', [
        'nama' => 'Kina SaQina',
        'status' => 'Siswa RPL',
        'kelas' => 'XI RPL 1'
    ]);
});
```

Di dalam view `resources/views/profil.blade.php`, key array tersebut otomatis dikonversi menjadi variabel PHP (`$nama`, `$status`, `$kelas`):

```blade [resources/views/profil.blade.php]
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Profil Pengguna</title>
</head>
<body class="p-4">
    <h1>Halo, {{ $nama }}!</h1>
    <p>Status: {{ $status }} ({{ $kelas }})</p>
</body>
</html>
```

---

### Cara B: Menggunakan Helper `compact()`

Jika Anda sudah memiliki variabel yang didefinisikan sebelumnya, fungsi bawaan PHP `compact()` adalah cara yang paling bersih dan ringkas:

```php [routes/web.php]
Route::get('/siswa', function () {
    $judul = 'Daftar Siswa Berprestasi';
    $daftarSiswa = ['Davin', 'Kina', 'Rehan', 'Jalal'];
    $angkatan = 2026;

    // compact('judul', 'daftarSiswa', 'angkatan')
    // otomatis membuat array ['judul' => $judul, 'daftarSiswa' => $daftarSiswa, 'angkatan' => $angkatan]
    return view('daftar_siswa', compact('judul', 'daftarSiswa', 'angkatan'));
});
```

Menampilkan data array pada file Blade menggunakan directive `@foreach`:

```blade [resources/views/daftar_siswa.blade.php]
<h2>{{ $judul }} - Angkatan {{ $angkatan }}</h2>

<ul>
    @foreach ($daftarSiswa as $siswa)
        <li>Siswa: {{ $siswa }}</li>
    @endforeach
</ul>
```

---

### Cara C: Menggunakan Method Chaining `with()`

Anda juga dapat merantai method `with()` langsung ke instance view:

```php [routes/web.php]
Route::get('/pengumuman', function () {
    return view('pengumuman')
        ->with('pesan', 'Pendaftaran anggota baru telah dibuka!')
        ->with('kuota', 50);
});
```

---

## 3. Perbandingan Ketiga Metode

| Metode | Contoh Sintaks | Kapan Digunakan? |
| :--- | :--- | :--- |
| **Array Asosiatif** | `view('page', ['key' => $val])` | Sangat cocok ketika nama variabel di view berbeda dengan nama variabel di backend. |
| **`compact()`** | `view('page', compact('val1', 'val2'))` | **Rekomendasi Utama** untuk kode yang bersih jika nama variabel sama. |
| **Method `with()`** | `view('page')->with('key', $val)` | Berguna saat melakukan chaining atau mem-passing flash session. |

::alert{type="tip" icon="lucide:lightbulb"}
**Best Practice:** Selalu gunakan sintaks interpolasi Blade `{{ $variabel }}` untuk otomatis melakukan sanitasi data dari serangan XSS (Cross-Site Scripting). Hindari penggunaan `{!! $variabel !!}` kecuali Anda yakin konten tersebut adalah HTML aman yang sudah dibersihkan.
