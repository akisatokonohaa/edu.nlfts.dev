### Menginstal PHP dan Laravel Installer

Sebelum membuat aplikasi Laravel pertama Anda, pastikan bahwa komputer lokal Anda telah menginstal [PHP](https://php.net), [Composer](https://getcomposer.org), dan [Laravel installer](https://github.com/laravel/installer). Selain itu, Anda juga harus menginstal [Node dan NPM](https://nodejs.org) atau [Bun](https://bun.sh/) agar Anda dapat mengkompilasi aset *frontend* aplikasi Anda.

Jika Anda belum menginstal PHP dan Composer di komputer lokal, perintah-perintah berikut akan menginstal PHP, Composer, dan Laravel installer di macOS, Windows, atau Linux:

```shell tab=macOS
/bin/bash -c "$(curl -fsSL https://php.new/install/mac/8.5)"
```

```shell tab=Windows PowerShell
# Run as administrator...
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://php.new/install/windows/8.5'))
```

```shell tab=Linux
/bin/bash -c "$(curl -fsSL https://php.new/install/linux/8.5)"
```

Setelah menjalankan salah satu perintah di atas, Anda harus memulai ulang sesi *terminal* Anda. Untuk memperbarui PHP, Composer, dan Laravel installer setelah menginstalnya melalui `php.new`, Anda dapat menjalankan kembali perintah tersebut di *terminal* Anda.

Jika Anda sudah menginstal PHP dan Composer, Anda dapat menginstal Laravel installer melalui Composer:

```shell
composer global require laravel/installer
```

> [!NOTE]
> Untuk pengalaman instalasi dan manajemen PHP berbasis grafis yang lengkap fiturnya, silakan cek [Laravel Herd](#installation-using-herd).

<a name="creating-an-application"></a>
### Membuat Aplikasi

Setelah Anda menginstal PHP, Composer, dan Laravel installer, Anda siap untuk membuat aplikasi Laravel baru:

```shell
laravel new example-app
```

Setelah aplikasi dibuat, Anda dapat menjalankan *server* pengembangan lokal Laravel, *queue worker*, dan *server* pengembangan Vite menggunakan skrip Composer `dev`:

```shell
cd example-app
npm install && npm run build
composer run dev
```

Setelah Anda menjalankan *development server*, Anda dapat mengakses aplikasi Anda di *web browser* melalui [http://localhost:8000](http://localhost:8000). Selanjutnya, Anda siap untuk [mulai melangkah ke ekosistem Laravel](#next-steps). Tentu saja, Anda mungkin juga ingin [mengonfigurasi database](#databases-and-migrations) dan menjalankan *migration* yang diperlukan.

> [!NOTE]
> Jika Anda ingin mendapatkan keuntungan awal saat mengembangkan aplikasi Laravel, pertimbangkan untuk menggunakan salah satu [starter kit](/docs/{{version}}/starter-kits) kami. *Starter kit* Laravel menyediakan perancah (*scaffolding*) autentikasi *frontend* dan *backend* untuk aplikasi Laravel baru Anda.

<a name="initial-configuration"></a>
## Konfigurasi Awal

Semua file konfigurasi untuk *framework* Laravel disimpan dalam direktori `config`. Setiap opsi telah didokumentasikan, jadi silakan telusuri file-file tersebut untuk mengenal opsi-opsi yang tersedia bagi Anda.

Laravel hampir tidak memerlukan konfigurasi tambahan apa pun secara *out of the box*. Anda dapat langsung mulai mengembangkan! Namun, Anda mungkin ingin meninjau file `config/app.php` dan dokumentasinya. File ini berisi beberapa opsi seperti `url` dan `locale` yang mungkin ingin Anda ubah sesuai dengan aplikasi Anda.

<a name="environment-based-configuration"></a>
### Konfigurasi Berbasis Lingkungan

Karena banyak nilai opsi konfigurasi Laravel mungkin berbeda tergantung pada apakah aplikasi Anda berjalan di komputer lokal atau di *web server* produksi, banyak nilai konfigurasi penting didefinisikan menggunakan file `.env` yang ada di akar aplikasi Anda.

File `.env` Anda tidak boleh di-*commit* ke dalam *source control* aplikasi Anda, karena setiap *developer* / *server* yang menggunakan aplikasi Anda mungkin memerlukan konfigurasi lingkungan yang berbeda. Selain itu, hal ini akan menjadi risiko keamanan jika ada penyusup yang berhasil mengakses repositori *source control* Anda, karena kredensial sensitif apa pun akan terekspos.

> [!NOTE]
> Untuk informasi lebih lanjut tentang file `.env` dan konfigurasi berbasis lingkungan, silakan baca [dokumentasi konfigurasi](/docs/{{version}}/configuration#environment-configuration) secara lengkap.

<a name="databases-and-migrations"></a>
### Database dan Migrasi

Sekarang setelah Anda membuat aplikasi Laravel, Anda mungkin ingin menyimpan beberapa data di dalam database. Secara *default*, file konfigurasi `.env` aplikasi Anda menentukan bahwa Laravel akan berinteraksi dengan database SQLite.

Selama pembuatan aplikasi, Laravel telah membuat file `database/database.sqlite` untuk Anda, dan menjalankan *migration* yang diperlukan untuk membuat tabel-tabel database aplikasi.

Jika Anda lebih suka menggunakan *database driver* lain seperti MySQL atau PostgreSQL, Anda dapat memperbarui file konfigurasi `.env` Anda untuk menggunakan database yang sesuai. Misalnya, jika Anda ingin menggunakan MySQL, perbarui variabel `DB_*` pada file konfigurasi `.env` Anda seperti ini:

```ini
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=root
DB_PASSWORD=
```

Jika Anda memilih untuk menggunakan database selain SQLite, Anda perlu membuat database tersebut dan menjalankan [migrasi database](/docs/{{version}}/migrations) aplikasi Anda:

```shell
php artisan migrate
```

> [!NOTE]
> Jika Anda mengembangkan di macOS atau Windows dan perlu menginstal MySQL, PostgreSQL, atau Redis secara lokal, pertimbangkan untuk menggunakan [Herd Pro](https://herd.laravel.com/#plans) atau [DBngin](https://dbngin.com/).

<a name="directory-configuration"></a>
### Konfigurasi Direktori

Laravel harus selalu dijalankan dari akar "direktori web" yang dikonfigurasi untuk *web server* Anda. Anda tidak boleh mencoba menjalankan aplikasi Laravel dari subdirektori "direktori web". Mencoba melakukannya dapat mengekspos file-file sensitif yang ada di dalam aplikasi Anda.

<a name="installation-using-herd"></a>
## Instalasi Menggunakan Herd

[Laravel Herd](https://herd.laravel.com) adalah lingkungan pengembangan Laravel dan PHP native yang sangat cepat untuk macOS dan Windows. Herd menyertakan semua yang Anda butuhkan untuk memulai pengembangan Laravel, termasuk PHP dan Nginx.

Setelah Anda menginstal Herd, Anda siap untuk mulai mengembangkan dengan Laravel. Herd menyertakan alat *command line* untuk `php`, `composer`, `laravel`, `expose`, `node`, `npm`, dan `nvm`.

> [!NOTE]
> [Herd Pro](https://herd.laravel.com/#plans) meningkatkan kemampuan Herd dengan fitur tambahan yang powerful, seperti kemampuan untuk membuat dan mengelola database MySQL, Postgres, dan Redis secara lokal, serta pemantauan *log* dan penampilan *mail* lokal.

<a name="herd-on-macos"></a>
### Herd di macOS

Jika Anda mengembangkan di macOS, Anda dapat mengunduh installer Herd dari [situs web Herd](https://herd.laravel.com). Installer ini secara otomatis mengunduh versi PHP terbaru dan mengonfigurasi Mac Anda agar selalu menjalankan [Nginx](https://www.nginx.com/) di latar belakang.

Herd untuk macOS menggunakan [dnsmasq](https://en.wikipedia.org/wiki/Dnsmasq) untuk mendukung direktori yang "di-*parkir*". Setiap aplikasi Laravel di dalam direktori yang di-*parkir* akan secara otomatis dilayani oleh Herd. Secara *default*, Herd membuat direktori parkir di `~/Herd` dan Anda dapat mengakses aplikasi Laravel apa pun di direktori ini pada domain `.test` menggunakan nama direktorinya.

Setelah menginstal Herd, cara tercepat untuk membuat aplikasi Laravel baru adalah menggunakan Laravel CLI, yang sudah termasuk di dalam Herd:

```shell
cd ~/Herd
laravel new my-app
cd my-app
herd open
```

Tentu saja, Anda selalu dapat mengelola direktori parkir dan pengaturan PHP lainnya melalui UI Herd, yang dapat dibuka dari menu Herd di *system tray* Anda.

Anda dapat mempelajari lebih lanjut tentang Herd dengan membaca [dokumentasi Herd](https://herd.laravel.com/docs).

<a name="herd-on-windows"></a>
### Herd di Windows

Anda dapat mengunduh installer Windows untuk Herd di [situs web Herd](https://herd.laravel.com/windows). Setelah instalasi selesai, Anda dapat memulai Herd untuk menyelesaikan proses *onboarding* dan mengakses UI Herd untuk pertama kalinya.

UI Herd dapat diakses dengan mengklik kiri pada ikon Herd di *system tray*. Klik kanan akan membuka menu cepat yang memberikan akses ke semua alat yang Anda butuhkan sehari-hari.

Selama instalasi, Herd membuat direktori "parkir" di direktori *home* Anda pada `%USERPROFILE%\Herd`. Setiap aplikasi Laravel di dalam direktori parkir akan secara otomatis dilayani oleh Herd, dan Anda dapat mengakses aplikasi Laravel apa pun di direktori ini pada domain `.test` menggunakan nama direktorinya.

Setelah menginstal Herd, cara tercepat untuk membuat aplikasi Laravel baru adalah menggunakan Laravel CLI, yang sudah termasuk di dalam Herd. Untuk memulai, buka Powershell dan jalankan perintah-perintah berikut:

```shell
cd ~\Herd
laravel new my-app
cd my-app
herd open
```

Anda dapat mempelajari lebih lanjut tentang Herd dengan membaca [dokumentasi Herd untuk Windows](https://herd.laravel.com/docs/windows).

<a name="ide-support"></a>
## Dukungan IDE

Anda bebas menggunakan *code editor* apa pun yang Anda inginkan saat mengembangkan aplikasi Laravel. [Laravel LSP](https://github.com/laravel/lsp) menyediakan dukungan *editor* yang sadar akan *framework*, termasuk pelengkapan kode, informasi *hover*, diagnostik, tautan dokumen, *go-to definition*, dan perbaikan cepat untuk kode Laravel dan Blade.

Untuk menginstal Laravel LSP, instal secara global melalui Composer. Pastikan direktori *vendor bin* global Composer berada di `PATH` Anda:

```shell
composer global require laravel/lsp
```

Jika Anda mencari *editor* yang ringan dan dapat dikembangkan (*extensible*), [VS Code](https://code.visualstudio.com) atau [Cursor](https://cursor.com) yang dikombinasikan dengan [Ekstensi VS Code Laravel](https://marketplace.visualstudio.com/items?itemName=laravel.vscode-laravel) resmi menyediakan penyorotan sintaksis, *snippet*, integrasi perintah Artisan, dan dukungan Laravel LSP otomatis. Ekstensi Laravel resmi juga tersedia untuk [Sublime Text](https://github.com/laravel/sublime-extension) dan [Zed](https://github.com/laravel/zed-extension). Silakan merujuk ke [repositori Laravel LSP](https://github.com/laravel/lsp) untuk petunjuk pengaturan pada *editor* lain yang kompatibel dengan *language-server*, termasuk Neovim dan OpenCode.

Untuk dukungan Laravel yang luas dan tangguh, silakan lihat [PhpStorm](https://www.jetbrains.com/phpstorm/laravel/?utm_source=laravel.com&utm_medium=link&utm_campaign=laravel-2025&utm_content=partner&ref=laravel-2025), sebuah IDE dari JetBrains. Dukungan *framework* Laravel bawaan PhpStorm mencakup *template* Blade, *autocompletion* cerdas untuk model Eloquent, *route*, *view*, terjemahan, dan komponen, bersama dengan pembuatan kode dan navigasi yang powerful di seluruh proyek Laravel.

Bagi mereka yang mencari pengalaman pengembangan berbasis *cloud*, [Firebase Studio](https://firebase.studio/) menyediakan akses instan untuk membangun dengan Laravel langsung di *browser* Anda. Tanpa perlu konfigurasi apa pun, Firebase Studio memudahkan Anda memulai membangun aplikasi Laravel dari perangkat apa pun.

<a name="laravel-and-ai"></a>
## Laravel dan AI

[Laravel Boost](https://github.com/laravel/boost) adalah alat yang powerful yang menjembatani kesenjangan antara *AI coding agent* dan aplikasi Laravel. Boost menyediakan konteks, alat, dan pedoman khusus Laravel kepada *AI agent* agar mereka dapat menghasilkan kode yang lebih akurat, sesuai versi, dan mengikuti konvensi Laravel.

Ketika Anda menginstal Boost di aplikasi Laravel, *AI agent* mendapatkan akses ke lebih dari 15 alat khusus termasuk kemampuan untuk mengetahui paket apa yang Anda gunakan, meminta *query* ke database Anda, mencari dokumentasi Laravel, membaca *log browser*, membuat pengujian, dan mengeksekusi kode melalui Tinker.

Selain itu, Boost memberikan *AI agent* akses ke lebih dari 17.000 potongan dokumentasi ekosistem Laravel yang telah di-*vektorisasi*, yang spesifik untuk versi paket yang Anda instal. Ini berarti *agent* dapat memberikan panduan yang ditujukan tepat untuk versi yang digunakan proyek Anda.

Boost juga menyertakan pedoman AI yang dipelihara oleh Laravel yang membantu *agent* untuk mengikuti konvensi *framework*, menulis pengujian yang tepat, dan menghindari jebakan umum saat menghasilkan kode Laravel.

<a name="installing-laravel-boost"></a>
### Menginstal Laravel Boost

Boost dapat diinstal di aplikasi Laravel 10, 11, 12, dan 13 yang menjalankan PHP 8.1 atau lebih tinggi. Untuk memulai, instal Boost sebagai *development dependency*:

```shell
composer require laravel/boost --dev
```

Setelah diinstal, jalankan installer interaktifnya:

```shell
php artisan boost:install
```

Installer akan mendeteksi secara otomatis IDE dan *AI agent* Anda, memungkinkan Anda untuk memilih fitur-fitur yang masuk akal untuk proyek Anda. Boost menghormati konvensi proyek yang sudah ada dan tidak memaksakan aturan gaya yang kaku secara *default*.

> [!NOTE]
> Untuk mempelajari lebih lanjut tentang Boost, silakan cek [repositori Laravel Boost di GitHub](https://github.com/laravel/boost).

<a name="adding-custom-ai-guidelines"></a>
#### Menambahkan Pedoman AI Kustom

Untuk melengkapi Laravel Boost dengan pedoman AI kustom Anda sendiri, tambahkan file `.blade.php` atau `.md` ke direktori `.ai/guidelines/*` aplikasi Anda. File-file ini akan secara otomatis disertakan bersama pedoman Laravel Boost saat Anda menjalankan `boost:install`.

<a name="laravel-the-fullstack-framework"></a>
### Laravel sebagai Framework Full-Stack

Laravel dapat berfungsi sebagai *framework full-stack*. Dengan "full-stack", yang kami maksud adalah Anda akan menggunakan Laravel untuk mengarahkan (*route*) permintaan ke aplikasi Anda dan merender *frontend* Anda melalui [*template* Blade](/docs/{{version}}/blade) atau teknologi hibrida *single-page application* seperti [Inertia](https://inertiajs.com). Ini adalah cara yang paling umum untuk menggunakan *framework* Laravel, dan menurut kami, cara yang paling produktif.

Jika ini adalah cara Anda berencana menggunakan Laravel, Anda mungkin ingin melihat dokumentasi kami tentang [pengembangan *frontend*](/docs/{{version}}/frontend), [routing](/docs/{{version}}/routing), [views](/docs/{{version}}/views), atau [Eloquent ORM](/docs/{{version}}/eloquent). Selain itu, Anda mungkin tertarik untuk mempelajari paket komunitas seperti [Livewire](https://livewire.laravel.com) dan [Inertia](https://inertiajs.com). Paket-paket ini memungkinkan Anda untuk menggunakan Laravel sebagai *framework full-stack* sambil menikmati banyak manfaat UI yang disediakan oleh *single-page application* JavaScript.

Jika Anda menggunakan Laravel sebagai *framework full-stack*, kami juga sangat menganjurkan Anda untuk belajar cara mengkompilasi CSS dan JavaScript aplikasi Anda menggunakan [Vite](/docs/{{version}}/vite).

> [!NOTE]
> Jika Anda ingin mendapatkan keuntungan awal dalam membangun aplikasi Anda, silakan cek salah satu [starter kit aplikasi](/docs/{{version}}/starter-kits) resmi kami.

<a name="laravel-the-api-backend"></a>
### Laravel sebagai Backend API

Laravel juga dapat berfungsi sebagai *backend API* untuk *single-page application* JavaScript atau aplikasi mobile. Misalnya, Anda mungkin menggunakan Laravel sebagai *backend API* untuk aplikasi [Next.js](https://nextjs.org) Anda. Dalam konteks ini, Anda dapat menggunakan Laravel untuk menyediakan [autentikasi](/docs/{{version}}/sanctum) serta penyimpanan dan pengambilan data untuk aplikasi Anda, sambil juga mengambil keuntungan dari layanan Laravel yang powerful seperti *queue*, email, notifikasi, dan lainnya.

Jika ini adalah cara Anda berencana menggunakan Laravel, Anda mungkin ingin melihat dokumentasi kami tentang [routing](/docs/{{version}}/routing), [Laravel Sanctum](/docs/{{version}}/sanctum), dan [Eloquent ORM](/docs/{{version}}/eloquent).


## 1. Apa Itu CLI?

**CLI (Command Line Interface)** adalah antarmuka berbasis teks di mana pengembang berinteraksi dengan sistem operasi atau program dengan mengetikkan instruksi khusus (*commands*).

::alert{type="info" icon="lucide:info"}
Dibandingkan dengan GUI (*Graphical User Interface*), CLI menawarkan eksekusi yang jauh lebih cepat, presisi tinggi, serta kemampuan otomatisasi skrip yang sangat efisien untuk pengembang perangkat lunak.
::

### Cara Kerja Perintah CLI

1. **Penginputan Perintah:** Pengembang mengetikkan perintah di terminal (contoh: Terminal VS Code, PowerShell, atau Git Bash).
2. **Penerjemahan oleh Shell:** Shell memproses teks perintah dan mengirimkannya ke engine PHP atau sistem operasi.
3. **Eksekusi & Output:** Sistem mengeksekusi instruksi dan mencetak hasil berupa pesan status, progress bar, atau log informasi secara langsung.

---

## 2. Pengenalan PHP Artisan

**Artisan** adalah antarmuka baris perintah bawaan yang disertakan di dalam setiap instalasi Laravel. Artisan menyediakan kumpulan perintah (*commands*) siap pakai untuk membuat file boilerplate, menjalankan migrasi database, mengelola antrean (*queue*), hingga menjalankan server pengujian lokal.

Untuk melihat seluruh daftar perintah yang tersedia, jalankan perintah berikut di root proyek:

```bash [Terminal]
php artisan list
```

---

## 3. Daftar Perintah Artisan yang Sering Digunakan

Berikut adalah rangkuman perintah Artisan penting yang dikelompokkan berdasarkan fungsinya:

::tabs
::tabs-item{label="1. Server & Utilitas"}
Menjalankan server pengembangan lokal dan membersihkan cache aplikasi:

```bash [Terminal]
# Menjalankan local development server (http://127.0.0.1:8000)
php artisan serve

# Menampilkan semua daftar route yang terdaftar
php artisan route:list

# Membersihkan seluruh cache (config, route, view, application cache)
php artisan optimize:clear

# Masuk ke REPL interaktif Laravel (Tinker)
php artisan tinker
```
::

::tabs-item{label="2. Generator Komponen"}
Membuat file struktur MVC dan komponen aplikasi secara instan:

```bash [Terminal]
# Membuat Controller baru
php artisan make:controller PostController

# Membuat Model sekaligus Migration, Seeder, dan Controller (-msc)
php artisan make:model Post -msc

# Membuat Blade Component
php artisan make:component AlertCard

# Membuat Factory untuk data dummy
php artisan make:factory PostFactory

# Membuat Seeder database
php artisan make:seeder PostSeeder
```
::

::tabs-item{label="3. Database & Migrasi"}
Mengelola struktur tabel dan pengisian data:

```bash [Terminal]
# Menjalankan migrasi baru
php artisan migrate

# Mereset dan menjalankan ulang seluruh migrasi dari awal
php artisan migrate:fresh

# Mereset database sekaligus menjalankan seeder
php artisan migrate:fresh --seed

# Melihat status migrasi yang telah dijalankan
php artisan migrate:status
```
::
::

## 5. Tips Alur Kerja Efisien

::steps
### 1. Gunakan Shortcut Terminal Terintegrasi
Buka atau tutup terminal di VS Code kapan saja menggunakan tombol <kbd>Ctrl</kbd> + <kbd>`</kbd> (backtick).

### 2. Manfaatkan Flag Shorthand Artisan
Saat membuat Model, Anda bisa menambahkan flag lengkap sekaligus:
```bash [Terminal]
php artisan make:model Product -a
```
> Flag `-a` (*all*) akan otomatis membuat: **Model**, **Migration**, **Seeder**, **Factory**, **Policy**, dan **Resource Controller** dalam satu kali tekan!

### 3. Cek Status Route Secara Berkala
Gunakan filter pencarian saat memeriksa daftar route aplikasi:
```bash [Terminal]
php artisan route:list --path=posts
```
::
