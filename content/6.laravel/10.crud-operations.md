# Operasi CRUD dengan Eloquent

**CRUD** adalah singkatan dari **Create**, **Read**, **Update**, dan **Delete**—empat operasi dasar yang paling sering dilakukan dalam pengelolaan data aplikasi database.

---

## 1. Create (Menambahkan Data Baru)

Terdapat dua cara utama untuk menambahkan data baru menggunakan Eloquent:

::tabs
::tabs-item{label="Cara 1: Membuat Instance Objek"}
```php
use App\Models\Post;

$post = new Post();
$post->title = 'Tips Cepat Mahir Laravel 13';
$post->slug = 'tips-cepat-mahir-laravel-13';
$post->content = 'Pelajari konsep inti MVC dan Eloquent secara konsisten.';
$post->user_id = 1;

// Simpan data ke database (menjalankan query INSERT)
$post->save();
```
::

::tabs-item{label="Cara 2: Mass Assignment (Lebih Ringkas)"}
```php
use App\Models\Post;

// Syarat: Pastikan kolom sudah didaftarkan di $fillable model Post
$post = Post::create([
    'title'   => 'Tips Cepat Mahir Laravel 13',
    'slug'    => 'tips-cepat-mahir-laravel-13',
    'content' => 'Pelajari konsep inti MVC dan Eloquent secara konsisten.',
    'user_id' => 1,
]);
```
::
::

## 2. Read (Menampilkan & Mengambil Data)

Eloquent menyediakan metode pencarian data yang sangat fleksibel:

```php
use App\Models\Post;

// 1. Mengambil seluruh record
$allPosts = Post::all();

// 2. Mengambil satu record berdasarkan Primary Key
$post = Post::find(1);

// 3. Mengambil satu record atau lempar 404 jika tidak ada
$post = Post::findOrFail(1);

// 4. Mengambil data berdasarkan filter kondisi (misalnya pencarian judul)
$filteredPosts = Post::where('title', 'like', '%Tips%')
    ->where('status', 'published')
    ->orderBy('created_at', 'desc')
    ->get();

// 5. Menghitung total data
$totalPosts = Post::where('status', 'published')->count();
```

## 3. Update (Memperbarui Data)

Untuk memperbarui data, ambil instance model terlebih dahulu, ubah nilainya, lalu simpan kembali:

::tabs
::tabs-item{label="Cara 1: Mengubah Atribut Objek"}
```php
use App\Models\Post;

$post = Post::findOrFail(1);

// Ubah nilai kolom
$post->title = 'Judul Artikel Telah Diperbarui';
$post->content = 'Isi konten yang baru diperbarui.';

// Simpan perubahan ke database (menjalankan query UPDATE)
$post->save();
```
::

::tabs-item{label="Cara 2: Mass Update"}
```php
use App\Models\Post;

$post = Post::findOrFail(1);

$post->update([
    'title'   => 'Judul Artikel Telah Diperbarui',
    'content' => 'Isi konten yang baru diperbarui.',
]);
```
::
::

## 4. Delete (Menghapus Data)

Menghapus data dari database dapat dilakukan secara instan:

```php
use App\Models\Post;

// Cara 1: Mengambil objek lalu memanggil method delete()
$post = Post::findOrFail(1);
$post->delete();

// Cara 2: Menghapus langsung berdasarkan ID Primary Key menggunakan destroy()
Post::destroy(1);

// Cara 3: Menghapus banyak ID sekaligus
Post::destroy([1, 2, 3]);

// Cara 4: Menghapus data berdasarkan kriteria query
Post::where('status', 'draft')->where('created_at', '<', now()->subMonths(6))->delete();
```

## 5. Form Spoofing & CSRF pada View Blade

Formulir HTML browser standar hanya mendukung metode HTTP `GET` dan `POST`. Untuk melakukan operasi `PUT/PATCH` (Update) atau `DELETE` (Hapus), Laravel menyediakan directive `@method()` dan proteksi token `@csrf`:

```blade [resources/views/posts/edit.blade.php]
<!-- Form Update Data -->
<form action="{{ route('posts.update', $post->id) }}" method="POST">
    @csrf
    @method('PUT') <!-- Mengubah request POST menjadi PUT -->

    <div>
        <label for="title">Judul:</label>
        <input type="text" id="title" name="title" value="{{ old('title', $post->title) }}">
    </div>

    <div>
        <label for="content">Konten:</label>
        <textarea id="content" name="content">{{ old('content', $post->content) }}</textarea>
    </div>

    <button type="submit">Simpan Perubahan</button>
</form>

<!-- Form Hapus Data -->
<form action="{{ route('posts.destroy', $post->id) }}" method="POST" onsubmit="return confirm('Yakin ingin menghapus?');">
    @csrf
    @method('DELETE') <!-- Mengubah request POST menjadi DELETE -->
    <button type="submit" class="text-red-600">Hapus Artikel</button>
</form>
```

## 6. Standar Resource Controller RESTful

Daripada menuliskan rute CRUD satu per satu, gunakan fitur **Resource Controller** bawaan Laravel:

```bash [Terminal]
php artisan make:controller PostController --resource --model=Post
```

Daftarkan rute di `routes/web.php` dalam satu baris:

```php [routes/web.php]
use App\Http\Controllers\PostController;

Route::resource('posts', PostController::class);
```

Perintah di atas otomatis mendaftarkan 7 rute RESTful standar:

| Verb HTTP | URI | Action Method | Fungsi |
| :--- | :--- | :--- | :--- |
| `GET` | `/posts` | `index` | Menampilkan seluruh daftar artikel |
| `GET` | `/posts/create` | `create` | Menampilkan form tambah artikel |
| `POST` | `/posts` | `store` | Menyimpan data artikel baru |
| `GET` | `/posts/{post}` | `show` | Menampilkan detail satu artikel |
| `GET` | `/posts/{post}/edit` | `edit` | Menampilkan form edit artikel |
| `PUT/PATCH` | `/posts/{post}` | `update` | Memperbarui data artikel |
| `DELETE` | `/posts/{post}` | `destroy` | Menghapus data artikel |
