# Alur Kerja Git & GitHub untuk Proyek Laravel

Menggunakan Sistem Pengontrol Versi (*Version Control System*) seperti **Git** dan platform hosting **GitHub** adalah standar wajib dalam pengembangan aplikasi modern untuk mencatat riwayat perubahan dan berkolaborasi dalam tim.

---

## 1. Memahami File `.gitignore` pada Laravel

Proyek Laravel secara default sudah menyertakan file `.gitignore`. File ini memberi tahu Git agar **tidak melacak** file-file tertentu yang berukuran besar atau memuat kredensial sensitif.

```gitignore [.gitignore]
/node_modules
/public/build
/public/hot
/public/storage
/storage/*.key
/vendor
.env
.env.backup
.env.production
.phpunit.result.cache
Homestead.json
Homestead.yaml
npm-debug.log
yarn-error.log
/.fleet
/.idea
/.vscode
```

::alert{type="danger" icon="lucide:shield-alert"}
**PENTING:** Jangan pernah menghapus `.env` dari `.gitignore` atau mengunggah file `.env` ke GitHub karena file tersebut memuat kredensial database, App Key, dan API Secret aplikasi Anda.
::

## 2. Sesi 1: Inisialisasi Proyek & Push Pertama Kali ke GitHub

Ikuti langkah-langkah berikut ketika Anda baru pertama kali membuat proyek Laravel lokal dan ingin menghubungkannya ke repositori GitHub baru:

::steps
### 1. Buka Terminal pada Direktori Proyek
Buka terminal VS Code (<kbd>Ctrl</kbd> + <kbd>`</kbd>) atau PowerShell di direktori proyek Anda.

### 2. Inisialisasi Repositori Git Lokal
```bash [Terminal]
git init
```

### 3. Konfigurasi Identitas Pengembang (Wajib)
```bash [Terminal]
git config --global user.name "NamaLengkapAnda"
git config --global user.email "emailanda@example.com"
```
> Atau gunakan opsi `--local` jika ingin konfigurasi identitas hanya berlaku khusus untuk proyek ini saja.

### 4. Tambahkan Semua File ke Staging Area
```bash [Terminal]
git add .
```

### 5. Buat Commit Pertama
```bash [Terminal]
git commit -m "feat: inisialisasi proyek Laravel dan konfigurasi awal"
```

### 6. Hubungkan ke Remote Repositori GitHub
Buat repositori baru di [GitHub](https://github.com/new) (misalnya dengan nama `laravel-app`), lalu salin URL HTTPS repositori tersebut:
```bash [Terminal]
git remote add origin https://github.com/username-anda/laravel-app.git
```

### 7. Ubah Nama Branch ke `main` dan Lakukan Push
```bash [Terminal]
git branch -M main
git push -u origin main
```
::

## 3. Autentikasi GitHub & Windows Credential Manager

Saat pertama kali melakukan push, GitHub akan meminta autentikasi.

- **GitHub Personal Access Token (PAT):** Masukkan Token Akses Pribadi (bukan password akun GitHub biasa) yang dapat dibuat melalui menu **Settings > Developer Settings > Personal Access Tokens** di GitHub.
- **Mengubah Kredensial di Windows:** Jika Anda perlu memperbarui atau menghapus token yang tersimpan di sistem Windows, buka jendela Credential Manager melalui perintah:
  ```bash [Run Dialog / CMD]
  control /name Microsoft.CredentialManager
  ```
  Lalu pilih tab **Windows Credentials** dan cari entri `git:https://github.com`.

## 4. Sesi 2: Alur Kerja Pengembangan Harian

Setelah repositori terhubung, gunakan alur kerja berikut untuk memperbarui perubahan kode sehari-hari:

::steps
### 1. Periksa Status File yang Diubah
```bash [Terminal]
git status
```

### 2. Masukkan File ke Staging Area
```bash [Terminal]
git add .
```

### 3. Commit Perubahan dengan Pesan Jelas
Gunakan konvensi pesan commit standar (*Conventional Commits*):
```bash [Terminal]
git commit -m "feat: menambahkan komponen alert dan halaman dashboard"
```

### 4. Kirim (*Push*) ke Repositori GitHub
```bash [Terminal]
git push
```

### 5. Mengambil (*Pull*) Pembaruan Terbaru dari Tim
Jika anggota tim lain melakukan perubahan di repositori remote:
```bash [Terminal]
git pull origin main
```
::
