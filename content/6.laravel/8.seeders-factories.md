**Database Seeding** adalah proses memasukkan data awal atau data tiruan (*dummy/sample data*) ke dalam tabel database. Ini sangat berguna untuk mengisi data master (seperti data kategori, role pengguna) ataupun data pengujian (*testing*) dengan jumlah ribuan record.

---

## 1. Apa Itu Seeder & Factory?

- **Seeder:** Kelas khusus untuk mengeksekusi instruksi penyimpanan data ke tabel tertentu.
- **Model Factory:** Cetak biru (*blueprint*) penghasil data realistis secara otomatis dengan memanfaatkan library **Faker**.

---

## 2. Membuat dan Menulis Seeder Baru

Untuk membuat file seeder, jalankan perintah Artisan berikut:

```bash [Terminal]
php artisan make:seeder SiswaSeeder
```

File baru akan tersimpan di dalam folder `database/seeders/SiswaSeeder.php`.

### Menulis Logika Seeding Data

Anda dapat menggunakan **Query Builder (`DB::table`)** atau **Eloquent Model**:

```php [database/seeders/SiswaSeeder.php]
namespace Database\Seeders;

use Illuminate\Database\Seeder;
use Illuminate\Support\Facades\DB;
use App\Models\Siswa;

class SiswaSeeder extends Seeder
{
    public function run(): void
    {
        // Cara 1: Menggunakan Query Builder
        DB::table('siswas')->insert([
            [
                'nama_lengkap'  => 'Kina SaQina',
                'jenis_kelamin' => 'perempuan',
                'tanggal_lahir' => '2009-06-12',
                'tempat_lahir'  => 'Bandung',
                'agama'         => 'kristen',
                'alamat'        => 'Jl. Merdeka No. 45',
                'email'         => 'kina@example.com',
                'id_kelas'      => 1,
                'created_at'    => now(),
                'updated_at'    => now(),
            ],
            [
                'nama_lengkap'  => 'Nairha',
                'jenis_kelamin' => 'Perempuan',
                'tanggal_lahir' => '2008-11-20',
                'tempat_lahir'  => 'Jakarta',
                'agama'         => 'Islam',

                'email'         => 'nairha@example.com',
                'id_kelas'      => 1,

                'updated_at'    => now(),
            ],
        ]);
    }
}
```

## 3. Menghasilkan Data Dummy dalam Jumlah Banyak dengan Factory

Jika Anda membutuhkan puluhan atau ratusan data realistis untuk pengujian beban, buat sebuah **Factory**:

```bash [Terminal]
php artisan make:factory SiswaFactory --model=Siswa
```

Definisikan data generator menggunakan helper `fake()`:

```php [database/factories/SiswaFactory.php]
namespace Database\Factories;

use App\Models\Siswa;
use Illuminate\Database\Eloquent\Factories\Factory;

class SiswaFactory extends Factory
{
    protected $model = Siswa::class;

    public function definition(): array
    {
        return [
            'nama_lengkap'  => fake()->name(),
            'jenis_kelamin' => fake()->randomElement(['laki-laki', 'perempuan']),
            'tanggal_lahir' => fake()->date('Y-m-d', '2010-01-01'),
            'tempat_lahir'  => fake()->city(),
            'agama'         => 'Islam',
            'alamat'        => fake()->address(),
            'email'         => fake()->unique()->safeEmail(),
            'id_kelas'      => 1,
        ];
    }
}
```

Gunakan Factory tersebut di dalam `SiswaSeeder.php`:

```php [database/seeders/SiswaSeeder.php]
// Menghasilkan 50 data siswa secara instan
Siswa::factory()->count(50)->create();
```

## 4. Mendaftarkan Seeder di `DatabaseSeeder.php`

File `database/seeders/DatabaseSeeder.php` adalah gerbang utama eksekusi seeder. Daftarkan class seeder yang telah dibuat pada method `run()` menggunakan `$this->call()`:

```php [database/seeders/DatabaseSeeder.php]
namespace Database\Seeders;

use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            KelasSeeder::class, // Eksekusi tabel parent terlebih dahulu jika ada relasi
            SiswaSeeder::class,
        ]);
    }
}
```

## 5. Menjalankan Perintah Seeder

::tabs
::tabs-item{label="Jalankan Semua Seeder"}
```bash [Terminal]
php artisan db:seed
```
> Menjalankan seluruh seeder yang terdaftar di `DatabaseSeeder.php`.
::

::tabs-item{label="Jalankan Seeder Tertentu"}
```bash [Terminal]
php artisan db:seed --class=SiswaSeeder
```
> Hanya mengeksekusi kelas `SiswaSeeder`.
::

::tabs-item{label="Reset Total & Seed"}
```bash [Terminal]
php artisan migrate:fresh --seed
```
> Menghapus semua tabel, migrasi ulang, lalu menjalankan seluruh seeder secara otomatis.

## 6. Mengatasi Masalah & Error Umum Seeder

### Error: `UniqueConstraintViolationException`

```
Illuminate\Database\UniqueConstraintViolationException 
SQLSTATE[23000]: Integrity constraint violation: 19 UNIQUE constraint failed: users.email
```

**Penyebab:**  
Error ini terjadi ketika seeder mencoba memasukkan data dengan nilai kolom unik (seperti `email` atau `username`) yang sudah ada sebelumnya di database.

**Solusi Terbaik:**
1. **Gunakan Fresh Migration:** Bersihkan database sebelum melakukan seeding dengan perintah:
   ```bash [Terminal]
   php artisan migrate:fresh --seed
   ```
2. **Gunakan `firstOrCreate` / `updateOrCreate`:**
   ```php
   Siswa::updateOrCreate(
       ['email' => 'admin@example.com'], // Kriteria pengecekan
       ['nama_lengkap' => 'Administrator', 'id_kelas' => 1]
   );
   ```
