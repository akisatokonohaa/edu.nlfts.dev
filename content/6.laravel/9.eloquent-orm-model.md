# Eloquent ORM & Model

**Eloquent** adalah implementasi **Object-Relational Mapping (ORM)** bawaan Laravel. Eloquent memungkinkan pengembang berinteraksi dengan tabel database menggunakan class dan object PHP secara natural tanpa perlu menulis query SQL mentah yang berulang.

---

## 1. Perbandingan: Raw SQL vs Eloquent ORM

::tabs
::tabs-item{label="1. Raw SQL"}
```php
$articles = DB::select('SELECT * FROM articles WHERE status = ? ORDER BY created_at DESC', ['published']);
```
> Mengharuskan pengembang menghafal sintaks SQL dan memetakan hasilnya secara manual.
::

::tabs-item{label="2. Query Builder"}
```php
$articles = DB::table('articles')->where('status', 'published')->latest()->get();
```
> Lebih aman dari SQL Injection, namun belum memiliki relasi objek dan model mutator.
::

::tabs-item{label="3. Eloquent ORM (Sangat Direkomendasikan)"}
```php
$articles = Article::where('status', 'published')->latest()->get();
```
> Sintaks sangat bersih, ekspresif, mendukung relasi relasional, event, dan enkapsulasi logika bisnis.
::
::

## 2. Membuat Model Eloquent

Gunakan perintah Artisan `make:model`:

```bash [Terminal]
php artisan make:model Post
```

File model akan dibuat di folder `app/Models/Post.php`.

### Konvensi Penamaan Tabel Laravel

Secara otomatis (*by convention*), Laravel menghubungkan nama model berformat tunggal (*singular*) ke nama tabel jamak (*plural snake_case*) dalam bahasa Inggris:

| Nama Model | Nama Tabel Otomatis di Database |
| :--- | :--- |
| `Post` | `posts` |
| `User` | `users` |
| `Siswa` | `siswas` *(atau override dengan `$table = 'siswa'`)* |
| `OrderItem` | `order_items` |

## 3. Konfigurasi dan Properti Penting Model

Berikut adalah struktur model Eloquent dengan atribut konfigurasi standar:

```php [app/Models/Post.php]
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    use HasFactory;

    // Menentukan nama tabel jika tidak mengikuti konvensi jamak bahasa Inggris
    protected $table = 'posts';

    // Menentukan primary key jika bukan 'id'
    protected $primaryKey = 'id';

    // Mass Assignment Protection: Kolom yang diizinkan untuk diisi secara massal
    protected $fillable = [
        'title',
        'slug',
        'content',
        'status',
        'user_id',
    ];

    // Kolom yang dijaga (tidak boleh diisi massal). Jika kosong: semua kolom boleh diisi
    // protected $guarded = ['id'];

    // Mengaktifkan atau menonaktifkan kolom created_at & updated_at
    public $timestamps = true;

    // Type Casting: Mengubah format kolom secara otomatis saat diakses
    protected function casts(): array
    {
        return [
            'is_published' => 'boolean',
            'published_at' => 'datetime',
        ];
    }
}
```

::alert{type="warning" icon="lucide:shield-alert"}
**Keamanan Mass Assignment:** Selalu definisikan `$fillable` pada model Anda untuk mencegah celah keamanan di mana pengguna luar menyuntikkan kolom terlarang (seperti `is_admin = true`) melalui form input.
::

## 4. Berbagai Metode Query Data Menggunakan Model

Eloquent menyediakan metode statis ekspresif untuk mengambil data dari database:

```php [routes/web.php / Controller]
use App\Models\Post;

// 1. Mengambil seluruh record (SELECT * FROM posts)
$posts = Post::all();

// 2. Mengambil record berdasarkan ID Primary Key
$post = Post::find(1);

// 3. Mengambil record atau lempar 404 jika data tidak ditemukan (Sangat disarankan untuk halaman detail)
$post = Post::findOrFail($id);

// 4. Mengambil data dengan kondisi tertentu
$draftPosts = Post::where('status', 'draft')->get();

// 5. Mengambil satu record pertama yang cocok
$latestPost = Post::where('status', 'published')->latest()->first();

// 6. Mengambil data dengan pagination otomatis (misal: 10 data per halaman)
$paginatedPosts = Post::latest()->paginate(10);
```

## 5. Mengirimkan Data Model ke View Blade

Mari kita hubungkan Model `Post` ke dalam rute dan tampilkan hasilnya di file Blade:

::tabs
::tabs-item{label="1. Route / Controller"}
```php [routes/web.php]
use App\Models\Post;

Route::get('/posts', function () {
    // Ambil data postingan terbaru dari database
    $posts = Post::latest()->get();

    // Kirim data ke view menggunakan helper compact
    return view('posts.index', compact('posts'));
});
```
::

::tabs-item{label="2. Template Blade View"}
```blade [resources/views/posts/index.blade.php]
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Daftar Artikel</title>
</head>
<body class="p-6 bg-gray-50">
    <h1 class="text-2xl font-bold mb-4">Daftar Artikel Terbaru</h1>

    <div class="space-y-4">
        @forelse ($posts as $post)
            <article class="p-4 bg-white rounded-lg shadow-sm border">
                <h2 class="text-xl font-semibold">{{ $post->title }}</h2>
                <p class="text-gray-600 mt-2">{{ $post->content }}</p>
                <span class="text-xs text-gray-400">Dibuat pada: {{ $post->created_at->format('d M Y') }}</span>
            </article>
        @empty
            <p class="text-gray-500 italic">Belum ada artikel yang tersedia.</p>
        @endforelse
    </div>
</body>
</html>
```
