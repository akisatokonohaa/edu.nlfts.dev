# OOP Dasar

Mengenal Class, Object, Property, Method, Constructor, dan Destructor sebagai fondasi pemrograman berorientasi objek di PHP.

---

## 1. Mengapa OOP?

Prosedural (fungsi terpisah) cocok untuk script kecil. Tapi saat aplikasi tumbuh, kode jadi **sulit dipelihara** — data dan fungsi terpisah, mudah konflik nama variabel, susah di-*reuse*.

OOP menyelesaikan ini dengan **membungkus data (property) dan perilaku (method) dalam satu unit bernama Class**.

```text
┌─────────────────────────────┐
│         Class Mobil         │
│  ┌───────────────────────┐  │
│  │ Properties (data)     │  │
│  │  - merek              │  │
│  │  - warna              │  │
│  │  - kecepatan          │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ Methods (perilaku)    │  │
│  │  - nyalakan()         │  │
│  │  - gas()              │  │
│  │  - rem()              │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
            │
            │ instantiate (new)
            ▼
   ┌─────────────────────┐
   │  Object $mobilSaya  │
   │  merek: "Toyota"    │
   │  warna: "Merah"     │
   │  kecepatan: 0       │
   └─────────────────────┘
```

### 1.1 Prosedural vs OOP

| Aspek | Prosedural | OOP |
| :--- | :--- | :--- |
| Fokus | Fungsi & langkah urut | Objek & interaksi antar objek |
| Data | Terpisah dari fungsi | Dibungkus dalam class bersama fungsi |
| Reusability | Sulit (copy-paste) | Mudah (inheritance, trait) |
| Skalabilitas | Terbatas (rawan spageti code) | Tinggi (cocok untuk app besar) |
| Cocok untuk | Script kecil, cron jobs | Aplikasi web, API, sistem kompleks |

## 2. Class & Object

### 2.1 Sintaks Dasar

```php
<?php
class Mobil {
    // Properties
    public string $merek;
    public string $warna;
    public int $kecepatan = 0;

    // Methods
    public function nyalakan(): void {
        echo "🔥 {$this->merek} dinyalakan\n";
    }

    public function gas(int $tambah = 10): void {
        $this->kecepatan += $tambah;
        echo "💨 Kecepatan sekarang: {$this->kecepatan} km/jam\n";
    }

    public function rem(): void {
        $this->kecepatan = max(0, $this->kecepatan - 10);
        echo "🛑 Kecepatan turun ke {$this->kecepatan} km/jam\n";
    }
}

// Instantiate (buat object)
$mobilSaya = new Mobil();
$mobilSaya->merek = "Toyota";
$mobilSaya->warna = "Merah";

$mobilSaya->nyalakan();  // 🔥 Toyota dinyalakan
$mobilSaya->gas(50);    // 💨 Kecepatan sekarang: 50 km/jam
$mobilSaya->gas();      // 💨 Kecepatan sekarang: 60 km/jam
$mobilSaya->rem();      // 🛑 Kecepatan turun ke 50 km/jam
```

> [!TIP]
`$this` merujuk ke **object saat ini** (instance yang sedang memanggil method). Tanpa `$this->`, PHP menganggap variabel tersebut sebagai variabel lokal biasa di dalam fungsi.

### 2.2 Banyak Object dari Satu Class

Satu class bisa dipakai membuat banyak object. Setiap object punya data propertinya sendiri-sendiri (tidak berbagi).

```php
<?php
$mobil1 = new Mobil();
$mobil1->merek = "Honda";

$mobil2 = new Mobil();
$mobil2->merek = "Suzuki";

$mobil1->gas(100);
echo $mobil2->kecepatan;  // Masih 0, karena beda object
```

## 3. Property

### 3.1 Visibility Modifier

Mengontrol dari mana property bisa diakses.

| Modifier | Dari dalam class | Subclass (Child) | Luar class |
| :--- | :---: | :---: | :---: |
| `public` | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ❌ |
| `private` | ✅ | ❌ | ❌ |

```php
<?php
class User {
    public    string $nama;        // Bisa diakses dari mana saja
    protected string $email;       // Hanya class ini & subclass
    private   string $password;    // Hanya class ini sendiri
}

$u = new User();
$u->nama = "Budi";         // ✅ OK
// $u->email = "b@x.com";  // ❌ Error fatal
// $u->password = "rahasia"; // ❌ Error fatal
```

### 3.2 Typed Properties (PHP 7.4+)

Wajib deklarasikan tipe data agar PHP memvalidasi otomatis.

```php
<?php
class Produk {
    public string $nama;
    public int $harga;
    public bool $tersedia = true;
    public ?string $deskripsi = null;  // nullable (bisa string atau null)
}

$p = new Produk();
$p->nama = "Laptop";
$p->harga = 15000000;
// $p->harga = "murah";  // ❌ TypeError — harus int
```

### 3.3 Static Property

Property milik **class**, bukan object. Bisa diakses tanpa instantiate `new`.

```php
<?php
class Counter {
    public static int $total = 0;

    public function __construct() {
        self::$total++;
    }
}

new Counter();
new Counter();
new Counter();

echo Counter::$total;  // 3 — diakses langsung via nama class
```

> [!IMPORTANT]
`self::` merujuk ke class itu sendiri, sedangkan `$this->` merujuk ke object. Static property/method pakai `self::` atau `NamaClass::`.

### 3.4 Constant di Class

Mirip constant global, tapi dibungkus dalam class.

```php
<?php
class Config {
    const VERSION = "1.0.0";
    public const MAX_LOGIN_ATTEMPT = 5;
}

echo Config::VERSION;           // 1.0.0
echo Config::MAX_LOGIN_ATTEMPT; // 5
```

## 4. Method

### 4.1 Method Biasa

Fungsi yang ada di dalam class, biasanya berinteraksi dengan property object.

```php
<?php
class Kalkulator {
    public function tambah(int $a, int $b): int {
        return $a + $b;
    }

    public function bagi(int $a, int $b): float {
        if ($b === 0) {
            throw new DivisionByZeroError("Tidak bisa dibagi nol");
        }
        return $a / $b;
    }
}

$calc = new Kalkulator();
echo $calc->tambah(5, 3);  // 8
echo $calc->bagi(10, 4);   // 2.5
```

### 4.2 Static Method

Method milik class, dipanggil tanpa buat object. Cocok untuk *utility/helper function*.

```php
<?php
class MathHelper {
    public static function luasLingkaran(float $r): float {
        return 3.14159 * $r * $r;
    }

    public static function luasPersegi(float $sisi): float {
        return $sisi * $sisi;
    }
}

// Dipanggil langsung pakai ::
echo MathHelper::luasLingkaran(7);    // 153.93...
echo MathHelper::luasPersegi(5);      // 25
```

### 4.3 Method dengan Default Argument

Parameter bisa punya nilai default jika tidak diisi saat pemanggilan.

```php
<?php
class Email {
    public function kirim(
        string $ke,
        string $subjek,
        string $body = "",
        bool   $html = false,
        ?string $cc = null
    ): void {
        echo "📧 Ke: $ke | Subjek: $subjek\n";
        if ($cc) echo "CC: $cc\n";
    }
}

$e = new Email();
$e->kirim("budi@mail.com", "Halo"); // pakai default
$e->kirim("budi@mail.com", "Halo", "Isi pesan", true, "cc@mail.com");
```

## 5. Constructor & Destructor

### 5.1 Constructor — `__construct()`

Method khusus yang otomatis dipanggil **saat object dibuat**. Biasanya untuk inisialisasi property awal.

```php
<?php
class Mahasiswa {
    public string $nim;
    public string $nama;
    public string $jurusan;

    public function __construct(string $nim, string $nama, string $jurusan) {
        $this->nim     = $nim;
        $this->nama    = $nama;
        $this->jurusan = $jurusan;
        echo "🎓 Mahasiswa baru terdaftar: $nama\n";
    }
}

$mhs = new Mahasiswa("2024001", "Budi", "Teknik Informatika");
// 🎓 Mahasiswa baru terdaftar: Budi
```

### 5.2 Constructor Promotion (PHP 8.0+)

Singkat: deklarasi property + assign langsung di parameter constructor. Jadi tidak perlu tulis `$this->nama = $nama;` secara manual.

```php
<?php
// Versi panjang (PHP 7)
class User1 {
    public string $nama;
    public int $umur;
    public function __construct(string $nama, int $umur) {
        $this->nama = $nama;
        $this->umur = $umur;
    }
}

// Versi constructor promotion (PHP 8+)
class User2 {
    public function __construct(
        public string $nama,
        public int $umur
    ) {}
}

$u = new User2("Budi", 20);
echo $u->nama;  // Budi
```

### 5.3 Destructor — `__destruct()`

Method khusus yang otomatis dipanggil **saat object dihancurkan** (script selesai, atau tidak ada lagi variabel yang reference ke object tersebut).

```php
<?php
class FileHandler {
    private $handle;

    public function __construct(string $path) {
        $this->handle = fopen($path, 'r');
        echo "📂 File dibuka\n";
    }

    public function baca(): string {
        return fread($this->handle, 1024);
    }

    public function __destruct() {
        fclose($this->handle);
        echo "📂 File ditutup otomatis\n";
    }
}

$f = new FileHandler("data.txt");
echo $f->baca();
unset($f);  // Destructor dipanggil → File ditutup
```

### 5.4 Diagram Lifecycle Object

```text
new Mobil("Toyota")
       │
       ▼
┌─────────────────┐
│  __construct()  │  ← Inisialisasi: set merek, isi awal
└─────────────────┘
       │
       ▼
   Object aktif (hidup di memory)
   $mobil->gas()
   $mobil->rem()
       │
       ▼
┌─────────────────┐
│   __destruct()  │  ← Cleanup: tutup file, lepas koneksi DB
└─────────────────┘
       │
       ▼
   Object dihapus dari memory oleh PHP Garbage Collector
```

> [!TIP]
Destructor cocok untuk **cleanup resource**: tutup file, tutup koneksi DB, release lock. Tapi jangan terlalu andalkan timing destructor karena PHP kadang memprosesnya di akhir eksekusi script.

## 6. `$this` vs `self` vs `static`

Sering bikin bingung. Ini bedanya:

| Keyword | Merujuk ke | Konteks |
| :--- | :--- | :--- |
| `$this->` | Instance object saat ini | Pakai untuk property/method non-static |
| `self::` | Class tempat kode ditulis (compile-time) | Pakai untuk static property/method |
| `static::` | Class yang memanggil kode (runtime / LSB) | Pakai untuk inheritance static |

```php
<?php
class Hewan {
    public static function jenis1(): string {
        return self::class;   // Selalu "Hewan" (class tempat kode ini ditulis)
    }
    public static function jenis2(): string {
        return static::class; // Bisa "Hewan" atau subclass-nya (class yang manggil)
    }
}

class Kucing extends Hewan {}

echo Kucing::jenis1();  // Hewan    (self ngga peduli siapa yang manggil)
echo Kucing::jenis2();  // Kucing   (static mendeteksi Kucing yang manggil)
```

## 7. Contoh Real-World: Class Produk

Implementasi semua yang udah dipelajari.

```php
<?php
class Produk {
    public function __construct(
        private string $nama,
        private int $harga,
        private int $stok = 0
    ) {}

    public function getNama(): string {
        return $this->nama;
    }

    public function getHarga(): int {
        return $this->harga;
    }

    public function getStok(): int {
        return $this->stok;
    }

    public function tambahStok(int $jumlah): void {
        if ($jumlah <= 0) throw new InvalidArgumentException("Jumlah harus positif");
        $this->stok += $jumlah;
    }

    public function kurangiStok(int $jumlah): bool {
        if ($this->stok < $jumlah) return false; // stok ga cukup
        $this->stok -= $jumlah;
        return true;
    }

    public function info(): string {
        return "{$this->nama} — Rp" . number_format($this->harga) .
               " (Stok: {$this->stok})";
    }
}

// Penggunaan
$p = new Produk("Laptop ASUS", 15000000, 5);
echo $p->info() . "\n";  
// Laptop ASUS — Rp15.000.000 (Stok: 5)

$p->tambahStok(3);
echo "Stok sekarang: " . $p->getStok() . "\n"; // 8

if ($p->kurangiStok(2)) {
    echo "Stok dikurangi, sisa: " . $p->getStok() . "\n"; // 6
}
```

## 8. Object Context & `instanceof`

Cek tipe object saat runtime.

```php
<?php
class Anjing {
    public function gonggong(): void { echo "Woof!\n"; }
}

class Kucing {
    public function meong(): void { echo "Meong!\n"; }
}

$hewan = new Anjing();

if ($hewan instanceof Anjing) {
    $hewan->gonggong();
} elseif ($hewan instanceof Kucing) {
    $hewan->meong();
}

// Cek apakah class ada
var_dump(class_exists("Anjing"));  // true
var_dump(get_class($hewan));       // string("Anjing")
```

## 9. Magic Methods (Ringkasan)

Method bawaan PHP yang dipanggil otomatis pada event tertentu.

| Method | Dipanggil saat |
| :--- | :--- |
| `__construct()` | Object dibuat |
| `__destruct()` | Object dihancurkan |
| `__get($name)` | Akses property tak ada / private |
| `__set($name, $value)` | Set property tak ada / private |
| `__call($name, $args)` | Memanggil method tak ada |
| `__toString()` | Object di-cast ke string (misal `echo $obj`) |
| `__clone()` | Object di-clone pakai `clone` |

```php
<?php
class Orang {
    public function __construct(public string $nama) {}

    public function __toString(): string {
        return "[Orang: {$this->nama}]";
    }
}

$org = new Orang("Budi");
echo $org;  // [Orang: Budi]  (karena __toString dipanggil otomatis)
```
