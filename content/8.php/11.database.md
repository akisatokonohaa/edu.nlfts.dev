# Koneksi Database

Menghubungkan PHP dengan MySQL menggunakan PDO (PHP Data Objects) untuk operasi CRUD yang aman dari serangan SQL Injection.

---

## 1. Mengapa Database?

PHP tanpa database ibarat toko tanpa gudang — data hilang saat halaman ditutup. Database menyimpan data **secara permanen** sehingga bisa diakses kapan saja.

```text
┌────────────┐    SQL Query    ┌────────────┐
│   PHP App  │ ──────────────► │  Database  │
│  (PDO)     │                 │  (MySQL)   │
│            │ ◄────────────── │            │
└────────────┘    Result Set   └────────────┘
```

### 1.1 Ekstensi yang Tersedia

| Ekstensi | Status | Rekomendasi |
| :--- | :--- | :--- |
| **mysql** | ❌ Deprecated (dihapus di PHP 7) | Jangan dipakai |
| **mysqli** | ✅ Aktif | Khusus MySQL, sedikit lebih cepat |
| **PDO** | ✅ Aktif | ⭐ Direkomendasikan — support 12+ database |

> [!TIP]
**Kenapa PDO?** Karena satu API bisa dipakai untuk MySQL, PostgreSQL, SQLite, SQL Server, dll. Kalau pindah database, kode cukup diubah sedikit.

## 3. Koneksi dengan PDO

### 3.1 Sintaks Dasar

```php
<?php
$host    = "localhost";
$dbname  = "toko_online";
$user    = "root";
$pass    = "";  // default XAMPP kosong

try {
    $dsn = "mysql:host=$host;dbname=$dbname;charset=utf8mb4";
    $pdo = new PDO($dsn, $user, $pass);

    // Set mode error → Exception (wajib untuk debugging jelas)
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    // Set fetch mode → Associative array by default
    $pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);

    echo "✅ Koneksi berhasil!";
} catch (PDOException $e) {
    die("❌ Koneksi gagal: " . $e->getMessage());
}
```

### 3.2 DSN (Data Source Name) per Database

| Database | DSN |
| :--- | :--- |
| MySQL | `mysql:host=localhost;dbname=toko;charset=utf8mb4` |
| PostgreSQL | `pgsql:host=localhost;port=5432;dbname=toko` |
| SQLite | `sqlite:/path/to/database.sqlite` |
| SQL Server | `sqlsrv:Server=localhost;Database=toko` |

> [!IMPORTANT]
Selalu tambahkan `charset=utf8mb4` pada DSN MySQL. Tanpa ini, emoji dan karakter khusus bisa error (default masih `latin1`).

### 3.3 File Koneksi Terpisah — `config/database.php`

```php
<?php
// config/database.php

define('DB_HOST', 'localhost');
define('DB_NAME', 'toko_online');
define('DB_USER', 'root');
define('DB_PASS', '');

function db(): PDO {
    static $pdo = null;

    if ($pdo === null) {
        try {
            $dsn = "mysql:host=" . DB_HOST . ";dbname=" . DB_NAME . ";charset=utf8mb4";
            $pdo = new PDO($dsn, DB_USER, DB_PASS, [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,  // native prepared statement
            ]);
        } catch (PDOException $e) {
            die("Database error: " . $e->getMessage());
        }
    }
    return $pdo;
}
```

```php
<?php
// pakai di file manapun
require_once "config/database.php";
$pdo = db();
```

## 4. CRUD — Create, Read, Update, Delete

### 4.1 Create (INSERT)

**❌ Cara Salah (rentan SQL Injection):**

```php
<?php
// BAHAYA! User bisa input: '; DROP TABLE produk; --
$nama = $_POST['nama'];
$pdo->query("INSERT INTO produk (nama) VALUES ('$nama')");
```

**✅ Cara Benar (Prepared Statement):**

```php
<?php
require_once "config/database.php";
$pdo = db();

// Named placeholder (:nama)
$sql = "INSERT INTO produk (nama, harga, stok, kategori)
        VALUES (:nama, :harga, :stok, :kategori)";
$stmt = $pdo->prepare($sql);

$stmt->execute([
    ':nama'     => 'Headset Gaming',
    ':harga'    => 750000,
    ':stok'     => 8,
    ':kategori' => 'elektronik'
]);

echo "ID baru: " . $pdo->lastInsertId();
```

**Atau dengan positional placeholder (?):**

```php
<?php
$sql = "INSERT INTO produk (nama, harga, stok, kategori) VALUES (?, ?, ?, ?)";
$stmt = $pdo->prepare($sql);

$stmt->execute(['Webcam HD', 350000, 15, 'elektronik']);
```

### 4.2 Read (SELECT)

```php
<?php
// Ambil semua data
$stmt = $pdo->query("SELECT * FROM produk ORDER BY id DESC");
$semuaProduk = $stmt->fetchAll();

// Ambil satu baris
$stmt = $pdo->prepare("SELECT * FROM produk WHERE id = ?");
$stmt->execute([1]);
$produk = $stmt->fetch();

// Dengan kondisi
$stmt = $pdo->prepare("SELECT * FROM produk WHERE kategori = ? AND stok > ?");
$stmt->execute(['elektronik', 5]);
$produkElektronik = $stmt->fetchAll();

// Tampilkan
foreach ($semuaProduk as $p) {
    echo "{$p['nama']} - Rp" . number_format($p['harga']) . "\n";
}
```

### 4.3 Update

```php
<?php
$stmt = $pdo->prepare("UPDATE produk SET harga = ?, stok = ? WHERE id = ?");
$stmt->execute([13000000, 3, 1]);

echo "Baris terpengaruh: " . $stmt->rowCount();
```

### 4.4 Delete

```php
<?php
$stmt = $pdo->prepare("DELETE FROM produk WHERE id = ?");
$stmt->execute([5]);

echo "Dihapus: " . $stmt->rowCount() . " baris";
```

## 5. Fetch Modes

| Mode | Hasil |
| :--- | :--- |
| `PDO::FETCH_ASSOC` | Array asosiatif: `['nama' => 'Buku']` |
| `PDO::FETCH_NUM` | Array numerik: `[0 => 'Buku']` |
| `PDO::FETCH_BOTH` | Gabungan (default): keduanya |
| `PDO::FETCH_OBJ` | Object: `$row->nama` |
| `PDO::FETCH_CLASS` | Instance class tertentu |
| `PDO::FETCH_COLUMN` | Ambil 1 kolom saja |

```php
<?php
// FETCH_COLUMN — ambil hanya kolom 'nama'
$stmt = $pdo->query("SELECT nama FROM produk");
$namaProduk = $stmt->fetchAll(PDO::FETCH_COLUMN);
// ['Laptop ASUS', 'Mouse Logitech', ...]

// FETCH_KEY_PAIR — ambil 2 kolom jadi key=>value
$stmt = $pdo->query("SELECT id, nama FROM produk");
$pairs = $stmt->fetchAll(PDO::FETCH_KEY_PAIR);
// [1 => 'Laptop ASUS', 2 => 'Mouse Logitech', ...]
```

## 7. Transaction (Transaksi Database)

Transaksi memastikan beberapa operasi berhasil **semua atau tidak sama sekali** (ACID).

```php
<?php
$pdo = db();

try {
    $pdo->beginTransaction();

    // Transfer stok dari produk A ke B
    $pdo->prepare("UPDATE produk SET stok = stok - ? WHERE id = ?")
        ->execute([2, 1]);

    $pdo->prepare("UPDATE produk SET stok = stok + ? WHERE id = ?")
        ->execute([2, 2]);

    // Catat log
    $pdo->prepare("INSERT INTO log_aktivitas (aksi) VALUES (?)")
        ->execute(['transfer stok']);

    $pdo->commit();  // Semua sukses → simpan
    echo "✅ Transfer berhasil";
} catch (Exception $e) {
    $pdo->rollBack();  // Ada error → batalkan semua
    echo "❌ Gagal: " . $e->getMessage();
}
```

> [!IMPORTANT]
Gunakan transaction ketika: transfer uang, mengurangi stok + insert order, atau operasi yang melibatkan multiple tabel terkait.

## 8. Pagination

```php
<?php
$pdo = db();
$perHalaman = 5;
$halaman    = max(1, (int)($_GET['page'] ?? 1));
$offset     = ($halaman - 1) * $perHalaman;

// Total data
$total = $pdo->query("SELECT COUNT(*) FROM produk")->fetchColumn();
$totalHalaman = ceil($total / $perHalaman);

// Ambil data halaman ini
$stmt = $pdo->prepare("SELECT * FROM produk LIMIT ? OFFSET ?");
$stmt->bindValue(1, $perHalaman, PDO::PARAM_INT);
$stmt->bindValue(2, $offset, PDO::PARAM_INT);
$stmt->execute();
$produk = $stmt->fetchAll();

// Tampilkan pagination
for ($i = 1; $i <= $totalHalaman; $i++) {
    $active = $i === $halaman ? 'font-weight:bold' : '';
    echo "<a href='?page=$i' style='$active;margin:0 5px'>$i</a>";
}
```

> [!TIP]
`LIMIT` dan `OFFSET` harus di-bind dengan `PDO::PARAM_INT`, karena secara default PDO meng-quote parameter sebagai string — bisa error di beberapa database.

## 9. Search dengan LIKE

```php
<?php
$pdo = db();

$keyword = trim($_GET['q'] ?? '');

if ($keyword !== '') {
    $stmt = $pdo->prepare(
        "SELECT * FROM produk
```

## 10. Keamanan Database

| Ancaman | Pencegahan |
| :--- | :--- |
| **SQL Injection** | Selalu pakai **prepared statement**, jangan concat string |
| **XSS** | `htmlspecialchars()` saat menampilkan data dari DB |
| **CSRF** | Token CSRF di form & session |
| **Credential leak** | Simpan password DB di file `.env` atau `config.php` (jangan di repo Git) |
| **Error leak** | Jangan tampilkan pesan error PDO ke user di production |

### 10.1 Contoh SQL Injection

```php
<?php
// ❌ RENTAN
$id = $_GET['id'];
$pdo->query("SELECT * FROM produk WHERE id = $id");

// Jika user input: 1 OR 1=1
// Query jadi: SELECT * FROM produk WHERE id = 1 OR 1=1
// → Semua data bocor!

// ✅ AMAN
$stmt = $pdo->prepare("SELECT * FROM produk WHERE id = ?");
$stmt->execute([$_GET['id']]);
```

### 10.2 Mode Production

```php
<?php
// php.ini atau runtime
error_reporting(0);            // Sembunyikan error dari user
ini_set('display_errors', '0');

// Tapi log ke file
ini_set('log_errors', '1');
ini_set('error_log', '/var/log/php_errors.log');
```

## Cek Pemahaman

- [ ] Memahami perbedaan mysqli dan PDO
- [ ] Bisa membuat koneksi PDO dengan DSN yang benar
- [ ] Bisa membuat file koneksi terpisah (`config/database.php`)
- [ ] Bisa melakukan INSERT, SELECT, UPDATE, DELETE dengan prepared statement
- [ ] Memahami perbedaan `:nama` dan `?` sebagai placeholder
- [ ] Bisa membedakan `fetch()` dan `fetchAll()`
- [ ] Tahu berbagai fetch mode (ASSOC, NUM, OBJ, COLUMN, KEY_PAIR)
- [ ] Bisa membangun aplikasi CRUD lengkap (list, create, edit, show, delete)
- [ ] Memahami kapan menggunakan transaction
- [ ] Bisa membuat pagination dengan LIMIT & OFFSET
- [ ] Bisa membuat search dengan LIKE
- [ ] Memahami bahaya SQL Injection dan cara mencegahnya

---

*Kalau semua checklist di atas sudah dicentang, kamu siap lanjut ke materi berikutnya: **OOP Dasar**.*
