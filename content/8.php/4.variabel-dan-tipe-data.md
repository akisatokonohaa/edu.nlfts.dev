# Variabel & Tipe Data

Memahami cara menyimpan, mengelola, dan menggunakan data dalam PHP menggunakan **variabel** serta mengenali berbagai **tipe data** yang tersedia. Variabel dan tipe data merupakan konsep dasar yang sangat penting karena hampir setiap program membutuhkan tempat untuk menyimpan dan mengolah informasi.

Pada bagian ini, kamu akan mempelajari cara membuat variabel, memberikan nilai, mengubah nilai, serta menggunakan variabel dalam berbagai operasi dan proses program. Selain itu, kamu juga akan mengenal tipe data yang digunakan PHP untuk menentukan jenis nilai yang sedang diproses.

---

## 1. Apa Itu Variabel dan Tipe Data?

**Variabel** adalah tempat untuk menyimpan sebuah nilai yang dapat digunakan dan diubah selama program berjalan. Dalam PHP, variabel ditandai dengan simbol `$` diikuti dengan nama variabel.

Contoh:

```php
$nama = "Radiedtya";
$umur = 17;

echo $nama;
echo $umur;
```

Pada contoh tersebut, `$nama` dan `$umur` merupakan variabel yang digunakan untuk menyimpan data.

---

**Tipe data** adalah jenis atau kategori dari sebuah nilai yang disimpan di dalam variabel. PHP memiliki beberapa tipe data yang umum digunakan, seperti:

* `String` — digunakan untuk menyimpan teks.
* `Integer` — digunakan untuk menyimpan bilangan bulat.
* `Float` — digunakan untuk menyimpan bilangan desimal.
* `Boolean` — digunakan untuk menyimpan nilai `true` atau `false`.
* `Array` — digunakan untuk menyimpan kumpulan beberapa nilai.
* `Object` — digunakan untuk menyimpan data dan perilaku dalam konsep OOP.
* `NULL` — menunjukkan bahwa sebuah variabel tidak memiliki nilai.
* `Resource` — digunakan untuk menyimpan referensi terhadap resource eksternal tertentu.

Dengan memahami variabel dan tipe data, kamu akan memiliki dasar yang kuat untuk mengolah informasi, membuat logika program, dan melanjutkan ke materi PHP yang lebih kompleks.

---
## 2. Aturan Penamaan Variabel

PHP memiliki aturan ketat dalam penamaan variabel:

| Aturan | Benar | Salah |
| :--- | :---: | :---: |
| Harus diawali tanda dolar `$` | `$nama` | `nama` |
| Setelah `$`, huruf atau `_` saja | `$_data`, `$nama` | `$1data`, `$@nama` |
| Setelah karakter pertama, boleh huruf, angka, `_` | `$nama1`, `$data_2` | `$nama!` |
| **Case-sensitive** (huruf besar/kecil berbeda) | `$Nama` ≠ `$nama` | — |
| Tidak boleh menggunakan *reserved keyword* | `$_if`, `$forLoop` | `$if`, `$for`, `$echo` |
---
## 3. Konvensi Penamaan (Best Practice)

Tidak wajib, tapi sangat direkomendasikan agar kode mudah dibaca:

```php
<?php
// ✅ camelCase — paling umum untuk variabel
$namaLengkap = "Budi Santoso";
$hargaBarang = 15000;
$jumlahPembelian = 3;

// ✅ snake_case — juga umum, terutama di proyek tertentu
$nama_lengkap = "Budi Santoso";
$harga_barang = 15000;

// ❌ Hindari — susah dibaca
$namalengkap = "Budi Santoso";
$NamaLengkap = "Budi Santoso";  // konsistensi huruf besar kecil juga penting
```

> [!TIP]
Rekomendasi: Pilih satu konvensi (camelCase atau snake_case) dan konsisten menggunakannya di seluruh proyek. Dalam panduan ini, kita menggunakan camelCase.

## 4. Mendeklarasikan Variabel
Di PHP, variabel tidak perlu dideklarasikan dengan tipe data. Cukup tulis $nama = nilai; dan PHP akan otomatis menentukan tipe datanya.
```php
<?php
// Deklarasi dan assignment sekaligus
 $nama = "Andi";          // String
 $umur = 25;              // Integer
 $tinggi = 172.5;         // Float
 $aktif = true;           // Boolean
 $alamat = null;          // Null
```
Tidak seperti bahasa seperti Java atau C++, kamu tidak bisa mendeklarasikan variabel tanpa nilai (kecuali dengan `null`):
```php
<?php
// ❌ Error — undefined variable
echo $belumDidefinisikan;

// ✅ Benar — inisialisasi dengan null
$belumDidefinisikan = null;
echo $belumDidefinisikan;  // (tidak menampilkan apa-apa karna isinya null/kosong)
```

## 5. Menampilkan Variabel
```php
<?php

$nama = "Sari";
$umur = 22;

// Menggunakan echo dengan concatenation (titik)
echo "Nama: " . $nama . ", Umur: " . $umur;

// Menggunakan double quotes (variabel otomatis diproses)
echo "Nama: $nama, Umur: $umur";

// Menggunakan curly braces untuk kejelasan
echo "Nama: {$nama}, Umur: {$umur} tahun";
```
### 5.1 Perbedaan Single Quotes vs Double Quotes
| Aspek | Single Quotes `'...'` | Double Quotes `"..."` |
| :--- | :--- | :--- |
| **Variabel** | Tidak diproses — ditampilkan apa adanya | Diproses — nilainya ditampilkan |
| **Escape character** | Hanya `\'` dan `\\` | Mendukung `\n`, `\t`, `\$`, `\"`, dll. |
| **Kecepatan** | Sedikit lebih cepat | Sedikit lebih lambat |

```php
<?php

$buah = "mangga";

echo 'Saya suka $buah';      // Saya suka $buah  (variabel tidak diproses)
echo "Saya suka $buah";      // Saya suka mangga (variabel diproses)
echo 'Saya suka \'mangga\''; // Saya suka 'mangga'
echo "Baris 1\nBaris 2";     // Baris 1 (newline) Baris 2
echo 'Baris 1\nBaris 2';     // Baris 1\nBaris 2  (tidak diproses)
```
> [!TIP]
Gunakan single quotes untuk teks biasa tanpa variabel, dan double quotes saat butuh menampilkan variabel atau escape character.
---
## 6. Curly Brace Syntax untuk Variabel Kompleks
Jika variabel berada di samping karakter yang bisa membingungkan parser, gunakan `{}`:
```php
<?php

$makanan = "nasi";

// ❌ Ambigu — PHP bingung mencari variabel $makananan
echo "Saya makan $makananan";

// ✅ Jelas — curly brace membatasi nama variabel
echo "Saya makan {$makanan}an";

// ✅ Bisa juga dengan concatenation
echo "Saya makan " . $makanan . "an";
```
Curly braces juga berguna untuk mengakses elemen array di dalam string:
```php
<?php

$data = ["nama" => "Budi", "umur" => 25];
echo "Nama: {$data['nama']}, Umur: {$data['umur']}";
```

## 7. Tipe Data dalam PHP
PHP adalah bahasa **dynamically typed** — tipe data variabel ditentukan otomatis berdasarkan nilai yang disimpan, dan bisa berubah kapan saja.

### 7.1 Ringkasan Tipe Data
```text
Tipe Data PHP
├── Scalar (Sederhana)
│   ├── String      → "Halo", "123"
│   ├── Integer     → 25, -10, 0
│   ├── Float       → 3.14, -0.5, 1.5e3
│   └── Boolean     → true, false
│
├── Compound (Gabungan)
│   ├── Array       → [1, 2, 3], ["a" => 1]
│   └── Object      → $obj = new MyClass()
│
├── Special (Khusus)
│   ├── NULL        → null
│   └── Resource    → database connection, file handle
│
└── Pseudo-types (Dokumentasi)
    ├── mixed       → tipe apa saja
    ├── void        → tidak mengembalikan nilai
    └── callable    → bisa dipanggil sebagai fungsi

```
---
### 7.2 String
String adalah kumpulan karakter (teks). Bisa ditulis dengan single quotes, double quotes, heredoc, atau nowdoc.
```php
<?php
 $satu = 'Halo Dunia';                    // Single quotes
 $dua = "Baris baru:\nHalo lagi";         // Double quotes dengan escape
 $tiga = <<<HTML                          // Heredoc
    <p>Ini paragraf
    dengan beberapa baris.</p>
HTML;
 $empat = <<<'TEXT'                       // Nowdoc
    Teks ini $tidak diproses.
TEXT;
```
**Fungsi-fungsi string yang penting:**
| Fungsi | Keterangan | Contoh |
| :--- | :--- | :--- |
| `strlen()` | Menghitung panjang string | `strlen("Halo")` → `4` |
| `strtoupper()` | Ubah ke huruf kapital | `strtoupper("halo")` → `"HALO"` |
| `strtolower()` | Ubah ke huruf kecil | `strtolower("HALO")` → `"halo"` |
| `str_replace()` | Mengganti bagian string | `str_replace("a", "o", "mata")` → `"moto"` |
| `substr()` | Mengambil bagian string | `substr("Halo", 1, 2)` → `"al"` |
| `explode()` | Memecah string jadi array | `explode(",", "a,b,c")` → `["a","b","c"]` |
| `implode()` | Menggabungkan array jadi string | `implode("-", [1,2,3])` → `"1-2-3"` |
| `trim()` | Menghapus spasi di awal & akhir | `trim("  halo  ")` → `"halo"` |
| `str_contains()` | Cek apakah string mengandung substring* | `str_contains("Halo", "al")` → `true` |
| `str_starts_with()` | Cek awalan string* | `str_starts_with("Halo", "Ha")` → `true` |
| `str_ends_with()` | Cek akhiran string* | `str_ends_with("Halo", "lo")` → `true` |

> [!INFO]
**Tersedia sejak PHP 8.0**

### 7.3 Integer
Bilangan bulat, positif atau negatif, tanpa desimal.
```php
<?php

$angka = 42;
$negatif = -15;
$nol = 0;
$oktal = 0755;        // Prefiks 0 → oktal (493 dalam desimal)
$heksa = 0x1A;        // Prefiks 0x → heksadesimal (26 dalam desimal)
$biner = 0b1010;      // Prefiks 0b → biner (10 dalam desimal)
```
**Batas nilai integer** bergantung pada arsitektur sistem:
| Sistem | Batas Integer |
| :--- | :--- |
| 64-bit | ±9.223.372.036.854.775.807 |
| 32-bit | ±2.147.483.647 |

Jika melebihi batas, PHP otomatis mengkonversinya ke **float**.
```php
<?php

$besar = PHP_INT_MAX;       // Nilai integer terbesar
echo $besar;                // 9223372036854775807 (64-bit)
echo gettype($besar);       // integer

$lebihBesar = $besar + 1;
echo gettype($lebihBesar);  // double (otomatis jadi float)
```
**Fungsi yang berguna:**
| Fungsi | Keterangan | Contoh |
| :--- | :--- | :--- |
| `PHP_INT_MAX` | Konstanta integer terbesar | `PHP_INT_MAX` |
| `PHP_INT_MIN` | Konstanta integer terkecil | `PHP_INT_MIN` |
| `is_int()` | Cek apakah integer | `is_int(42)` → `true` |
| `abs()` | Nilai mutlak | `abs(-5)` → `5` |
| `round()` | Pembulatan | `round(3.6)` → `4` |
| `ceil()` | Pembulatan ke atas | `ceil(3.1)` → `4` |
| `floor()` | Pembulatan ke bawah | `floor(3.9)` → `3` |
---
### 7.4 Float
Bilangan desimal (pecahan), juga disebut **double** di PHP.
```php
<?php

$phi = 3.14;
$negatif = -0.75;
$notasiIlmiah = 1.5e3;     // 1.5 × 10³ = 1500.0
$kecil = 2.5E-4;           // 2.5 × 10⁻⁴ = 0.00025
```
> [!DANGER]
**Float** memiliki ketidakpastian pada operasi desimal karena cara komputer menyimpan bilangan pecahan (floating-point arithmetic).
```php
<?php

// ❌ Jangan bandingkan float dengan == secara langsung
$result = 0.1 + 0.2;
var_dump($result == 0.3);    // bool(false) !

// Mengapa? Karena 0.1 + 0.2 sebenarnya = 0.30000000000000004...

// ✅ Gunakan perbandingan dengan toleransi
$epsilon = 0.00001;
$result = 0.1 + 0.2;
var_dump(abs($result - 0.3) < $epsilon);  // bool(true)
```
---
### 7.5 Boolean
Hanya memiliki dua nilai: `true` atau `false`. Sering digunakan untuk kondisi dan perbandingan.
```php
<?php

$aktif = true;
$blokir = false;
```
Nilai yang dianggap false (falsy values) dalam PHP:
| Nilai | Keterangan |
| :--- | :--- |
| `false` | Boolean false |
| `0` | Integer 0 |
| `0.0` | Float 0.0 |
| `""` | String kosong |
| `"0"` | String "0" |
| `[]` atau `array()` | Array kosong |
| `null` | Nilai NULL |
| **SimpleXML object** (dari *empty element*) | Kasus khusus |

Semua nilai selain yang ada di tabel di atas dianggap `true` (*truthy*), termasuk string `"false"`, integer `-1`, dan array berisi `false`.
```php
<?php

// Semua ini bernilai TRUE
var_dump((bool) "Halo");      // true
var_dump((bool) "false");     // true  (karena string tidak kosong!)
var_dump((bool) -1);          // true
var_dump((bool) [0]);         // true  (array tidak kosong)

// Semua ini bernilai FALSE
var_dump((bool) "");          // false
var_dump((bool) "0");         // false
var_dump((bool) 0);           // false
var_dump((bool) null);        // false
var_dump((bool) []);          // false
```
---
### 7.6 NULL
Mewakili **tidak ada nilai**. Sebuah variabel bernilai `null` berarti variabel tersebut tidak memiliki data.
```php
<?php

$belumDiisi = null;

// Menghapus nilai variabel (menjadikannya null)
$nama = "Andi";
$nama = null;     // $nama sekarang null

// Cek apakah null
$isNull = is_null($belumDiisi);  // true
```
Perbedaan `null` dan string kosong `""` :
```php
<?php
$a = null;
$b = "";

var_dump($a === null);   // true
var_dump($b === null);   // false

var_dump(empty($a));     // true
var_dump(empty($b));     // true  (keduanya dianggap "kosong")
```

### 7.7 Array
Array digunakan untuk menyimpan kumpulan nilai dalam satu variabel. Array akan dibahas secara mendalam di materi tersendiri, tapi berikut gambaran singkatnya:
```php
<?php
// Indexed Array (berdasarkan urutan)
$buah = ["Apel", "Mangga", "Jeruk"];
echo $buah[0];  // Apel

// Associative Array (berdasarkan key)
 $mahasiswa = [
    "nama" => "Budi",
    "nim"  => "2024001",
    "ipk"  => 3.85
];
echo $mahasiswa["nama"];  // Budi
```

### 7.8 Object
Object adalah instansi dari sebuah class. Akan dibahas mendalam di materi OOP.

```php
<?php

class Mobil {
    public $merk;
    public $warna;
}

 $mobilSaya = new Mobil();
 $mobilSaya->merk = "Toyota";
 $mobilSaya->warna = "Hitam";

echo $mobilSaya->merk;  // Toyota
```

## 8. Mengecek Tipe Data
PHP menyediakan fungsi untuk mengecek dan mengidentifikasi tipe data.

### 8.1 `gettype()`
Mendapatkan nama tipe data
```php
<?php

echo gettype(42);          // integer
echo gettype(3.14);        // double
echo gettype("Halo");      // string
echo gettype(true);        // boolean
echo gettype(null);        // NULL
echo gettype([1, 2, 3]);   // array
echo gettype(new stdClass()); // object
```
### 8.2 `var_dump()`
Informasi lengkap (sangat berguna untuk *debugging*)
```php
<?php
var_dump(42);
// int(42)

var_dump(3.14);
// float(3.14)

var_dump("Halo");
// string(4) "Halo"

var_dump(true);
// bool(true)

var_dump(null);
// NULL

var_dump([1, "dua", 3.0]);
// array(3) {
//   [0]=>
//   int(1)
//   [1]=>
//   string(3) "dua"
//   [2]=>
//   float(3)
// }
```
> [!TIP]
Tips Debugging: `var_dump()` adalah sahabat terbaikmu saat *debugging*. Gunakan daripada `echo` karena menampilkan tipe data dan panjang string sekaligus.
---
### 8.3 `is_*()` 
Cek tipe data spesifik
```php
<?php

$nilai = "42";

is_string($nilai);   // true
is_int($nilai);      // false
is_float($nilai);    // false
is_bool($nilai);     // false
is_null($nilai);     // false
is_array($nilai);    // false
is_numeric($nilai);  // true  (string "42" dianggap numerik)

$angka = 42;
is_int($angka);      // true
is_numeric($angka);  // true
```
#### Tabel lengkap fungsi pengecekan
| Fungsi | Mengembalikan `true` jika |
| :--- | :--- |
| `is_string($x)` | String |
| `is_int($x)` / `is_integer($x)` / `is_long($x)` | Integer |
| `is_float($x)` / `is_double($x)` | Float |
| `is_bool($x)` | Boolean |
| `is_null($x)` | NULL |
| `is_array($x)` | Array |
| `is_object($x)` | Object |
| `is_numeric($x)` | Numerik (angka atau string angka) |
| `is_scalar($x)` | Scalar (int, float, string, bool) |
| `is_callable($x)` | Bisa dipanggil sebagai fungsi |

## 9. Type Casting (Konversi Tipe Data)
Kadang kamu perlu mengubah tipe data secara eksplisit. PHP menyediakan dua cara:
### 9.1 Cara 1 — Casting Operator
```php
<?php
$nilai = "42";

// Cast ke integer
$int = (int) $nilai;       // 42
$int = intval($nilai);     // 42 (fungsi alternatif)

// Cast ke float
$float = (float) $nilai;   // 42.0
$float = floatval($nilai); // 42.0

// Cast ke string
$str = (string) 42;        // "42"
$str = strval(42);         // "42"

// Cast ke boolean
$bool = (bool) 1;          // true
$bool = (bool) "";         // false

// Cast ke array
$arr = (array) "Halo";     // ["Halo"]

// Cast ke object
$obj = (object) "Halo";    // object dengan property scalar = "Halo"
```
### 9.2 Cara 2 — Fungsi `settype()`
Berbeda dengan casting operator yang mengembalikan nilai baru, `settype()` mengubah tipe data variabel itu sendiri (*pass by reference*).
```php
<?php

$angka = "100";

// settype mengubah variabel langsung
$hasil = settype($angka, "integer");

echo gettype($angka);  // integer
echo $angka;           // 100
var_dump($hasil);      // bool(true) — mengembalikan status berhasil/gagal
```
#### Hasil Casting yang Perlu Diperhatikan
```php
<?php

// String ke Integer — mengambil angka dari awal string
var_dump((int) "42abc");     // int(42)
var_dump((int) "abc42");     // int(0)
var_dump((int) "3.14");      // int(3)

// Float ke Integer — dipotong, dibulatkan ke bawah
var_dump((int) 3.9);         // int(3)
var_dump((int) -3.9);        // int(-3)

// Boolean ke Integer/String
var_dump((int) true);        // int(1)
var_dump((int) false);       // int(0)
var_dump((string) true);     // string(1) "1"
var_dump((string) false);    // string(0) ""

// NULL ke tipe lain
var_dump((int) null);        // int(0)
var_dump((string) null);     // string(0) ""
var_dump((bool) null);       // bool(false)

// Array ke Integer/Boolean
var_dump((int) [1, 2]);      // int(1)
var_dump((bool) []);         // bool(false)
var_dump((bool) [1, 2]);     // bool(true)
```

## 10. Type Juggling (Perubahan Tipe Otomatis)
PHP secara otomatis mengubah tipe data berdasarkan konteks penggunaan. Ini disebut type juggling.
```php
<?php
// Integer + Float → otomatis jadi Float
$hasil = 5 + 2.5;
var_dump($hasil);  // float(7.5)

// Integer + String angka → otomatis String dikonversi ke Integer
$hasil = 10 + "5";
var_dump($hasil);  // int(15)

// String + Integer → otomatis Integer dikonversi ke String
$hasil = "Halo " . 42;
var_dump($hasil);  // string(7) "Halo 42"

// Perbandingan antar tipe
var_dump(0 == "Halo");    // true  (!) — "Halo" diubah jadi 0
var_dump(0 == "0");       // true
var_dump("" == null);     // true
var_dump(0 == null);      // true
```
> [!DANGER]
Bahaya type juggling pada perbandingan `==`: Gunakan `===` (*strict comparison*) untuk menghindari kejutan tidak terduga.
```php
<?php
// == (loose) — membandingkan nilai setelah type juggling
var_dump(0 == "Halo");     // true  (!)
var_dump(0 == false);      // true
var_dump("" == null);      // true

// === (strict) — membandingkan nilai DAN tipe data
var_dump(0 === "Halo");    // false
var_dump(0 === false);     // false
var_dump("" === null);     // false
```
> [!TIP]
Aturan emas: Selalu gunakan `===` dan `!==` kecuali kamu benar-benar menginginkan type juggling.

## 11. Konstanta
Konstanta mirip variabel, tetapi nilainya tidak bisa diubah setelah didefinisikan.

### 11.1 Perbedaan Variabel dan Konstanta
| Aspek | Variabel | Konstanta |
| :--- | :--- | :--- |
| **Awalan** | `$` | Tanpa `$` |
| **Nilai** | Bisa diubah | Tidak bisa diubah |
| **Scope** | Bergantung posisi (local/global) | Global otomatis |
| **Definisi** | Langsung assign | `const` atau `define()` |
| **Tipe data** | Semua tipe | Scalar saja (string, int, float, bool, null) |

### 11.2 Cara Membuat Konstanta
**Cara 1** — `const` (direkomendasikan):
```php
<?php

const NAMA_APLIKASI = "Toko Online";
const VERSI = "1.0";
const MAKSIMAL_LOGIN = 3;
const PHI = 3.14;
const MODE_DEBUG = false;
```
**Cara 2** — `define()` :
```php
<?php

define("NAMA_APLIKASI", "Toko Online");
define("VERSI", "1.0");
define("MAKSIMAL_LOGIN", 3);
```
### 11.3 Kapan Pakai `const` vs `define()`?
| Aspek | `const` | `define()` |
| :--- | :--- | :--- |
| **Waktu eksekusi** | *Compile time* (lebih cepat) | *Runtime* |
| **Tempat definisi** | Hanya di *top-level scope* (bukan di dalam fungsi/if) | Bisa di mana saja, termasuk di dalam fungsi/if |
| **Case-insensitive** | Tidak bisa | Bisa (`define("FOO", 1, true)`) |
| **Array sebagai nilai** | Bisa (PHP 7.0+) | Bisa (PHP 7.0+) |
| **Rekomendasi** | ✅ Untuk kebanyakan kasus | Hanya jika butuh definisi dinamis |
```php
<?php
// ❌ const tidak bisa di dalam fungsi
function setup() {
    const NAMA = "Test";  // Parse error!
}

// ✅ define bisa di dalam fungsi
function setup() {
    define("NAMA", "Test");  // Berhasil
}

// ✅ const di top-level — ini yang benar
const NAMA = "Test";
```
### 11.4 Konstanta Bawaan PHP (Magic Constants)
PHP memiliki konstanta khusus yang nilainya berubah tergantung konteks:
| Konstanta | Keterangan |
| :--- | :--- |
| `__FILE__` | Path lengkap file saat ini |
| `__LINE__` | Nomor baris saat ini |
| `__DIR__` | Direktori file saat ini |
| `__FUNCTION__` | Nama fungsi saat ini |
| `__CLASS__` | Nama class saat ini |
| `__METHOD__` | Nama method saat ini |
| `__NAMESPACE__` | Nama namespace saat ini |
| `__TRAIT__` | Nama trait saat ini |

```php
<?php
echo __FILE__;    // C:\xampp\htdocs\belajar\04-variabel.php
echo __LINE__;    // 3
echo __DIR__;     // C:\xampp\htdocs\belajar
```

## Latihan Praktik
Buat file baru `4.variabel-dan-tipe-data.php`:
```php
<?php
// === Latihan 1: Deklarasi variabel ===
 $nama = "Rina Wijaya";
 $umur = 23;
 $tinggi = 165.5;
 $studentActive = true;
 $hobi = null;

echo "<h3>Latihan 1: Profil</h3>";
echo "Nama: $nama<br>";
echo "Umur: $umur tahun<br>";
echo "Tinggi: $tinggi cm<br>";
echo "Status Mahasiswa: " . ($studentActive ? "Aktif" : "Tidak Aktif") . "<br>";
echo "Hobi: " . ($hobi ?? "Belum diisi") . "<br>";

// === Latihan 2: Cek tipe data ===
echo "<h3>Latihan 2: Cek Tipe Data</h3>";
 $datas = [$nama, $umur, $tinggi, $studentActive, $hobi, [1, 2, 3]];

foreach ($datas as $data) {
    echo gettype($data) . ": ";
    var_dump($data);
    echo "<br>";
}

// === Latihan 3: Type casting ===
echo "<h3>Latihan 3: Type Casting</h3>";
 $hargaString = "25000";
 $hargaInt = (int) $hargaString;
 $hargaFormatted = "Rp" . number_format($hargaInt, 0, ',', '.');
echo "String: \"$hargaString\" → Tipe: " . gettype($hargaString) . "<br>";
echo "Integer: $hargaInt → Tipe: " . gettype($hargaInt) . "<br>";
echo "Formatted: $hargaFormatted<br>";

// === Latihan 4: Type juggling danger ===
echo "<h3>Latihan 4: Perbandingan == vs ===</h3>";
 $tests = [
    [0, "0", "0 == '0'"],
    [0, "Halo", "0 == 'Halo'"],
    [0, false, "0 == false"],
    ["", null, "'' == null"],
];

foreach ($tests as $test) {
    $loose = $test[0] == $test[1] ? "true" : "false";
    $strict = $test[0] === $test[1] ? "true" : "false";
    echo "$test[2]  →  == : $loose  |  === : $strict<br>";
}

// === Latihan 5: Konstanta ===
echo "<h3>Latihan 5: Konstanta</h3>";
const APP_NAME = "Belajar PHP";
const APP_VERSION = "1.0.0";
const MAX_USERS = 100;
const DISKON_MEMBER = 0.15;

echo "Aplikasi: " . APP_NAME . " v" . APP_VERSION . "<br>";
echo "Maksimal pengguna: " . MAX_USERS . "<br>";
 $harga = 50000;
 $potongan = $harga * DISKON_MEMBER;
printf("Harga: Rp%s → Diskon: Rp%s → Bayar: Rp%s<br>",
    number_format($harga, 0, ',', '.'),
    number_format($potongan, 0, ',', '.'),
    number_format($harga - $potongan, 0, ',', '.')
);

// === Latihan 6: String functions ===
echo "<h3>Latihan 6: Fungsi String</h3>";
 $kalimat = "  Belajar PHP itu Menyenangkan  ";
echo "Original: \"$kalimat\"<br>";
echo "Trimmed: \"" . trim($kalimat) . "\"<br>";
echo "Lowercase: \"" . strtolower(trim($kalimat)) . "\"<br>";
echo "Uppercase: \"" . strtoupper(trim($kalimat)) . "\"<br>";
echo "Replace: \"" . str_replace("Menyenangkan", "Mudah", trim($kalimat)) . "\"<br>";
echo "Length: " . strlen(trim($kalimat)) . "<br>";
echo "Contains 'PHP': " . (str_contains($kalimat, "PHP") ? "Ya" : "Tidak") . "<br>";
echo "Starts with 'Belajar': " . (str_starts_with(trim($kalimat), "Belajar") ? "Ya" : "Tidak") . "<br>";
```
