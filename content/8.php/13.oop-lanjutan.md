# OOP Lanjutan

Encapsulation, Inheritance, Polymorphism, dan Abstraction — empat pilar utama OOP yang bikin kode rapi, reusable, dan gampang di-maintain.

---

## 1. Empat Pilar OOP

| Pilar | Inti | Contoh |
| :--- | :--- | :--- |
| **Encapsulation** | Membungkus data + behavior, kontrol akses | `private $saldo`, getter/setter |
| **Inheritance** | Pewarisan property/method antar class | `class Kucing extends Hewan` |
| **Polymorphism** | Satu interface, banyak bentuk implementasi | `override`, `interface` |
| **Abstraction** | Sembunyikan detail rumit, tampilkan hanya yang penting | `abstract class`, `interface` |

```text
        ┌──────────────────────────┐
        │      Empat Pilar OOP     │
        └──────────┬───────────────┘
                   │
   ┌───────────────┼───────────────┐
   │               │               │
┌──▼───┐   ┌───────▼────────┐   ┌──▼──────────┐   ┌─────────────┐
│Encap.│   │  Inheritance   │   │Polymorphism │   │ Abstraction │
└──────┘   └────────────────┘   └─────────────┘   └─────────────┘
```

## 2. Encapsulation (Enkapsulasi)

Membungkus data dalam class dan mengontrol aksesnya via getter/setter. Tujuannya: melindungi data dari perubahan ngawur dari luar class.

### 2.1 Tanpa Encapsulation (❌ Buruk)

```php
<?php
class RekeningBuruk {
    public float $saldo;
}

$rek = new RekeningBuruk();
$rek->saldo = -1000000;  // Bisa di-set negatif! Saldo jadi ngaco 💀
```

### 2.2 Dengan Encapsulation (✅ Baik)

```php
<?php
class Rekening {
    private float $saldo = 0;

    public function getSaldo(): float {
        return $this->saldo;
    }

    public function setor(float $jumlah): void {
        if ($jumlah <= 0) {
            throw new InvalidArgumentException("Jumlah harus positif");
        }
        $this->saldo += $jumlah;
    }

    public function tarik(float $jumlah): void {
        if ($jumlah <= 0) {
            throw new InvalidArgumentException("Jumlah harus positif");
        }
        if ($jumlah > $this->saldo) {
            throw new RuntimeException("Saldo tidak cukup");
        }
        $this->saldo -= $jumlah;
    }
}

$rek = new Rekening();
$rek->setor(500000);
$rek->tarik(100000);
echo $rek->getSaldo();  // 400000

// $rek->saldo = -1000;  // ❌ Error — property private
// $rek->setor(-100);   // ❌ Throw exception
```

> [!IMPORTANT]
**Aturan umum OOP:** Jadikan property `private` secara default. Buka akses hanya via method (getter/setter) yang **memvalidasi**. Ini mencegah data rusak akibat input sembarangan.

### 2.3 Read-Only & Write-Only Property

```php
<?php
class User {
    public function __construct(
        private string $nama,
        private string $email,
        private string $passwordHash
    ) {}

    // Read-only: ada getter, tidak ada setter
    public function getNama(): string { return $this->nama; }
    public function getEmail(): string { return $this->email; }

    // Write-only: ada setter, tidak ada getter (password tidak bisa dibaca)
    public function setPassword(string $plain): void {
        $this->passwordHash = password_hash($plain, PASSWORD_DEFAULT);
    }

    public function verifyPassword(string $plain): bool {
        return password_verify($plain, $this->passwordHash);
    }
}

$u = new User("Budi", "b@x.com", password_hash("rahasia", PASSWORD_DEFAULT));
echo $u->getNama();                  // Budi
// echo $u->passwordHash;           // ❌ Error
$u->setPassword("baru123");
var_dump($u->verifyPassword("baru123"));  // true
```

### 2.4 Readonly Property (PHP 8.1+)

Property yang cuma bisa di-set **sekali** (saat object dibuat), tidak bisa diubah lagi.

```php
<?php
class Produk {
    public function __construct(
        public readonly string $id,
        public readonly string $nama,
        public readonly int $harga
    ) {}
}

$p = new Produk("P001", "Laptop", 15000000);
echo $p->nama;       // ✅ Bisa baca
// $p->nama = "PC";  // ❌ Error — readonly tidak bisa diubah
```

## 3. Inheritance (Pewarisan)

Class bisa **mewarisi** property dan method dari class lain menggunakan keyword `extends`.

```text
┌─────────────────────┐
│   class Hewan       │  ← parent / base class
│  - nama             │
│  - umur             │
│  + makan()          │
│  + tidur()          │
└──────────┬──────────┘
           │ extends
   ┌───────┴────────┐
   │                │
┌──▼──────┐    ┌────▼────┐
│ Kucing  │    │  Anjing │  ← child / subclass
│ +meong()│    │ +gonggong()
└─────────┘    └─────────┘
```

### 3.1 Contoh Dasar

```php
<?php
class Hewan {
    public function __construct(
        protected string $nama,
        protected int $umur
    ) {}

    public function makan(): void {
        echo "{$this->nama} sedang makan\n";
    }

    public function tidur(): void {
        echo "{$this->nama} sedang tidur\n";
    }
}

class Kucing extends Hewan {
    public function meong(): void {
        echo "{$this->nama} berkata: Meong!\n";
    }
}

class Anjing extends Hewan {
    public function gonggong(): void {
        echo "{$this->nama} berkata: Guk guk!\n";
    }
}

$kucing = new Kucing("Tom", 3);
$kucing->makan();   // Tom sedang makan (diwarisi dari Hewan)
$kucing->meong();   // Tom berkata: Meong!

$anjing = new Anjing("Spike", 5);
$anjing->tidur();   // Spike sedang tidur
$anjing->gonggong(); // Spike berkata: Guk guk!
```

### 3.2 Override Method

Child class bisa menulis ulang method dari parent dengan nama yang sama.

```php
<?php
class Hewan {
    public function __construct(protected string $nama) {}

    public function bersuara(): string {
        return "{$this->nama} mengeluarkan suara";
    }
}

class Kucing extends Hewan {
    public function bersuara(): string {
        return "{$this->nama} berkata: Meong!";
    }
}

class Anjing extends Hewan {
    public function bersuara(): string {
        return "{$this->nama} berkata: Guk guk!";
    }
}

$hewan = [
    new Kucing("Tom"),
    new Anjing("Spike"),
    new Hewan("Makhluk")
];

foreach ($hewan as $h) {
    echo $h->bersuara() . "\n";
}
// Tom berkata: Meong!
// Spike berkata: Guk guk!
// Makhluk mengeluarkan suara
```

### 3.3 Keyword `parent::`

Memanggil method parent yang sudah di-override.

```php
<?php
class Hewan {
    public function __construct(protected string $nama) {}

    public function info(): string {
        return "Hewan: {$this->nama}";
    }
}

class Kucing extends Hewan {
    private int $jumlahKumis;

    public function __construct(string $nama, int $kumis) {
        parent::__construct($nama);  // panggil constructor parent
        $this->jumlahKumis = $kumis;
    }

    public function info(): string {
        return parent::info() . " (Kucing, kumis: {$this->jumlahKumis})";
    }
}

$k = new Kucing("Tom", 12);
echo $k->info();  // Hewan: Tom (Kucing, kumis: 12)
```

### 3.4 `final` Class & Method

Mencegah class di-extends atau method di-override.

```php
<?php
class Base {
    public function normalMethod(): void {}

    final public function tidakBolehDiubah(): void {
        echo "Implementasi ini final, anak tidak boleh override";
    }
}

// ❌ Error: Class TidakBisaDiwariskan tidak bisa di-extend
final class TidakBisaDiwariskan {}

// class Coba extends TidakBisaDiwariskan {}  // Fatal Error
```

## 4. Polymorphism (Polimorfisme)

"Poly" (banyak) + "morph" (bentuk). Method yang sama, tapi perilakunya berbeda tergantung object yang memanggilnya.

### 4.1 Polymorphism via Inheritance

```php
<?php
class Bentuk {
    public function hitungLuas(): float {
        return 0;
    }
}

class Persegi extends Bentuk {
    public function __construct(private float $sisi) {}
    public function hitungLuas(): float {
        return $this->sisi ** 2;
    }
}

class Lingkaran extends Bentuk {
    public function __construct(private float $r) {}
    public function hitungLuas(): float {
        return 3.14159 * $this->r ** 2;
    }
}

class Segitiga extends Bentuk {
    public function __construct(private float $alas, private float $tinggi) {}
    public function hitungLuas(): float {
        return 0.5 * $this->alas * $this->tinggi;
    }
}

// Polymorphism: fungsi yang sama, perilaku beda
function cetakLuas(Bentuk $b): void {
    echo "Luas: " . $b->hitungLuas() . "\n";
}

cetakLuas(new Persegi(4));           // 16
cetakLuas(new Lingkaran(7));         // 153.93...
cetakLuas(new Segitiga(6, 8));       // 24
```

> [!TIP]
Polymorphism memungkinkan kita menulis kode **generik**. Fungsi `cetakLuas()` tidak perlu tahu bentuk spesifiknya, cukup tahu bahwa semua Bentuk pasti punya `hitungLuas()`.

### 4.2 Polymorphism via Interface

```php
<?php
interface Berbicara {
    public function bicara(): string;
}

class Manusia implements Berbicara {
    public function __construct(private string $nama) {}
    public function bicara(): string {
        return "{$this->nama}: Halo, saya manusia";
    }
}

class Robot implements Berbicara {
    public function bicara(): string {
        return "Beep boop. Saya robot.";
    }
}

class Parrot implements Berbicara {
    public function bicara(): string {
        return "Squawk! Squawk!";
    }
}

function ajakBicara(Berbicara $obj): void {
    echo $obj->bicara() . "\n";
}

ajakBicara(new Manusia("Budi"));
ajakBicara(new Robot());
ajakBicara(new Parrot());
```

## 5. Abstraction (Abstraksi)

Sembunyikan detail implementasi yang rumit, tampilkan hanya kontrak (apa yang bisa dilakukan) ke pengguna class.

### 5.1 Abstract Class

Class yang **tidak bisa di-instantiate** (tidak bisa di-`new`), harus di-extend dulu. Bisa punya method abstract (wajib di-override) dan method konkret.

```php
<?php
abstract class Kendaraan {
    public function __construct(protected string $merk) {}

    // Method konkret — sudah ada implementasi
    public function infoMerk(): string {
        return "Merk: {$this->merk}";
    }

    // Method abstract — wajib di-override di subclass
    abstract public function jumlahRoda(): int;
    abstract public function bunyiKlakson(): string;
}

class Mobil extends Kendaraan {
    public function jumlahRoda(): int {
        return 4;
    }
    public function bunyiKlakson(): string {
        return "Tin! Tin!";
    }
}

class Motor extends Kendaraan {
    public function jumlahRoda(): int {
        return 2;
    }
    public function bunyiKlakson(): string {
        return "Tet! Tet!";
    }
}

// $k = new Kendaraan("X");  // ❌ Error — abstract class tidak bisa di-instantiate
$mobil = new Mobil("Toyota");
echo $mobil->infoMerk();         // Merk: Toyota
echo $mobil->jumlahRoda();       // 4
echo $mobil->bunyiKlakson();     // Tin! Tin!
```

### 5.2 Abstract Method (Template Method Pattern)

```php
<?php
abstract class Pembayaran {
    public function __construct(protected float $jumlah) {}

    // Template method — alurnya sudah jadi
    final public function proses(): void {
        $this->validasi();
        $this->bayar();
        $this->kirimNotifikasi();
    }

    private function validasi(): void {
        if ($this->jumlah <= 0) throw new InvalidArgumentException("Jumlah tidak valid");
    }

    private function kirimNotifikasi(): void {
        echo "📧 Notifikasi terkirim\n";
    }

    // Abstract — subclass wajib implementasi cara bayarnya
    abstract protected function bayar(): void;
}

class BayarTransfer extends Pembayaran {
    protected function bayar(): void {
        echo "🏦 Transfer bank Rp" . number_format($this->jumlah) . "\n";
    }
}

class BayarKartu extends Pembayaran {
    protected function bayar(): void {
        echo "💳 Kartu kredit Rp" . number_format($this->jumlah) . "\n";
    }
}

(new BayarTransfer(500000))->proses();
// 🏦 Transfer bank Rp500.000
// 📧 Notifikasi terkirim
```

### 5.3 Interface vs Abstract Class

| Aspek | Abstract Class | Interface |
| :--- | :--- | :--- |
| **Instantiate (new)** | Tidak bisa | Tidak bisa |
| **Property** | Bisa ada | Hanya konstanta |
| **Method body** | Bisa abstract + konkret | Hanya signature (sebelum PHP 8) |
| **Multiple inheritance** | Tidak (1 parent saja) | Bisa implementasi banyak interface |
| **Constructor** | Bisa ada | Tidak bisa |
| **Access modifier** | Public/protected/private | Hanya public |
| **Cocok untuk** | Hierarki yang berbagi kode | Kontrak antar class tak terkait |

```php
<?php
// Bisa implements banyak interface
interface BisaTerbang {
    public function terbang(): void;
}

interface BisaBerenang {
    public function berenang(): void;
}

class Bebek implements BisaTerbang, BisaBerenang {
    public function terbang(): void   { echo "Bebek terbang\n"; }
    public function berenang(): void { echo "Bebek berenang\n"; }
}
```

### 5.4 Contoh Real: Sistem Pembayaran

```php
<?php
interface MetodePembayaran {
    public function bayar(float $jumlah): bool;
    public function refund(float $jumlah): bool;
}

class Tunai implements MetodePembayaran {
    public function bayar(float $jumlah): bool {
        echo "💵 Bayar tunai Rp" . number_format($jumlah) . "\n";
        return true;
    }
    public function refund(float $jumlah): bool {
        echo "💵 Refund tunai\n";
        return true;
    }
}

class KartuKredit implements MetodePembayaran {
    public function __construct(private string $nomor) {}
    public function bayar(float $jumlah): bool {
        echo "💳 Kartu {$this->nomor}: Rp" . number_format($jumlah) . "\n";
        return true;
    }
    public function refund(float $jumlah): bool {
        echo "💳 Refund ke kartu {$this->nomor}\n";
        return true;
    }
}

class Kasir {
    public function __construct(private MetodePembayaran $metode) {}

    public function checkout(float $total): void {
        if ($this->metode->bayar($total)) {
            echo "✅ Pembayaran berhasil\n";
        } else {
            echo "❌ Pembayaran gagal\n";
        }
    }
}

$kasir = new Kasir(new KartuKredit("4111-xxxx-1234"));
$kasir->checkout(750000);
// 💳 Kartu 4111-xxxx-1234: Rp750.000
// ✅ Pembayaran berhasil

$kasir2 = new Kasir(new Tunai());
$kasir2->checkout(50000);
```

## 6. Perbandingan 4 Pilar dengan Contoh

```php
<?php
// 1. ENCAPSULATION (Pembungkusan & Proteksi Data)
class AkunBank {
    private float $saldo;

    public function __construct(float $saldoAwal) {
        $this->saldo = $saldoAwal;
    }

    public function getSaldo(): float {
        return $this->saldo;
    }

    public function setor(float $jml): void {
        if ($jml > 0) $this->saldo += $jml;
    }
}

// 2. INHERITANCE (Pewarisan)
class AkunPremium extends AkunBank {
    private float $poin;

    public function __construct(float $saldoAwal) {
        parent::__construct($saldoAwal);
        $this->poin = 0;
    }

    public function setor(float $jml): void {
        parent::setor($jml); // panggil method parent
        $this->poin += $jml * 0.01;  // bonus poin
    }

    public function getPoin(): float {
        return $this->poin;
    }
}

// 3. POLYMORPHISM (Banyak Bentuk via Interface)
interface Bunga {
    public function hitungBunga(float $saldo): float;
}

class BungaFlat implements Bunga {
    public function hitungBunga(float $saldo): float {
        return $saldo * 0.05;
    }
}

class BungaBerjenjang implements Bunga {
    public function hitungBunga(float $saldo): float {
        if ($saldo < 1000000)  return $saldo * 0.02;
        if ($saldo < 10000000) return $saldo * 0.04;
        return $saldo * 0.06;
    }
}

// 4. ABSTRACTION (Menyembunyikan Detail Rumit)
abstract class ProdukBank {
    abstract public function tampilkanInfo(): string;
}

class Tabungan extends ProdukBank {
    public function __construct(private float $saldo, private Bunga $bunga) {}

    public function tampilkanInfo(): string {
        $b = $this->bunga->hitungBunga($this->saldo);
        return "Tabungan — Saldo: {$this->saldo}, Bunga: $b";
    }
}
```
