# Operator
Memahami berbagai jenis operator dalam PHP yang digunakan untuk melakukan operasi terhadap data. Operator merupakan bagian penting dalam pemrograman karena memungkinkan kita untuk melakukan perhitungan, membandingkan nilai, menentukan kondisi, memberikan nilai ke variabel, hingga menggabungkan beberapa data.

---

## Apa Itu Operator?
Operator adalah simbol atau tanda khusus yang digunakan untuk melakukan operasi terhadap satu atau lebih nilai yang disebut **operand**. Hasil dari operasi tersebut dapat berupa nilai baru, perbandingan `true` atau `false`, maupun perubahan terhadap suatu variabel.

10 + 5
── ── ──

operand op operand

| Istilah | Keterangan |
| :--- | :--- |
| **Operand** | Nilai yang dioperasikan (contoh: `10` dan `5`) |
| **Operator** | Simbol yang melakukan operasi (contoh: `+`) |
| **Ekspresi** | Kombinasi operand dan operator (contoh: `10 + 5`) |

## 1. Operator Aritmatika

Digunakan untuk operasi matematika dasar. Kedua operand harus berupa angka (atau string angka yang bisa dikonversi).

| Operator | Nama | Contoh | Hasil |
| :---: | :--- | :--- | :---: |
| `+` | Penjumlahan | `10 + 3` | `13` |
| `-` | Pengurangan | `10 - 3` | `7` |
| `*` | Perkalian | `10 * 3` | `30` |
| `/` | Pembagian | `10 / 3` | `3.333...` |
| `%` | Modulus (sisa bagi) | `10 % 3` | `1` |
| `**` | Eksponen (pangkat)* | `2 ** 3` | `8` |

\*Tersedia sejak PHP 5.6

```php
<?php
$a = 10;
$b = 3;

echo $a + $b;   // 13
echo $a - $b;   // 7
echo $a * $b;   // 30
echo $a / $b;   // 3.3333333333333
echo $a % $b;   // 1
echo $a ** $b;  // 1000
```
### 1.1 Hal Penting tentang Pembagian `/`
```php
<?php
// Pembagian selalu menghasilkan float (kecuali hasilnya bulat sempurna)
var_dump(10 / 2);    // float(5) — bukan integer!
var_dump(10 / 3);    // float(3.333...)
var_dump(7 / 2);     // float(3.5)

// Jika butuh integer, gunakan intdiv() (PHP 7+)
echo intdiv(10, 3);  // 3 (dibulatkan ke bawah, tanpa desimal)
echo intdiv(-10, 3); // -4 (floor division)
```
### 1.2 Hal Penting tentang Modulus `%`
```php
<?php
// Modulus mengembalikan sisa pembagian
// Sangat berguna untuk cek ganjil/genap
$angka = 17;

if ($angka % 2 === 0) {
    echo "Genap";
} else {
    echo "Ganjil";  // Output ini
}

// Modulus dengan negatif — hasilnya mengikuti tanda operand kiri
echo 10 % 3;    // 1
echo -10 % 3;   // -1
echo 10 % -3;   // 1
```
### 1.3 Operasi dengan String Angka
```php
<?php
// PHP otomatis mengkonversi string angka
echo "5" + "3";      // 8
echo "10" * 2;       // 20
echo "3.5" + 1;      // 4.5

// String non-angka dikonversi jadi 0
echo "Halo" + 5;     // 5
echo "5apel" + 3;    // 8 (mengambil angka dari awal)
echo "apel5" + 3;    // 3 (tidak ada angka di awal → 0)
```

## 2. Operator Penugasan (Assignment)
Digunakan untuk memberikan nilai ke variabel. Selain `=` dasar, ada compound assignment yang menggabungkan operasi aritmatika/string dengan assignment.
| Operator | Sama Dengan | Contoh | Ekivalen |
| :---: | :--- | :--- | :--- |
| `=` | Assignment dasar | `$x = 5` | `$x = 5` |
| `+=` | Tambah lalu assign | `$x += 3` | `$x = $x + 3` |
| `-=` | Kurang lalu assign | `$x -= 3` | `$x = $x - 3` |
| `*=` | Kali lalu assign | `$x *= 3` | `$x = $x * 3` |
| `/=` | Bagi lalu assign | `$x /= 3` | `$x = $x / 3` |
| `%=` | Modulus lalu assign | `$x %= 3` | `$x = $x % 3` |
| `**=` | Pangkat lalu assign | `$x **= 3` | `$x = $x ** 3` |
| `.=` | Gabung string lalu assign | `$x .= "!"` | `$x = $x . "!"` |

```php
<?php
$nilai = 100;
echo $nilai;       // 100

$nilai += 25;
echo $nilai;       // 125

$nilai -= 50;
echo $nilai;       // 75

$nilai *= 2;
echo $nilai;       // 150

$nilai /= 3;
echo $nilai;       // 50

$nilai .= " poin";
echo $nilai;       // "50 poin"
```
> [!TIP]
Compound assignment lebih ringkas dan sering digunakan dalam loop.

## 3. Operator Perbandingan
Digunakan untuk membandingkan dua nilai dan mengembalikan `true` atau `false`.

#### Perbandingan Sederhana
| Operator | Nama | Contoh | Hasil |
| :---: | :--- | :--- | :---: |
| `==` | Sama (loose) | `5 == "5"` | `true` |
| `===` | Identik (strict) | `5 === "5"` | `false` |
| `!=` | Tidak sama (loose) | `5 != "5"` | `false` |
| `!==` | Tidak identik (strict) | `5 !== "5"` | `true` |
| `<` | Lebih kecil | `3 < 5` | `true` |
| `>` | Lebih besar | `3 > 5` | `false` |
| `<=` | Lebih kecil atau sama dengan | `5 <= 5` | `true` |
| `>=` | Lebih besar atau sama dengan | `3 >= 5` | `false` |

### 3.1 Loose `==` vs Strict `===` (Penting!)
```php
<?php
// == membandingkan nilai SETELAH type juggling
var_dump(0 == false);      // true   (0 dijadikan false, false dijadikan 0)
var_dump("" == false);     // true   (empty string dijadikan false)
var_dump("0" == false);    // true   (string "0" adalah falsy)
var_dump(0 == "0");        // true
var_dump(0 == "Halo");     // true   (!) "Halo" dijadikan 0
var_dump(null == "0");     // false  (ini satu-satunya pengecualian aneh)
var_dump(null == "");      // true

// === membandingkan nilai DAN tipe data — TANPA type juggling
var_dump(0 === false);     // false  (integer vs boolean)
var_dump("" === false);    // false  (string vs boolean)
var_dump(0 === "0");       // false  (integer vs string)
var_dump(0 === "Halo");    // false
var_dump(null === "");     // false  (null vs string)
```
> [!INFO]
Aturan emas (diulang karena penting): Gunakan `===` dan `!==` dalam 99% kasus. Hanya gunakan `==` jika kamu benar-benar memahami dan menginginkan type juggling.

### 3.2 Spaceship Operator `<=>` (PHP 7+)
Mengembalikan -`1`, `0`, atau `1` bergantung pada perbandingan. Sangat berguna untuk fungsi *sorting*.
```php
<?php
echo 1 <=> 1;    // 0  (sama)
echo 1 <=> 2;    // -1 (kiri lebih kecil)
echo 2 <=> 1;    // 1  (kiri lebih besar)

// Contoh penggunaan nyata: sorting array
$angka = [3, 1, 4, 1, 5, 9];
usort($angka, fn($a, $b) => $a <=> $b);
print_r($angka);  // [1, 1, 3, 4, 5, 9]
```

### 3.3 Null Coalescing Operator `??` (PHP 7+)
Mengembalikan operand kiri jika **bukan null**, jika tidak mengembalikan operand kanan. Mendukung *chaining*.
```php
<?php
$nama = null;
echo $nama ?? "Tidak dikenal";    // "Tidak dikenal"

$nama = "Budi";
echo $nama ?? "Tidak dikenal";    // "Budi"

// Chaining — cek dari kiri ke kanan
$aksi = null;
$aksiDefault = null;
echo $aksi ?? $aksiDefault ?? "tidak ada aksi";  // "tidak ada aksi"

// Perbedaan dengan isset() + ternary
// Cara lama:
echo isset($user["nama"]) ? $user["nama"] : "Guest";

// Cara baru dengan ??:
echo $user["nama"] ?? "Guest";

// ⚠️ Perhatikan: ?? hanya cek null, bukan falsy
$jumlah = 0;
echo $jumlah ?? "tidak ada";   // 0 (karena 0 bukan null!)

// Jika butuh cek falsy, gunakan ?: (Elvis operator)
echo $jumlah ?: "tidak ada";   // "tidak ada" (karena 0 adalah falsy)
```

### 3.4 Elvis Operator `?:` (Ternary Tanpa Kondisi)
Mengembalikan operand kiri jika **truthy**, jika tidak mengembalikan operand kanan.
```php
<?php
$nama = "Andi";
echo $nama ?: "Anonim";     // "Andi" (truthy, pakai kiri)

$nama = "";
echo $nama ?: "Anonim";     // "Anonim" (falsy, pakai kanan)

$nama = 0;
echo $nama ?: "tidak ada";  // "tidak ada" (falsy)
```

#### Perbandingan String
```php
<?php
// String dibandingkan berdasarkan urutan alfabet (ASCII)
var_dump("apel" < "jeruk");    // true  (a < j)
var_dump("Apel" < "apel");     // true  (huruf kapital 'A' = 65, 'a' = 97)
var_dump("abc" == "abc");      // true
var_dump("abc" === "abc");     // true (sama tipe, sama nilai)
```

## 4. Operator Logika
Digunakan untuk menggabungkan beberapa kondisi. Mengembalikan true atau false.
| Operator | Nama | Contoh | Hasil |
| :---: | :--- | :--- | :---: |
| `&&` / `and` | DAN | `true && false` | `false` |
| `\|\|` / `or` | ATAU | `true \|\| false` | `true` |
| `!` | TIDAK | `!true` | `false` |
| `xor` | EKSKLUSIF ATAU | `true xor true` | `false` |

### 4.1 Tabel Kebenaran
| A | B | `A && B` | `A \|\| B` | `!A` | `A xor B` |
| :---: | :---: | :---: | :---: | :---: | :---: |
| `true` | `true` | `true` | `true` | `false` | `false` |
| `true` | `false` | `false` | `true` | `false` | `true` |
| `false` | `true` | `false` | `true` | `true` | `true` |
| `false` | `false` | `false` | `false` | `true` | `false` |

```php
<?php
$umur = 20;
$punyaSIM = true;

// AND — kedua kondisi harus true
if ($umur >= 17 && $punyaSIM) {
    echo "Boleh mengemudi";       // Ini yang tampil
}

// OR — salah satu kondisi true sudah cukup
if ($umur >= 17 || $punyaSIM) {
    echo "Boleh mengemudi atau punya SIM";
}

// NOT — membalikkan nilai
if (!$punyaSIM) {
    echo "Tidak punya SIM";
}

// XOR — tepat satu yang true (tidak boleh keduanya)
$hariIniCerah = true;
$hariIniHujan = false;
if ($hariIniCerah xor $hariIniHujan) {
    echo "Cuaca pasti salah satu: cerah atau hujan";  // Ini yang tampil
}
```

### 4.2 Perbedaan `&&`/`||` dengan `and`/`or`
Mereka melakukan hal yang sama secara logika, tetapi memiliki prioritas berbeda. Ini bisa menyebabkan bug yang sulit ditemukan.

```php
<?php
// && memiliki prioritas TINGGI (lebih tinggi dari =)
$result = true && false;
// Dievaluasi sebagai: $result = (true && false)
var_dump($result);  // bool(false)

// and memiliki prioritas RENDAH (lebih rendah dari =)
$result = true and false;
// Dievaluasi sebagai: ($result = true) and false
var_dump($result);  // bool(true)  (!) — $result sudah true sebelum 'and' dievaluasi
```

#### Tabel Prioritas (dari tinggi ke rendah):
```text
&&    → prioritas tinggi
||    → prioritas tinggi
=     → prioritas sedang
and   → prioritas rendah
or    → prioritas rendah
```

> [!TIP]
**Rekomendasi**: Selalu gunakan `&&` dan `||`. Hindari `and`/`or` kecuali benar-benar paham prioritasnya.

### 4.3 Short-Circuit Evaluation
Operator `&&` dan `||` tidak mengevaluasi operand kanan jika operand kiri sudah cukup menentukan hasil.

```php
<?php
function cekKiri() {
    echo "cekKiri dipanggil\n";
    return false;
}

function cekKanan() {
    echo "cekKanan dipanggil\n";
    return true;
}

// AND: jika kiri sudah false, kanan TIDAK dievaluasi
if (cekKiri() && cekKanan()) {
    echo "Masuk if\n";
}
// Output: cekKiri dipanggil
// (cekKanan TIDAK dipanggil!)

echo "---\n";

// OR: jika kiri sudah true, kanan TIDAK dievaluasi
if (cekKanan() || cekKiri()) {
    echo "Masuk if\n";
}
// Output: cekKanan dipanggil → Masuk if
// (cekKiri TIDAK dipanggil!)
```

> [!IMPORTANT]
 Ini berguna untuk mencegah error, misalnya: `if ($obj !== null && $obj->method())` — jika `$obj` null, `$obj->method()` tidak akan dipanggil sehingga tidak error.

 ## 5. Operator String
| Operator | Nama | Contoh | Hasil |
| :---: | :--- | :--- | :--- |
| `.` | Penggabungan (concatenation) | `"Halo" . " Dunia"` | `"Halo Dunia"` |
| `.=` | Gabung lalu assign | `$s .= "!"` | `$s = $s . "!"` |

```php
<?php
$depan = "Halo";
$belakang = "Dunia";

// Concatenation
$gabung = $depan . " " . $belakang;
echo $gabung;     // Halo Dunia

// Concatenation assignment
$teks = "Belajar";
$teks .= " PHP";
$teks .= " itu";
$teks .= " menyenangkan";
echo $teks;       // Belajar PHP itu menyenangkan
```

> [!DANGER]
Jangan gunakan `+` untuk menggabungkan string. Meskipun `"5"` + `"3"` menghasilkan `8` (bukan `"53"`), ini karena PHP melakukan type juggling ke angka.

```php
<?php
$nama = "Budi" . " " . "Santoso";   // ✅ "Budi Santoso"
$nama = "Budi" + " " + "Santoso";   // ❌ 0 (semua string non-angka jadi 0)
```

## 6. Operator Increment & Decrement
Digunakan untuk menambah atau mengurangi nilai variabel sebesar 1.
| Operator | Nama | Keterangan |
| :---: | :--- | :--- |
| `++$x` | Pre-increment | Tambah 1, **lalu** kembalikan nilai |
| `$x++` | Post-increment | Kembalikan nilai, **lalu** tambah 1 |
| `--$x` | Pre-decrement | Kurangi 1, **lalu** kembalikan nilai |
| `$x--` | Post-decrement | Kembalikan nilai, **lalu** kurangi 1 |

```php
<?php
// === POST-INCREMENT ===
$a = 5;
$b = $a++;    // $b dapat nilai $a DULU (5), lalu $a ditambah
echo $a;      // 6  (sudah ditambah)
echo $b;      // 5  (nilai sebelum increment)

// === PRE-INCREMENT ===
$c = 5;
$d = ++$c;    // $c ditambah DULU (6), lalu $d dapat nilainya
echo $c;      // 6
echo $d;      // 6  (nilai setelah increment)

// === POST-DECREMENT ===
$e = 5;
$f = $e--;    // $f dapat nilai $e DULU (5), lalu $e dikurangi
echo $e;      // 4
echo $f;      // 5

// === PRE-DECREMENT ===
$g = 5;
$h = --$g;    // $g dikurangi DULU (4), lalu $h dapat nilainya
echo $g;      // 4
echo $h;      // 4
```

### 6.1 Kapan Perbedaan Pre vs Post Penting?
Hanya penting ketika hasilnya langsung ditugaskan ke variabel lain atau digunakan dalam ekspresi:

```php
<?php
// Jika digunakan sendiri (tidak di-assign), HASILNYA SAMA
$x = 5;
$x++;
echo $x;   // 6

$y = 5;
++$y;
echo $y;   // 6

// Berbeda jika di-assign atau dipakai dalam ekspresi
$i = 5;
$j = $i++;     // j = 5, i = 6
$k = ++$i;     // k = 7, i = 7
```

### 6.2 Increment pada String (Kasus Khusus)
```php
<?php
// PHP mendukung increment pada karakter huruf
$huruf = 'a';
$huruf++;
echo $huruf;    // 'b'

$huruf = 'z';
$huruf++;
echo $huruf;    // 'aa'

$huruf = 'A9';
$huruf++;
echo $huruf;    // 'B0'

// ⚠️ Decrement TIDAK didukung untuk string
$huruf = 'b';
$huruf--;
echo $huruf;    // 'b' (tidak berubah, tidak error, tapi tidak melakukan apa-apa)
```

## 7. Operator Bitwise
Mengoperasikan data pada level bit (biner). Jarang digunakan dalam pengembangan web sehari-hari, tapi penting untuk diketahui.

| Operator | Nama | Contoh | Penjelasan Biner |
| :---: | :--- | :--- | :--- |
| `&` | AND | `5 & 3` | `0101 & 0011` → `0001` → `1` |
| `\|` | OR | `5 \| 3` | `0101 \| 0011` → `0111` → `7` |
| `^` | XOR | `5 ^ 3` | `0101 ^ 0011` → `0110` → `6` |
| `~` | NOT | `~5` | `~0101` → `1010` → `-6` |
| `<<` | Left Shift | `5 << 1` | `0101` → `1010` → `10` |
| `>>` | Right Shift | `5 >> 1` | `0101` → `0010` → `2` |

```php
<?php
$a = 5;  // 0101
$b = 3;  // 0011

echo $a & $b;    // 1   (0001)
echo $a | $b;    // 7   (0111)
echo $a ^ $b;    // 6   (0110)
echo ~$a;        // -6
echo $a << 1;    // 10  (setara dengan 5 * 2)
echo $a << 2;    // 20  (setara dengan 5 * 4)
echo $a >> 1;    // 2   (setara dengan 5 / 2 dibulatkan ke bawah)
```

### 7.1 Contoh penggunaan praktis:
```php
<?php
// Menyimpan banyak flag dalam satu integer
const READ    = 1;      // 0001
const WRITE   = 2;      // 0010
const EXECUTE = 4;      // 0100
const DELETE  = 8;      // 1000

// Memberikan hak akses
$permissions = READ | WRITE;           // 0011 (3)
echo $permissions;                      // 3

// Menambah hak execute
$permissions = $permissions | EXECUTE;  // 0111 (7)

// Mengecek apakah punya hak WRITE
if ($permissions & WRITE) {
    echo "Punya hak tulis";              // Tampil
}

// Menghapus hak WRITE
$permissions = $permissions & ~WRITE;   // 0101 (5)
```

## 8. Operator Array
Digunakan untuk membandingkan atau menggabungkan array.
| Operator | Nama | Keterangan |
| :---: | :--- | :--- |
| `+` | Union | Menggabungkan array (key yang sama dari kiri tetap) |
| `==` | Equal | Sama key/value, tipe tidak dicek ketat |
| `===` | Identical | Sama key/value, urutan sama, tipe sama |
| `!=` / `<>` | Not Equal | Kebalikan `==` |
| `!==` | Not Identical | Kebalikan `===` |

```php
<?php
$a = ["a" => 1, "b" => 2];
$b = ["b" => 3, "c" => 4];

// + Union — key dari kiri yang menang
$gabung = $a + $b;
print_r($gabung);
// Array ( [a] => 1 [b] => 2 [c] => 4 )
// "b" tetap 2 (dari $a), bukan 3 (dari $b)

// == Equal — sama key dan value
$c = ["a" => 1, "b" => 2];
$d = ["b" => 2, "a" => 1];
var_dump($c == $d);    // true  (urutan tidak penting)

// === Identical — sama key, value, urutan, DAN tipe
var_dump($c === $d);   // false (urutan berbeda!)

$e = ["a" => 1, "b" => 2];
var_dump($c === $e);   // true (semuanya identik)
```

## 9. Spread Operator `...` (PHP 7.4+)
Digunakan untuk "menyebarkan" elemen array atau argumen fungsi.
```php
<?php
// Menyebarkan elemen array ke dalam array baru
$awal = [1, 2, 3];
$akhir = [4, 5, 6];
$gabung = [...$awal, ...$akhir];
print_r($gabung);  // [1, 2, 3, 4, 5, 6]

// Menyisipkan elemen di tengah
$gabung = [...$awal, 99, ...$akhir];
print_r($gabung);  // [1, 2, 3, 99, 4, 5, 6]

// Menyebarkan sebagai argumen fungsi
function total(int $a, int $b, int $c): int {
    return $a + $b + $c;
}

$angka = [10, 20, 30];
echo total(...$angka);  // 60
```

## 10. Operator Ternary
Operator kondisi ringkas yang bisa ditulis dalam satu baris.

### 10.1 Sintaks Dasar
```php
<?php
$kondisi ? nilai_jika_true : nilai_jika_false
```
contoh:
```php
<?php
$umur = 20;
$status = ($umur >= 17) ? "Dewasa" : "Anak-anak";
echo $status;  // Dewasa

// Versi if-else yang setara:
if ($umur >= 17) {
    $status = "Dewasa";
} else {
    $status = "Anak-anak";
}
```

### 10.2 Nested Ternary (Bisa, Tapi Hindari)
```php
<?php
$nilai = 85;

// ❌ Susah dibaca
$grade = $nilai >= 90 ? "A" : $nilai >= 80 ? "B" : $nilai >= 70 ? "C" : "D";

// ✅ Lebih baik pakai if-elseif
if ($nilai >= 90) {
    $grade = "A";
} elseif ($nilai >= 80) {
    $grade = "B";
} elseif ($nilai >= 70) {
    $grade = "C";
} else {
    $grade = "D";
}

echo $grade;  // B
```

### 10.3 Ternary untuk Default Value
```php
<?php
$nama = "Budi";
echo $nama ?: "Tidak dikenal";     // Budi (truthy, pakai $nama)

$nama = "";
echo $nama ?: "Tidak dikenal";     // Tidak dikenal (falsy, pakai default)

$nama = null;
echo $nama ?? "Tidak dikenal";     // Tidak dikenal (null, pakai default)

$nama = 0;
echo $nama ?? "Tidak ada";         // 0 (bukan null, jadi pakai $nama)
echo $nama ?: "Tidak ada";         // Tidak ada (falsy, jadi pakai default)
```

## 11. Operator `match` (PHP 8.0+)
Mirip `switch`, tetapi lebih aman, lebih ringkas, dan mengembalikan nilai langsung.
```php
<?php
$status = "aktif";

// Cara lama: switch
switch ($status) {
    case "aktif":
        $label = '<span style="color:green">Aktif</span>';
        break;
    case "nonaktif":
        $label = '<span style="color:red">Nonaktif</span>';
        break;
    default:
        $label = '<span style="color:gray">Tidak diketahui</span>';
}

// Cara baru: match (lebih ringkas)
$label = match ($status) {
    "aktif"    => '<span style="color:green">Aktif</span>',
    "nonaktif" => '<span style="color:red">Nonaktif</span>',
    default    => '<span style="color:gray">Tidak diketahui</span>',
};

echo $label;
```

### 11.1 Perbedaan `match` vs `switch`
| Aspek | `switch` | `match` |
| :--- | :--- | :--- |
| **Return value** | Tidak mengembalikan nilai | Mengembalikan nilai langsung |
| **Break** | Wajib pakai `break` | Tidak perlu `break` |
| **Perbandingan** | Loose (`==`) | Strict (`===`) |
| **Tidak cocok** | Tidak error, lanjut ke default | `UnhandledMatchError` |
| **Multiple condition** | Tidak bisa | Bisa dengan `|` |

```php
<?php
// Multiple condition dengan |
$angka = 3;
$jenis = match (true) {
    $angka % 2 === 0 => "Genap",
    $angka % 2 !== 0 => "Ganjil",
};
echo $jenis;  // Ganjil

// Strict comparison — ini penting
$nilai = "0";
$result = match ($nilai) {
    0   => "Nol (integer)",
    "0" => "Nol (string)",
};
echo $result;  // "Nol (string)" — karena ===
// Jika pakai switch(0), akan masuk case pertama saja
```

## 12. Prioritas Operator
Ketika beberapa operator muncul dalam satu ekspresi, PHP menentukan urutan eksekusi berdasarkan prioritas. Gunakan tanda kurung () jika ragu — lebih aman dan lebih mudah dibaca.

### 12.1 Tabel Prioritas (dari tertinggi ke terendah)
| Prioritas | Operator | Keterangan |
| :---: | :--- | :--- |
| Tertinggi | `()` | Tanda kurung |
| | `**` | Eksponen |
| | `++`, `--`, `~`, `(int)`, `(string)`, dll. | Unary / type cast |
| | `*`, `/`, `%` | Perkalian, pembagian, modulus |
| | `+`, `-`, `.` | Penjumlahan, pengurangan, concatenation |
| | `<<`, `>>` | Bitwise shift |
| | `<`, `<=`, `>`, `>=` | Perbandingan |
| | `==`, `!=`, `===`, `!==`, `<=>` | Perbandingan kesetaraan |
| | `&` | Bitwise AND |
| | `^` | Bitwise XOR |
| | `\|` | Bitwise OR |
| | `&&` | Logical AND |
| | `\|\|` | Logical OR |
| | `??` | Null coalescing |
| | `?:` | Ternary / Elvis |
| | `=`, `+=`, `-=`, `.=`, dll. | Assignment |
| Terendah | `and` | Logical AND (rendah) |
| | `xor` | Logical XOR (rendah) |
| | `or` | Logical OR (rendah) |

```php
<?php
// Tanpa kurung — bisa membingungkan
echo 2 + 3 * 4;       // 14 (kali dulu, baru tambah)
echo 2 * 3 + 4 * 5;   // 26

// Dengan kurung — jelas dan aman
echo (2 + 3) * 4;     // 20
echo 2 * (3 + 4) * 5; // 70

// Contoh yang berbahaya tanpa kurung
$result = true && false || true;
// Dievaluasi: (true && false) || true → false || true → true
echo $result ? "true" : "false";  // true

$result = true && (false || true);
// Dievaluasi: true && (false || true) → true && true → true
echo $result ? "true" : "false";  // true

// Tapi ini berbeda hasilnya!
$result = true || false && false;
// Dievaluasi: true || (false && false) → true || false → true
// Bukan: (true || false) && false → true && false → false
```

> [!TIP]
Jika ekspresi melibatkan lebih dari 2 operator, selalu gunakan tanda kurung. Kode yang mudah dibaca lebih berharga daripada menghafal tabel prioritas.

### 12.2 Error Suppression Operator `@`
Operator `@` digunakan untuk menyembunyikan pesan error yang dihasilkan oleh sebuah ekspresi.
```php
<?php
// Tanpa @ — akan muncul warning
echo $tidakAda;  // Warning: Undefined variable $tidakAda

// Dengan @ — warning disembunyikan
echo @$tidakAda; // (tidak ada output apapun, tidak ada warning)
```

> [!WARNING]
Hindari penggunaan `@`. Menyembunyikan error bukan cara yang benar untuk menangani masalah. Sebaiknya gunakan `isset()`, null coalescing `??,` atau `try`-`catch`. Performa juga sedikit lebih lambat karena **PHP tetap memproses error di belakang layar**.

```php
<?php
// ❌ Buruk
$nama = @$_POST["nama"];

// ✅ Benar
$nama = $_POST["nama"] ?? "";

// ✅ Juga benar
$nama = isset($_POST["nama"]) ? $_POST["nama"] : "";
 ```

 ## Latihan Praktik
 Buat file `05-operator.php`:
 ```php
 <?php
// === Latihan 1: Operator Aritmatika ===
echo "<h3>Latihan 1: Aritmatika</h3>";
$harga = 45000;
$jumlah = 3;
$diskon = 10;

$subTotal = $harga * $jumlah;
$potongan = $subTotal * ($diskon / 100);
$total = $subTotal - $potongan;

printf("Harga: Rp%s × %d = Rp%s<br>",
    number_format($harga, 0, ',', '.'),
    $jumlah,

printf("Diskon %d%%: -Rp%s<br>",
    $diskon,
    number_format($potongan, 0, ',', '.')
);
printf("Total: Rp%s<br>",
    number_format($total, 0, ',', '.')
);

// === Latihan 2: Perbandingan ===
echo "<h3>Latihan 2: Perbandingan == vs ===</h3>";
 $pasangan = [
    [0, "0"],
    [1, true],
    ["", null],
    [0, false],
    ["1", true],
];

foreach ($pasangan as $p) {
    $loose = $p[0] == $p[1] ? "true" : "false";
    $strict = $p[0] === $p[1] ? "true" : "false";
    echo var_export($p[0], true) . " == " . var_export($p[1], true);
    echo " → ==: $loose | ===: $strict<br>";
}

// === Latihan 3: Null Coalescing & Elvis ===
echo "<h3>Latihan 3: ?? dan ?:</h3>";
 $values = [0, "", null, "Halo", false];

foreach ($values as $v) {
    $nullCoalesce = $v ?? "DEFAULT";
    $elvis = $v ?: "DEFAULT";
    echo "Nilai: " . var_export($v, true);
    echo " | ?? : " . var_export($nullCoalesce, true);
    echo " | ?: : " . var_export($elvis, true) . "<br>";
}

// === Latihan 4: Match Expression ===
echo "<h3>Latihan 4: Match Expression</h3>";
$bulan = 8;
$musim = match (true) {
    $bulan >= 3 && $bulan <= 5  => "Semi (Musim Semi)",
    $bulan >= 6 && $bulan <= 8  => "Natsu (Musim Panas)",
    $bulan >= 9 && $bulan <= 11 => "Aki (Musim Gugur)",
    $bulan == 12 || $bulan <= 2 => "Fuyu (Musim Dingin)",
    default => "Tidak diketahui"
};
echo "Bulan $bulan → $musim<br>";

// === Latihan 5: Operator Logika + Short-Circuit ===
echo "<h3>Latihan 5: Logika</h3>";
$role = "admin";
$loggedIn = true;
$ban = false;

if ($loggedIn && !$ban && ($role === "admin" || $role === "editor")) {
    echo "Akses diterima: Dashboard Admin<br>";
} else {
    echo "Akses ditolak<br>";
}

// === Latihan 6: Bitwise (Permission System) ===
echo "<h3>Latihan 6: Bitwise Permission</h3>";
const PERM_READ    = 1 << 0;  // 1
const PERM_WRITE   = 1 << 1;  // 2
const PERM_DELETE  = 1 << 2;  // 4
const PERM_ADMIN   = 1 << 3;  // 8

$userPerm = PERM_READ | PERM_WRITE;

echo "Hak akses user: $userPerm<br>";
echo "Bisa baca? " . (($userPerm & PERM_READ) ? "Ya" : "Tidak") . "<br>";
echo "Bisa tulis? " . (($userPerm & PERM_WRITE) ? "Ya" : "Tidak") . "<br>";
echo "Bisa hapus? " . (($userPerm & PERM_DELETE) ? "Ya" : "Tidak") . "<br>";
echo "Admin? " . (($userPerm & PERM_ADMIN) ? "Ya" : "Tidak") . "<br>";

// Tambah hak hapus
$userPerm |= PERM_DELETE;
echo "<br>Setelah ditambah hak hapus: $userPerm<br>";
echo "Bisa hapus? " . (($userPerm & PERM_DELETE) ? "Ya" : "Tidak") . "<br>";

// Hapus hak tulis
$userPerm &= ~PERM_WRITE;
echo "Setelah dihapus hak tulis: $userPerm<br>";
echo "Bisa tulis? " . (($userPerm & PERM_WRITE) ? "Ya" : "Tidak") . "<br>";
```
