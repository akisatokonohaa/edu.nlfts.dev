# Pengenalan pada PHP
Belajar **PHP** secara bertahap, mulai dari konsep dasar hingga memahami pemrograman berorientasi objek (**Object-Oriented Programming/OOP**).

Pada bagian ini, kamu akan mengenal PHP lebih dalam sebagai bahasa pemrograman yang banyak digunakan untuk membangun aplikasi web. Materi akan dimulai dari fundamental seperti syntax, variabel, tipe data, operator, percabangan, perulangan, function, array, hingga pengolahan data.

Setelah memahami dasar-dasarnya, pembelajaran akan dilanjutkan ke konsep yang lebih lanjut seperti penggunaan function yang lebih terstruktur, modularisasi kode, serta Object-Oriented Programming (OOP) yang mencakup class, object, property, method, inheritance, encapsulation, dan konsep OOP lainnya.

## 1. Apa Itu PHP?

**PHP (Hypertext Preprocessor)** adalah bahasa pemrograman scripting tingkat tinggi yang berjalan di sisi server (server-side). Bahasa ini dirancang khusus untuk pengembangan web agar dapat menghasilkan halaman situs yang dinamis dan interaktif. Berbeda dengan HTML yang bersifat statis dan hanya menampilkan struktur halaman, PHP mampu memproses data di server sebelum mengirimkan hasilnya ke peramban (browser) pengguna dalam bentuk HTML biasa, sehingga pengunjung tidak dapat melihat kode sumber PHP yang kamu tulis.

Keunggulan utama PHP terletak pada kemudahan dipelajarinya, fleksibilitasnya, serta dukungan komunitas yang sangat luas di seluruh dunia. PHP bersifat open-source (gratis) dan dapat berjalan secara lintas platform di berbagai sistem operasi seperti Windows, Linux, maupun macOS. Selain itu, PHP memiliki integrasi yang sangat baik dengan berbagai sistem basis data, terutama MySQL, yang membuatnya menjadi pilihan populer untuk membangun sistem login, pengolahan formulir, toko online, hingga sistem manajemen konten (Content Management System) terkenal seperti WordPress.

Seiring berjalannya waktu, PHP terus mengalami modernisasi dan tetap menjadi salah satu fondasi utama ekosistem web global. Dengan hadirnya framework modern seperti Laravel dan CodeIgniter, penulisan kode PHP kini menjadi jauh lebih rapi, aman, dan terstruktur menggunakan pendekatan Object-Oriented Programming (OOP). Bagi siapa saja yang baru memulai perjalanan di dunia web development, PHP merupakan salah satu bahasa dasar yang sangat ramah pemula namun tetap powerful untuk membangun aplikasi web skala kecil hingga enterprise.

## 2. Sejarah Singkat
**PHP** pertama kali diciptakan pada tahun 1994 oleh Rasmus Lerdorf sebagai sekumpulan skrip sederhana berbasis **C** yang ia sebut Personal Home Page Tools. Awalnya, skrip ini hanya digunakan untuk melacak pengunjung yang melihat resume online miliknya. Namun, seiring berkembangnya kebutuhan dan minat dari para pengembang lain, Lerdorf merilis kode sumbernya ke publik pada tahun 1995. Dari sana, proyek ini mulai berkembang menjadi sebuah bahasa pemrosesan formulir web yang lebih lengkap dan dikenal sebagai PHP/FI (Form Interpreter).

Lompatan besar terjadi pada tahun 1997 ketika Zeev Suraski dan Andi Gutmans mendaftar untuk menulis ulang inti mesin PHP. Kerja sama ini melahirkan PHP 3, yang secara resmi mengubah akronim PHP menjadi singkatan rekursif Hypertext Preprocessor. Tak lama setelah itu, mereka mendirikan Zend Technologies dan meluncurkan Zend Engine pada PHP 4 dan PHP 5, yang membawa fitur pemrograman berbasis objek (Object-Oriented Programming) modern serta peningkatan performa yang drastis. Hingga hari ini, PHP terus bertransformasi dengan rilis PHP 8 yang jauh lebih cepat, aman, dan menjadi penopang jutaan situs web di seluruh dunia.

## 3. Versi PHP Saat ini
Versi terbaru dari bahasa pemrograman PHP adalah seri PHP 8.5, yang dirilis membawa peningkatan fokus pada kenyamanan pengkodean (developer experience), performa, dan pengelolaan memori yang lebih optimal.

### 3.1 Fitur Unggulan PHP Terbaru
- **Pipe Operator:** Menyederhanakan penulisan kode fungsional agar jauh lebih mudah dibaca dan dirawat.
- **Fungsi Baru Array:** Penambahan fungsi array_first() dan array_last() untuk mempermudah pengambilan elemen pertama atau terakhir.
- **Peningkatan Introspeksi:** Penambahan fungsi transparan seperti get_error_handler() dan get_exception_handler().
- **Dukungan Ekstensi URI:** Pengelolaan URL yang lebih ergonomis langsung dari inti bahasa.

### 3.2 Keunggulan Utama Seri PHP 8
- **JIT (Just-In-Time) Compiler:** Meningkatkan kecepatan eksekusi kode secara signifikan lewat kompilasi saat runtime.
- **Keamanan & Validasi:** Memiliki fungsi bawaan modern seperti json_validate() serta manajemen tipe data yang lebih ketat.

### 3.3 Daftar Versi PHP Stabil yang Didukung

| :---: | :--- | :---: |

## 4. Arsitektur & Alur Kerja Proses Aplikasi PHP

PHP bekerja dengan model **Client-Side** dan **Server-Side**. Berikut adalah alur lengkap bagaimana sebuah aplikasi PHP memproses permintaan (*request*) dari pengguna hingga memberikan respons kembali ke peramban (*browser*).

### 4.1 Diagram Alur Kerja pada PHP

```text
┌─────────┐
│  USER   │
└────┬────┘
     │ 1. Interaksi Pengguna (Klik link, isi form, buka URL)
     ▼
┌─────────┐
│ BROWSER │
└────┬────┘
     │ 2. Mengirimkan HTTP Request (GET/POST/PUT/DELETE)
     ▼
┌─────────────────────────────────────────────────────────────┐
│                       WEB SERVER                            │
│                 (Apache / Nginx / LiteSpeed)                │
└────┬────────────────────────────────────────────────────────┘
     │ 3. Menemukan file .php & Meneruskan ke Interpreter PHP
     ▼
┌─────────────────────────────────────────────────────────────┐
│                      PHP ENGINE                             │
│                                                             │
│   a. Membaca & Mengeksekusi Kode (Business Logic)          │
│   b. Memproses Input Data ($_GET, $_POST, $_SESSION)        │
│                                                             │
│       ┌──────────────────────────────────────────────┐      │
│       │ DATABASE SYSTEM (MySQL / PostgreSQL / etc.)  │      │
│       │  • Query Data   (SELECT)                     │      │
│       │  • Modifikasi Data (INSERT/UPDATE/DELETE)    │      │
│       └──────────────────────┬───────────────────────┘      │
│                              │ 4. Ambil / Simpan Data       │
│                              ▼                              │
│       ┌──────────────────────────────────────────────┐      │
│       │ RENDERING & OUTPUT GENERATION                │      │
│       │  • Menggabungkan Data & Template HTML        │      │
│       │  • Menghasilkan Output HTML / JSON / CSS     │      │
│       └──────────────────────────────────────────────┘      │
└────┬────────────────────────────────────────────────────────┘
     │ 5. Mengirimkan HTTP Response (HTML / CSS / JS / JSON)
     ▼
┌─────────┐
│ BROWSER │ 6. Memproses (Render) HTML, CSS, & JS menjadi tampilan visual
└────┬────┘
     │
     ▼
┌─────────┐
│  USER   │ 7. Melihat Halaman Web Interaktif
└─────────┘
```


### 4.2 Penjelasan Tahap demi Tahap

| No | Tahapan | Deskripsi Detail |
| :---: | :--- | :--- |
| **1** | **User Action** | Pengguna melakukan aksi di halaman web, seperti mengetik URL, menekan tombol *submit*, atau mengeklik menu. |
| **2** | **HTTP Request** | Browser mengubah aksi pengguna menjadi pesan *HTTP Request* yang dikirimkan melalui internet ke server target. |
| **3** | **Web Server** | Web server (seperti Apache/Nginx) menerima permintaan. Jika ekstensi file adalah `.php`, web server menyerahkannya ke modul **PHP Engine**. |
| **4** | **PHP Processing** | **PHP Engine** mengeksekusi logika pemrograman (*Logic*): <br> • Mengecek autentikasi/session pengguna. <br> • Melakukan *query* ke **Database** jika membutuhkan data. <br> • Mengolah data hasil *query*. |
| **5** | **HTML Response** | PHP menggabungkan hasil olahan data ke dalam struktur markup **HTML** (atau JSON jika berupa API) lalu menyusun *HTTP Response*. |
| **6** | **Browser Rendering** | Web server mengirimkan balik respon HTML tersebut ke browser. Browser kemudian menerjemahkan kode HTML/CSS/JS menjadi tampilan visual yang siap dilihat pengguna. |

> [!INFO]
PHP akan menjalankan kode di server terlebih dahulu, kemudian hasilnya dikirimkan kepada browser.

## 5. Keunggulan dan Penggunaan PHP

PHP adalah bahasa pemrograman *server-side* yang sangat fleksibel dan dapat digunakan untuk membangun berbagai skala aplikasi web, mulai dari tingkat sederhana hingga kompleks.

### 5.1 Keunggulan PHP
| Keunggulan PHP | Deskripsi Utama |
| :--- | :--- |
| **Gratis & Open-Source** | Tidak memerlukan biaya lisensi untuk digunakan secara bebas. |
| **Mudah Dipelajari** | Sintaksnya mirip dengan C dan Java, sehingga sangat ramah untuk pemula. |
| **Komunitas Besar** | Memiliki dokumentasi yang sangat lengkap, forum aktif, dan banyak solusi di Stack Overflow. |
| **Lintas Platform** | Dapat berjalan lancar di Windows, Linux, maupun macOS tanpa perlu perubahan kode. |
| **Integrasi Database Kuat** | Mendukung berbagai basis data populer seperti MySQL, PostgreSQL, SQLite, hingga MongoDB. |
| **Hosting Murah** | Biaya pemeliharaan terjangkau karena hampir semua *shared hosting* mendukung PHP secara *native*. |
| **Mature & Stabil** | Telah teruji dan berkembang selama lebih dari 25 tahun untuk menopang jutaan situs web dunia. |

## 6. Prasyarat
>[!QUESTION]
**apa saja sih kebutuhan untuk memulai PHP?** *berikut adalah kebutuhan atau prasyarat untuk memulai PHP*

| Prasyarat / Kebutuhan | Tingkat Urgensi | Deskripsi & Fokus Pembelajaran |
| :--- | :---: | :--- |
