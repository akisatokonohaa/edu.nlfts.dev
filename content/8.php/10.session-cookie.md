# Session & Cookie

Menyimpan data pengguna antar halaman menggunakan Cookie (di browser) dan Session (di server).

---

## 1. Mengapa Perlu Menyimpan State?

HTTP adalah protokol **stateless** — setiap request bersifat independen dan server tidak "ingat" request sebelumnya. Untuk mempertahankan data antar halaman (misalnya: user login, keranjang belanja), kita membutuhkan mekanisme penyimpanan state.

```text
Request 1:  user membuka halaman login
Request 2:  user mengisi form dan submit
Request 3:  user membuka halaman dashboard
            ↑ Server harus "tahu" bahwa user sudah login — bagaimana?
```

Dua mekanisme utama di PHP:

| Mekanisme | Data disimpan di | Ukuran | Keamanan |
| :--- | :--- | :--- | :--- |
| **Cookie** | Browser (client) | ~4 KB per cookie | Rendah (user bisa lihat & ubah) |
| **Session** | Server | Tidak terbatas | Tinggi (user tidak bisa akses) |

---

## 2. Cookie

Cookie adalah **file kecil yang disimpan di browser** pengguna. Setiap kali browser mengirim request ke server, cookie juga ikut dikirim.

### 2.1 Diagram Alur Cookie

```text
                    SET COOKIE
┌──────────┐    ┌──────────────────┐    ┌──────────┐
│  Browser  │◄───│  Server PHP      │───►│  Browser  │
│           │    │  setcookie(...)  │    │  Simpan   │
└──────────┘    └──────────────────┘    └──────────┘

                    KIRIM COOKIE
┌──────────┐    ┌──────────────────┐    ┌──────────┐
│  Browser  │───►│  Server PHP      │───►│  Browser  │
│  Kirim    │    │  $_COOKIE["..."] │    │           │
└──────────┘    └──────────────────┘    └──────────┘
```

### 2.2 Membuat Cookie — `setcookie()`

```php
<?php
// Sintaks dasar
setcookie(nama, nilai, expire, path, domain, secure, httponly);
```

**Parameter `setcookie`:**

| Parameter | Wajib? | Keterangan | Contoh |
| :--- | :---: | :--- | :--- |
| `$nama` | ✅ | Nama cookie | `"username"` |
| `$nilai` | ✅ | Nilai yang disimpan | `"Budi"` |
| `$expire` | ❌ | Waktu kadaluarsa (Unix timestamp) | `time() + 3600` (1 jam) |
| `$path` | ❌ | Path di server cookie berlaku | `"/"` (seluruh situs) |
| `$domain` | ❌ | Domain cookie berlaku | `".example.com"` |
| `$secure` | ❌ | Hanya kirim via HTTPS | `true` |
| `$httponly` | ❌ | Tidak bisa diakses JavaScript | `true` |

```php
<?php
// Cookie berlaku 1 jam
setcookie("username", "Budi", time() + 3600, "/", "", false, true);

// Cookie berlaku 7 hari
setcookie("tema", "gelap", time() + (7 * 24 * 3600), "/", "", false, true);

// Cookie berlaku 30 hari
setcookie("bahasa", "id", time() + (30 * 24 * 3600), "/", "", false, true);
```

> [!WARNING]
`setcookie()` **wajib dipanggil SEBELUM** output apapun dikirim ke browser (sebelum `<html>`, `echo`, spasi kosong, dll). Jika tidak, akan muncul error *headers already sent*.

### 2.3 Waktu Kadaluarsa Cookie

```php
<?php
// 1 jam dari sekarang
$expire = time() + 3600;

// 1 hari
$expire = time() + (24 * 3600);

// 30 hari
$expire = time() + (30 * 24 * 3600);

// 1 tahun
$expire = time() + (365 * 24 * 3600);

// Spesifik: akhir tahun
$expire = strtotime("December 31 23:59:59");

// Session cookie — kadaluarsa saat browser ditutup
$expire = 0;
```

### 2.4 Membaca Cookie — `$_COOKIE`

```php
<?php
// Cek apakah cookie ada
if (isset($_COOKIE["username"])) {
    echo "Halo, " . htmlspecialchars($_COOKIE["username"]);
} else {
    echo "Cookie username tidak ada";
}

// Dengan null coalescing
$tema = $_COOKIE["tema"] ?? "terang";
$bahasa = $_COOKIE["bahasa"] ?? "id";
```

> [!IMPORTANT]
Cookie baru bisa dibaca di `$_COOKIE` **pada request berikutnya** setelah `setcookie()` dipanggil, bukan pada request yang sama.

```php
<?php
// Request ini: set cookie
setcookie("nama", "Budi", time() + 3600);

// ❌ Masih kosong — cookie belum sampai
echo $_COOKIE["nama"] ?? "belum ada";  // "belum ada"

// ✅ Baru tersedia di request/halaman BERIKUTNYA
```

### 2.5 Menghapus Cookie

Cookie dihapus dengan **menetapkan waktu kadaluarsa di masa lalu**:

```php
<?php
// Cara 1: expire di masa lalu
setcookie("username", "", time() - 3600, "/");

// Cara 2: expire = 1 Januari 1970
setcookie("username", "", 1, "/");

// Hapus juga dari $_COOKIE (opsional, untuk request saat ini)
unset($_COOKIE["username"]);
```

> [!TIP]
Parameter `$path` dan `$domain` saat menghapus **harus sama** dengan saat membuat cookie. Jika berbeda, cookie tidak akan terhapus.

### 2.6 Menyimpan Array di Cookie

Cookie hanya bisa menyimpan **string**. Untuk menyimpan array, gunakan serialisasi atau JSON:

```php
<?php
// Simpan array sebagai JSON
$keranjang = ["laptop" => 1, "mouse" => 2];
setcookie("keranjang", json_encode($keranjang), time() + 3600, "/");

// Baca kembali
if (isset($_COOKIE["keranjang"])) {
    $keranjang = json_decode($_COOKIE["keranjang"], true);
    print_r($keranjang);  // ["laptop" => 1, "mouse" => 2]
}
```

**Atau gunakan notasi array di nama cookie:**

```php
<?php
// Set
setcookie("preferensi[tema]", "gelap", time() + 3600, "/");
setcookie("preferensi[bahasa]", "id", time() + 3600, "/");

// Baca — PHP otomatis buat array
if (isset($_COOKIE["preferensi"])) {
    $tema = $_COOKIE["preferensi"]["tema"] ?? "terang";
    $bahasa = $_COOKIE["preferensi"]["bahasa"] ?? "id";
}
```

### 2.7 Batasan Cookie

| Batasan | Nilai |
| :--- | :--- |
| **Ukuran per cookie** | ~4 KB (4096 byte) |
| **Jumlah per domain** | ~20-50 cookie (tergantung browser) |
| **Total semua domain** | ~300 cookie |
| **Tipe data** | Hanya string |

## 3. Session

Session menyimpan data **di server**. Browser hanya menyimpan **Session ID** (dalam cookie), yang digunakan server untuk mencocokkan data yang sesuai.

### 3.1 Diagram Alur Session

```text
1. User mengunjungi halaman
   Browser ──── Request ────► Server
                                 │
                                 ├── session_start()
                                 ├── Buat Session ID baru: abc123
                                 ├── Simpan data di server: /tmp/sess_abc123
                                 └── Kirim cookie: PHPSESSID=abc123
   Browser ◄── Response + Cookie ────

2. User membuka halaman lain
   Browser ──── Request + Cookie(PHPSESSID=abc123) ────► Server
                                                              │
                                                              ├── session_start()
                                                              ├── Baca Session ID: abc123
                                                              ├── Muat data dari: /tmp/sess_abc123
                                                              └── $_SESSION tersedia
```

### 3.2 Memulai Session — `session_start()`

```php
<?php
// Wajib di awal file, sebelum output apapun
session_start();

// Sekarang $_SESSION tersedia
$_SESSION["username"] = "Budi";
$_SESSION["role"] = "admin";
```

> [!WARNING]
Sama seperti `setcookie()`, `session_start()` **harus dipanggil sebelum output apapun** dikirim ke browser.

### 3.3 Menyimpan dan Membaca Data Session

```php
<?php
session_start();

// Menyimpan data
$_SESSION["username"] = "Budi";
$_SESSION["loginTime"] = time();
$_SESSION["keranjang"] = ["laptop" => 1, "mouse" => 2];

// Membaca data
echo $_SESSION["username"];              // Budi
echo date("H:i", $_SESSION["loginTime"]); // 14:30
print_r($_SESSION["keranjang"]);          // ["laptop" => 1, "mouse" => 2]

// Cek apakah key ada
if (isset($_SESSION["username"])) {
    echo "User sudah login";
}

// Hapus key tertentu
unset($_SESSION["keranjang"]);

// Hapus semua data session
$_SESSION = [];
```

### 3.4 Session ID

```php
<?php
session_start();

// Mendapatkan Session ID
$sid = session_id();
echo $sid;  // contoh: a3f8b2c1d4e5f6g7h8i9j0

// Membuat Session ID baru (misalnya setelah login)
session_regenerate_id(true);
// true = hapus session lama

// Parameter session_id() juga bisa dipakai untuk set custom ID
// (panggil SEBELUM session_start())
// session_id("custom-id-123");
// session_start();
```

> [!IMPORTANT]
Selalu panggil `session_regenerate_id(true)` **setelah login berhasil**. Ini mencegah **session fixation attack** — serangan di mana penyerang memaksa victim menggunakan Session ID yang sudah diketahui.

### 3.5 Menghancurkan Session

```php
<?php
session_start();

// 1. Hapus semua data session
$_SESSION = [];

// 2. Hapus cookie session dari browser
if (ini_get("session.use_cookies")) {
    $params = session_get_cookie_params();
    setcookie(
        session_name(),       // nama cookie (biasanya PHPSESSID)
        "",                   // nilai kosong
        time() - 42000,      // expire di masa lalu
        $params["path"],
        $params["domain"],
        $params["secure"],
        $params["httponly"]
    );
}

// 3. Hapus file session di server
session_destroy();

// 4. Redirect ke halaman login
header("Location: login.php");
exit;
```

> [!TIP]
Langkah 1 dan 2 penting. `session_destroy()` saja tidak cukup — `$_SESSION` masih tersedia di request saat ini, dan cookie di browser belum terhapus.

### 3.6 Konfigurasi Session (`php.ini`)

```ini
; php.ini — konfigurasi session

session.save_handler = files       ; Cara menyimpan (files, redis, memcached)
session.save_path = "/tmp"         ; Folder penyimpanan file session
session.name = "PHPSESSID"         ; Nama cookie session
session.gc_maxlifetime = 1440      ; Lifetime session (detik) — default 24 menit
session.cookie_lifetime = 0        ; 0 = cookie hilang saat browser ditutup
session.cookie_path = "/"          ; Path cookie
session.cookie_domain = ""         ; Domain cookie
session.cookie_secure = Off        ; On = hanya kirim via HTTPS
session.cookie_httponly = Off      ; On = tidak bisa diakses JavaScript
session.use_strict_mode = 0        ; 1 = reject uninitialized session ID
session.use_only_cookies = 1       ; 1 = hanya terima SID dari cookie, bukan URL
```

**Mengatur secara runtime:**

```php
<?php
// Sebelum session_start()
ini_set("session.cookie_lifetime", 3600);      // 1 jam
ini_set("session.cookie_httponly", "1");       // HttpOnly
ini_set("session.cookie_secure", "1");         // HTTPS only
ini_set("session.use_strict_mode", "1");       // Strict mode

session_start();
```

### 3.7 Session Timeout

```php
<?php
session_start();

// Timeout 30 menit
$timeout = 30 * 60; // 1800 detik

if (isset($_SESSION["lastActivity"])) {
    $idle = time() - $_SESSION["lastActivity"];

    if ($idle > $timeout) {
        // Session expired — logout user
        $_SESSION = [];
        session_destroy();
        header("Location: login.php?msg=expired");
        exit;
    }
}

// Update waktu aktivitas terakhir
$_SESSION["lastActivity"] = time();
```

## 4. Perbandingan Session vs Cookie

| Aspek | Session | Cookie |
| :--- | :--- | :--- |
| **Disimpan di** | Server | Browser (client) |
| **Kapasitas** | Tidak terbatas | ~4 KB per cookie |
| **Tipe data** | Semua tipe PHP (array, object, dll.) | Hanya string |
| **Keamanan** | Tinggi (user tidak bisa lihat/ubah) | Rendah (user bisa lihat & ubah) |
| **Lifetime** | Terbatas (default 24 menit idle) | Bisa diatur lama (hari/bulan/tahun) |
| **Browser ditutup** | Session hilang (default) | Tergantung expire |
| **Membutuhkan cookie?** | Ya (untuk Session ID) | Tidak |
| **Cocok untuk** | Data sensitif (login, keranjang) | Preferensi (tema, bahasa, remember me) |

> [!TIP]
**Aturan praktis**: Data sensitif dan sementara → **Session**. Data yang perlu bertahan lama dan tidak sensitif → **Cookie**.

## 5. Autentikasi Login dengan Session

### 5.1 File: `login.php`

```php
<?php
session_start();

// Jika sudah login, redirect ke dashboard
if (isset($_SESSION["user"])) {
    header("Location: dashboard.php");
    exit;
}

$error = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $username = trim($_POST["username"] ?? "");
    $password = $_POST["password"] ?? "";

    // Simulasi user database (dalam praktik nyata, query ke DB)
    $users = [
        "admin" => password_hash("admin123", PASSWORD_DEFAULT),
        "budi"  => password_hash("budi123", PASSWORD_DEFAULT),
    ];

    if ($username === "" || $password === "") {
        $error = "Username dan password wajib diisi";
    } elseif (!array_key_exists($username, $users)) {
        $error = "Username tidak ditemukan";
    } elseif (!password_verify($password, $users[$username])) {
        $error = "Password salah";
    } else {
        // ✅ Login berhasil
        session_regenerate_id(true);  // Cegah session fixation

        $_SESSION["user"] = [
            "username"  => $username,
            "loginTime" => time(),
            "role"      => $username === "admin" ? "admin" : "user"
        ];

        header("Location: dashboard.php");
        exit;
    }
}
```

```php
$_SESSION = [];

if (ini_get("session.use_cookies")) {

```

## 6. Fitur "Remember Me" dengan Cookie

Menggabungkan session (untuk login aktif) dengan cookie (untuk login otomatis saat kembali):

### 6.1 Saat Login (dengan "Remember Me")

```php
<?php
session_start();

// ... validasi login berhasil ...

// Set session
$_SESSION["user"] = $userData;

// Jika "Remember Me" dicentang
if (isset($_POST["remember"])) {
    // Buat token unik dan aman
    $token = bin2hex(random_bytes(32));  // 64 karakter hex

    // Simpan token di database, terkait dengan user
    // DB: INSERT INTO remember_tokens (user_id, token, expires) VALUES (...)

    // Set cookie — berlaku 30 hari
    setcookie("remember_token", $token, time() + (30 * 24 * 3600), "/", "", true, true);
}
```

### 6.2 Saat Menguji Auto-Login

```php
<?php
session_start();

// Jika belum login, tapi ada cookie "remember me"
if (!isset($_SESSION["user"]) && isset($_COOKIE["remember_token"])) {
    $token = $_COOKIE["remember_token"];

    // Cari token di database
    // $user = DB: SELECT * FROM remember_tokens WHERE token = ? AND expires > NOW()

    // Jika token valid:
    if ($user !== null) {
        session_regenerate_id(true);
        $_SESSION["user"] = $user;

        // Regenerasi token baru (token rotation)
        $newToken = bin2hex(random_bytes(32));
        // DB: UPDATE remember_tokens SET token = ? WHERE token = ?
        setcookie("remember_token", $newToken, time() + (30 * 24 * 3600), "/", "", true, true);
    } else {
        // Token tidak valid — hapus cookie
        setcookie("remember_token", "", time() - 3600, "/", "", true, true);
    }
}
```

### 6.3 Saat Logout

```php
<?php
session_start();

// Hapus token dari database
if (isset($_COOKIE["remember_token"])) {
    // DB: DELETE FROM remember_tokens WHERE token = ?
    setcookie("remember_token", "", time() - 3600, "/", "", true, true);
}

// Hancurkan session
$_SESSION = [];
session_destroy();
header("Location: login.php");
exit;
```

## 7. Keranjang Belanja dengan Session

### 7.1 File: `keranjang.php`

```php
<?php
session_start();

// Inisialisasi keranjang
if (!isset($_SESSION["keranjang"])) {
    $_SESSION["keranjang"] = [];
}

$keranjang = &$_SESSION["keranjang"]; // reference agar mudah diakses

// Produk yang tersedia
$produk = [
    1 => ["nama" => "Laptop",    "harga" => 12000000],
    2 => ["nama" => "Mouse",     "harga" => 150000],
    3 => ["nama" => "Keyboard",  "harga" => 500000],
    4 => ["nama" => "Monitor",   "harga" => 3000000],
    5 => ["nama" => "Headset",   "harga" => 750000],
];

$pesan = "";

// Aksi: Tambah ke keranjang
if (isset($_GET["tambah"])) {
    $id = (int) $_GET["tambah"];
    if (isset($produk[$id])) {
        if (isset($keranjang[$id])) {
            $keranjang[$id]++;
        } else {
            $keranjang[$id] = 1;
        }
        $pesan = "✅ {$produk[$id]['nama']} ditambahkan!";
    }
}

// Aksi: Kurangi
if (isset($_GET["kurangi"])) {
    $id = (int) $_GET["kurangi"];
    if (isset($keranjang[$id])) {
        $keranjang[$id]--;
        if ($keranjang[$id] <= 0) {
            unset($keranjang[$id]);
        }
        $pesan = "Jumlah dikurangi";
    }
}

// Aksi: Hapus
if (isset($_GET["hapus"])) {
    $id = (int) $_GET["hapus"];
    unset($keranjang[$id]);
    $pesan = "Produk dihapus dari keranjang";
}

// Aksi: Kosongkan
if (isset($_GET["kosongkan"])) {
    $keranjang = [];
    $pesan = "Keranjang dikosongkan";
}

// Hitung total
$subtotal = 0;
foreach ($keranjang as $id => $qty) {
    $subtotal += $produk[$id]["harga"] * $qty;
}
?>
<!DOCTYPE html>
<html>
<head><title>Keranjang Belanja</title>
<style>
    body { font-family: sans-serif; max-width: 700px; margin: 20px auto; }
    .pesan { background: #efe; padding: 8px; border-radius: 4px; margin-bottom: 10px; }
    table { width: 100%; border-collapse: collapse; }
    th, td { border: 1px solid #ddd; padding: 10px; text-align: left; }
    th { background: #f5f5f5; }
    .btn { display: inline-block; padding: 4px 10px; color: #2563eb; text-decoration: none; border: 1px solid #2563eb; border-radius: 3px; font-size: 0.85em; }
    .btn-danger { color: #dc2626; border-color: #dc2626; }
    .produk-list { display: flex; gap: 10px; flex-wrap: wrap; margin-bottom: 20px; }
    .produk-card { border: 1px solid #ddd; padding: 12px; border-radius: 6px; width: 120px; text-align: center; }
    .produk-card a { text-decoration: none; color: #2563eb; font-weight: bold; }
</style>
</head>
<body>
    <h1>🛒 Keranjang Belanja</h1>

    <?php if ($pesan): ?>
        <div class="pesan"><?= htmlspecialchars($pesan) ?></div>
    <?php endif; ?>

    <h2>Produk</h2>
    <div class="produk-list">
        <?php foreach ($produk as $id => $p): ?>
            <div class="produk-card">
                <strong><?= $p["nama"] ?></strong><br>
                <small>Rp<?= number_format($p["harga"], 0, ',', '.') ?></small><br>
                <a href="?tambah=<?= $id ?>" class="btn">+ Tambah</a>
            </div>
        <?php endforeach; ?>
    </div>

    <?php if (empty($keranjang)): ?>

    <?php else: ?>
        <table>
            <tr>
                <th>Produk</th>
                <th>Harga</th>
                <th>Qty</th>

            <?php foreach ($keranjang as $id => $qty): ?>
                <tr>
                    <td><?= htmlspecialchars($produk[$id]["nama"]) ?></td>
                    <td>Rp<?= number_format($produk[$id]["harga"], 0, ',', '.') ?></td>
                    <td><?= $qty ?></td>
                    <td>Rp<?= number_format($produk[$id]["harga"] * $qty, 0, ',', '.') ?></td>
                    <td>
```

## 10. Keamanan Session dan Cookie

### 10.1 Session Hijacking

Serangan di mana penyerang **mencuri Session ID** yang valid dan menggunakannya untuk menyamar sebagai user.

**Pencegahan:**

```php
<?php
session_start();

// 1. Regenerasi Session ID setelah login
session_regenerate_id(true);

// 2. Validasi User-Agent dan IP (opsional, bisa terlalu ketat)
$currentUserAgent = $_SERVER["HTTP_USER_AGENT"] ?? "";
$currentIP = $_SERVER["REMOTE_ADDR"] ?? "";

if (isset($_SESSION["userAgent"])) {
    if ($_SESSION["userAgent"] !== $currentUserAgent) {
        // User-Agent berubah — kemungkinan hijacking
        session_destroy();
        header("Location: login.php?msg=security");
        exit;
    }
} else {
    $_SESSION["userAgent"] = $currentUserAgent;
}
```

### 10.2 Session Fixation

Serangan di mana penyerang **memaksa victim menggunakan Session ID tertentu** sebelum login.

**Pencegahan:**

```php
<?php
// 1. Aktifkan use_strict_mode
ini_set("session.use_strict_mode", "1");

// 2. Selalu regenerasi ID setelah login
session_regenerate_id(true);
```

### 10.3 XSS dan Cookie

Jika JavaScript bisa membaca cookie session, XSS attack bisa mencuri Session ID.

**Pencegahan:**

```php
<?php
// Set HttpOnly — JavaScript tidak bisa akses cookie
ini_set("session.cookie_httponly", "1");

// Set Secure — hanya kirim via HTTPS
ini_set("session.cookie_secure", "1");

// Set SameSite (PHP 7.3+)
ini_set("session.cookie_samesite", "Strict");
```

### 10.4 Cookie Tampering

User bisa mengubah nilai cookie secara manual.

**Pencegahan:**

```php
<?php
// ❌ Jangan simpan data sensitif di cookie
setcookie("role", "admin", ...);  // User bisa ubah jadi "admin"!

// ✅ Simpan token acak di cookie, verifikasi di server
$token = bin2hex(random_bytes(32));
setcookie("auth_token", $token, ...);
// Di server: cocokkan token dengan database
```

### 10.5 Tabel Ringkasan Keamanan

| Ancaman | Target | Pencegahan |
| :--- | :--- | :--- |
| **Session Hijacking** | Mencuri SID | `session_regenerate_id(true)`, validasi UA/IP |
| **Session Fixation** | Memaksa SID tertentu | `use_strict_mode = 1`, regenerasi ID setelah login |
| **XSS → Cookie Theft** | Mencuri cookie via JS | `httponly = 1`, `samesite = Strict` |
| **Cookie Tampering** | Mengubah nilai cookie | Simpan token, bukan data; verifikasi di server |
| **CSRF** | Memaksa user melakukan aksi | Token CSRF di session & form |

## 11. Flash Message dengan Session

Flash message adalah pesan yang **hanya ditampilkan sekali** (setelah redirect), lalu dihapus.

```php
<?php
// Fungsi helper
function setFlash(string $type, string $pesan): void {
    $_SESSION["flash"] = ["type" => $type, "pesan" => $pesan];
}

function getFlash(): ?array {
    if (isset($_SESSION["flash"])) {
        $flash = $_SESSION["flash"];
        unset($_SESSION["flash"]);
        return $flash;
    }
    return null;
}

function tampilFlash(): void {
    $flash = getFlash();
    if ($flash === null) return;

    $warna = match ($flash["type"]) {
        "success" => "#efe; border-color: #0a0; color: #050",
        "error"   => "#fee; border-color: #f00; color: #500",
        "warning" => "#ffe; border-color: #fa0; color: #540",
        "info"    => "#eef; border-color: #00f; color: #005",
        default   => "#eee; border-color: #999; color: #333"
    };

    echo "<div style='background: $warna; padding: 12px; border-radius: 4px; margin: 10px 0; border: 1px solid;'>";
    echo htmlspecialchars($flash["pesan"]);
    echo "</div>";
}

// --- Penggunaan ---

// Di file proses.php (setelah aksi):
session_start();
setFlash("success", "Data berhasil disimpan!");
header("Location: index.php");
exit;

// Di file index.php (halaman tujuan):
session_start();
tampilFlash();  // Tampil sekali, lalu hilang
```
