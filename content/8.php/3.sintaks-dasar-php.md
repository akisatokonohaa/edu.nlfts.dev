# Sintaks Dasar PHP

Memahami dasar-dasar penulisan kode PHP agar dapat membuat program dengan struktur dan sintaks yang benar. Pada bagian ini, kamu akan mempelajari cara menggunakan tag pembuka dan penutup PHP, menulis komentar untuk memberikan penjelasan pada kode, serta menampilkan informasi atau hasil program menggunakan berbagai fungsi output.

Materi ini menjadi langkah awal untuk memahami bagaimana PHP membaca dan menjalankan kode, sekaligus membiasakan diri menulis kode yang rapi, terstruktur, dan mudah dipahami.

---

## 1. Tag PHP
Kode PHP ditulis di dalam file dengan ekstensi `.php`, namun tidak semua isi file harus berupa kode PHP. File `.php` bisa berisi campuran HTML dan PHP. Agar interpreter PHP mengetahui mana bagian yang merupakan kode PHP, kita menggunakan tag pembuka dan tag penutup.

### 1.1 Sintaks Standar (Wajib Diketahui)
```php
<?php
// kode PHP ditulis disini 
?>
```
<!-- > [!INFO] -->
*Penjelasan*
- `<?php` : Tag Pembuka - Memberi tahu interpreter bahwa kode di belakangnya adalah PHP
- `?>`    : Tag Penutup - Mengembalikan kontrol ke HTML(Opsional)

Contoh di tengah **HTML** `tes.php`
```php
<!DOCTYPE html>
<html>
<head>
    <title>Halaman PHP Pertama</title>
</head>
<body>
    <h1>Selamat Datang</h1>
    <p>Hari ini tanggal: <?php echo date("d F Y"); ?></p>
    <p>Copyright &copy; <?php echo date("Y"); ?> - Website Saya</p>
</body>
</html>
```
> [!TIP]
Perhatikan bahwa PHP bisa disisipkan di mana saja di dalam HTML — di antara tag, di dalam atribut, atau di mana pun kamu butuh output dinamis.

### 1.2 Tag Penutup `?>`: Dipakai atau Tidak?
Rekomendasi resmi PHP: Jangan gunakan tag penutup `?>` pada file yang hanya berisi kode PHP (tanpa HTML di bawahnya).
```php
<?php
// ✅ — tanpa tag penutup
$nama = "Budi";
echo $nama;

// ❌ - hindari tag penutup tidak perlu di sini
// ?>
```
#### Alasannya:
| MASALAH | PENJELASAN |
| --- | --- |
| Spasi tersembunyi | Spasi atau baris kosong setelah `?>` akan terkirim ke browser, bisa menyebabkan error `headers already sent` saat menggunakan `header()` atau `session_start()` |
| Konsistensi | Tanpa tag penutup, kode lebih bersih dan tidak ada risiko error yang tidak terduga |

**Kapan wajib** pakai `?>`? Hanya ketika kamu perlu kembali ke HTML di bawah kode PHP:
```php
<?php
if ($loggedIn) {
    ?>
    <p>Selamat datang kembali!</p>
    <?php
} else {
    ?>
    <p>Silakan login terlebih dahulu.</p>
    <?php
}
```

## 2. Sintaks Alternatif Tag PHP (Tahukah Kamu?)
Selain `<?php`, ada beberapa format tag lain. Namun, **hanya** `<?php` yang direkomendasikan.
| Tag | Status | Keterangan |
| :--- | :--- | :--- |
| `<?php ... ?>` | ✅ **Selalu tersedia** | Standar resmi, wajib digunakan |
| `<? ... ?>` | ⚠️ *Short tags* | Harus diaktifkan via `short_open_tag = On` di `php.ini` — **hindari** |
| `<script language="php"> ... </script>` | ❌ *Deprecated* | Dihapus sejak PHP 7.0 |
| `<% ... %>` | ❌ *ASP-style tags* | Harus diaktifkan manual — **hindari** |

```php
<?php echo "Selalu gunakan ini"; ?>     <!-- ✅ Benar -->
<? echo "Jangan gunakan ini"; ?>        <!-- ❌ Hindari -->
```
## 3. Komentar
Komentar digunakan untuk memberikan catatan pada kode. Komentar tidak akan dieksekusi oleh PHP dan tidak akan muncul di browser.

### 3.1 Komentar Satu Baris
```php
<?php
// Ini komentar satu baris (double slash)

# Ini juga komentar satu baris (hash)
// Lebih umum pakai double slash daripada hash
```

### 3.2 Komentar Beberapa Baris
```php
<?php
/*
   Ini komentar beberapa baris.
   Cocok untuk penjelasan yang panjang,
   misalnya dokumentasi fungsi atau algoritma.
*/
```
### 3.3 Komentar di Tengah Baris
```php
<?php

$harga = 15000; // Harga dalam Rupiah
$diskon = 0.1;  // Diskon 10%
```
### 3.4 Komentar untuk Menonaktifkan Kode Sementara
```php
<?php
// echo "Baris ini tidak akan dijalankan";
// $total = $harga * $diskon;

/*
 $total = $harga - ($harga * $diskon);
echo $total;
*/
```
> [!TIP]
**Best Practice:** Tulis komentar untuk menjelaskan mengapa (why), bukan apa (what). Kode yang baik seharusnya sudah menjelaskan apa yang dilakukan.
```php
// ❌ Kurang bermakna
// Menambahkan 1 ke variabel umur
 $umur++;

// ✅ Lebih bermakna
// Umur bertambah setiap tahun pada tanggal lahir
 $umur++;
 ```

## 4. Menampilkan Output
PHP menyediakan beberapa cara untuk menampilkan output ke browser.

### 4.1 `echo` — Perintah Output Utama
`echo` bukanlah fungsi, melainkan bahasa konstruk (*language construct*). Artinya, ia bukan fungsi yang mengembalikan nilai, melainkan perintah langsung dari PHP.
```php
<?php
echo "Halo Dunia!";
echo "<br>";
echo "Saya sedang belajar PHP.";
```
#### 4.1.1 Menampilkan beberapa argumen sekaligus (dipisah koma):
```php
<?php
echo "Halo", " ", "Dunia", "!";
// Hasil: Halo Dunia!
```
#### 4.1.2 Menggabungkan string dengan titik (`.`):
```php
<?php
 $nama = "Andi";
echo "Nama saya " . $nama . ".";
// Hasil: Nama saya Andi.
```
#### 4.1.3 Menggunakan *heredoc* untuk teks panjang:
```php
<?php
 $html = <<<HTML
    <div class="card">
        <h2>Selamat Datang</h2>
        <p>Ini adalah contoh heredoc.</p>
    </div>
HTML;

echo $html;
```
#### 4.1.4 Menggunakan *nowdoc* (seperti *heredoc*, tapi tidak memproses variabel):
```php
<?php
 $teks = <<<'TEXT'
    Variabel seperti $nama TAKAN diproses di dalam nowdoc.
    Teks ini ditampilkan apa adanya.
TEXT;

echo $teks;
```

### 4.2 `print` — Alternatif Output
`print` juga merupakan language construct, mirip dengan `echo`, namun ada beberapa perbedaan:
```php
<?php
print "Halo Dunia!";
```
#### 4.2.1 Perbedaan `echo` vs `print`
| Aspek | `echo` | `print` |
| :--- | :--- | :--- |
| **Argumen** | Bisa menerima banyak argumen (dipisah koma) | Hanya menerima 1 argumen |
| **Return value** | Tidak mengembalikan nilai | Mengembalikan `1` (selalu) |
| **Kecepatan** | Sedikit lebih cepat | Sedikit lebih lambat |
| **Penggunaan umum** | Hampir selalu digunakan | Jarang digunakan |
```php
<?php
// echo: bisa banyak argumen
echo "Satu", " ", "Dua", " ", "Tiga";

// print: hanya satu argumen
print "Satu";

// print bisa digunakan dalam ekspresi karena punya return value
$result = print "Halo!";
// $result akan bernilai 1
```
**Kesimpulan:** *Gunakan echo untuk semua kebutuhan output. print hanya perlu kamu tahu existensinya, tapi jarang dibutuhkan di praktik nyata.*

#### 4.2.2 `printf` dan `sprintf` — Output Terformat
Digunakan ketika kamu butuh format output yang lebih terkontrol.
```php
<?php

$nama = "Budi";
$umur = 25;

// printf: langsung menampilkan ke browser
printf("Nama: %s, Umur: %d tahun", $nama, $umur);
// Hasil: Nama: Budi, Umur: 25 tahun

// sprintf: mengembalikan string (tidak langsung ditampilkan)
$teks = sprintf("Nama: %s, Umur: %d tahun", $nama, $umur);
echo $teks;
```
##### Format specifier yang umum:
| Specifier | Tipe Data | Contoh |
| :--- | :--- | :--- |
| `%s` | String | `"Budi"` |
| `%d` | Bilangan bulat (*integer*) | `25` |
| `%f` | Bilangan desimal (*float*) | `3.14` |
| `%.2f` | Float 2 desimal | `3.14` |
| `%b` | Bilangan biner | `11001` |
| `%x` | Bilangan heksadesimal | `1a` |
```php
<?php
 $harga = 150000;
 $berat = 2.5678;

printf("Harga: Rp%d\n", $harga);          // Harga: Rp150000
printf("Harga: Rp%s\n", number_format($harga, 0, ',', '.'));  // Harga: Rp150.000
printf("Berat: %.2f kg\n", $berat);      // Berat: 2.57 kg
```

#### 4.2.3 Akhir Pernyataan (Semicolon)
Setiap pernyataan (*statement*) di PHP **wajib** diakhiri dengan titik koma (`;`).
```php
<?php
echo "Baris pertama";    // ← titik koma wajib
echo "Baris kedua";      // ← titik koma wajib
```
```text
Parse error: syntax error, unexpected token "echo" in ...
```
PHP akan memberitahu bahwa ada kesalahan sintaks karena mengharapkan titik koma sebelum echo berikutnya.
#### 4.2.4 Pengecualian — tidak butuh titik koma:
```php
<?php
// Tag penutup PHP menggantikan titik koma
echo "Tidak perlu titik koma di sini" ?>
```

## 5. Case Sensitivity
PHP membedakan huruf besar dan kecil (*case-sensitive*) untuk beberapa hal, namun tidak untuk yang lain.
| Elemen | Case Sensitive? | Contoh |
| :--- | :---: | :--- |
| **Nama variabel** | ✅ Ya | `$nama` ≠ `$Nama` ≠ `$NAMA` |
| **Nama konstanta** | ✅ Ya* | `NAMA` ≠ `nama` (*default, bisa diubah*) |
| **Nama fungsi** | ❌ Tidak | `echo()` = `ECHO()` = `Echo()` |
| **Nama class** | ❌ Tidak** | ` MyClass` = `myclass` (**default*) |
| **Kata kunci** | ❌ Tidak | `if` = `IF` = `If` |
```php
<?php
// Variabel — CASE SENSITIVE
 $warna = "merah";
echo $warna;   // merah
echo $Warna;   // Warning: Undefined variable $Warna
echo $WARNA;   // Warning: Undefined variable $WARNA

// Fungsi — TIDAK CASE SENSITIVE
echo strlen("halo");  // 4
echo STRLEN("halo");  // 4
echo StrLen("halo");  // 4
```
> [!DANGER]
Meskipun nama fungsi tidak *case-sensitive**, **selalu tulis dalam huruf kecil** untuk konsistensi dan keterbacaan.

## 6. Spasi dan Baris Baru
PHP mengabaikan spasi berlebih, tab, dan baris baru di antara pernyataan. Artinya, ketiga cara berikut menghasilkan output yang sama:
```php
<?php
echo "Halo"; echo "Dunia";
```
```php
<?php
echo "Halo";
echo "Dunia";
```
```php
<?php
echo
    "Halo"
;
echo
    "Dunia"
;
```
Namun, untuk keterbacaan, selalu **tulis satu pernyataan per baris** dan gunakan indentasi yang konsisten.

```php
echo "Ini ditampilkan dengan echo<br>";
print "Ini ditampilkan dengan print<br>";

// === Latihan 3: Menggabungkan string ===
$kota = "Jakarta";
$negara = "Indonesia";
echo "Saya tinggal di " . $kota . ", " . $negara . ".<br>";

// === Latihan 4: printf terformat ===
$produk = "Buku PHP";
$harga = 85000;
$diskon = 15;
printf("Produk: %s | Harga: Rp%s | Diskon: %d%%<br>",
    $produk,
    number_format($harga, 0, ',', '.'),

        <strong>Halo, $nama!</strong><br>

    </div>
PESAN;
echo $pesan;
```
