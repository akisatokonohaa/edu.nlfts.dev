# OOP Mendalam

Interface, Trait, Namespace, Autoloading, dan Composer — topik OOP modern yang wajib dikuasai sebelum terjun ke framework PHP seperti Laravel atau Symfony.

---

## 1. Kenapa Perlu OOP Lanjutan?

Saat aplikasi PHP tumbuh hingga ratusan class, muncul masalah baru:

```text
┌──────────────────────────────────────────┐
│ Tanpa Namespace & Autoloading            │
├──────────────────────────────────────────┤
│ ❌ require_once "classes/User.php";       │
│ ❌ require_once "classes/Product.php";   │
│ ❌ require_once "classes/Order.php";     │
│ ❌ ... ratusan baris require ...         │
│ ❌ Konflik nama: dua class "User"        │
│ ❌ Code duplikat di banyak class          │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│ Dengan Namespace + Composer              │
├──────────────────────────────────────────┤
│ ✅ Cukup: require "vendor/autoload.php" │
│ ✅ Class auto-load saat pertama dipakai   │
│ ✅ App\Models\User vs Auth\User           │
│ ✅ Trait untuk reusable code              │
└──────────────────────────────────────────┘
```

## 2. Interface (Mendalam)

Interface adalah **kontrak** — class yang `implements` interface wajib menyediakan semua method yang dideklarasikan.

### 2.1 Multiple Interface & Constants

Class bisa implements banyak interface sekaligus.

```php
<?php
interface Loggable {
    public const LOG_FILE = "/var/log/app.log";
    public function log(string $pesan): void;
}

interface Serializable {
    public function toArray(): array;
    public function toJson(): string;
}

class User implements Loggable, Serializable {
    public function __construct(
        private string $nama,
        private string $email
    ) {}

    public function log(string $pesan): void {
        file_put_contents(self::LOG_FILE, $pesan . "\n", FILE_APPEND);
    }

    public function toArray(): array {
        return ['nama' => $this->nama, 'email' => $this->email];
    }

    public function toJson(): string {
        return json_encode($this->toArray());
    }
}
```

### 2.2 Interface Inheritance

Interface bisa `extends` interface lain.

```php
<?php
interface CRUD {
    public function create(array $data): int;
    public function read(int $id): ?array;
    public function update(int $id, array $data): bool;
    public function delete(int $id): bool;
}

interface SoftDelete {
    public function trash(int $id): bool;
    public function restore(int $id): bool;
}

// Interface gabungan
interface Repository extends CRUD, SoftDelete {
    public function paginate(int $page, int $perHalaman): array;
}

class ProdukRepo implements Repository {
    // WAJIB implementasi: create, read, update, delete, trash, restore, paginate
}
```

### 2.3 Default Method Interface (PHP 8.0+)

Di PHP 8, interface bisa punya implementasi default.

```php
<?php
interface Sapaable {
    public function sapa(): string {
        return "Halo dari " . static::class;
    }
}

class Orang implements Sapaable {
    // Tidak perlu buat method sapa(), sudah ada default-nya
}

echo (new Orang())->sapa();  // Halo dari Orang
```

## 3. Trait

### 3.1 Apa itu Trait?

PHP tidak mendukung *multiple inheritance* (satu class tidak bisa `extends` dua class). Trait adalah mekanisme **reuse method ke banyak class** tanpa inheritance.

```text
           Trait Logger
           ┌──────────────┐
           │  log()       │
           │  error()     │
           └──────┬───────┘
                  │ use
       ┌──────────┴──────────┐
       │                     │
   Class A                Class B
   (User)                 (Order)
```

### 3.2 Membuat & Menggunakan Trait

```php
<?php
trait Logger {
    public function log(string $pesan): void {
        echo "[LOG " . date('H:i:s') . "] $pesan\n";
    }

    public function error(string $pesan): void {
        echo "[ERROR " . date('H:i:s') . "] $pesan\n";
        file_put_contents("error.log", $pesan . "\n", FILE_APPEND);
    }
}

trait Timestampable {
    private ?string $createdAt = null;
    private ?string $updatedAt = null;

    public function setCreatedAt(): void {
        $this->createdAt = date('Y-m-d H:i:s');
    }

    public function setUpdatedAt(): void {
        $this->updatedAt = date('Y-m-d H:i:s');
    }
}

class User {
    use Logger, Timestampable;  // ← pakai trait

    public function __construct(private string $nama) {
        $this->setCreatedAt();
        $this->log("User {$this->nama} dibuat");
    }
}

class Order {
    use Logger, Timestampable;

    public function __construct(private int $orderId) {
        $this->setCreatedAt();
        $this->log("Order #{$this->orderId} dibuat");
    }
}

$u = new User("Budi");
// [LOG 14:30:15] User Budi dibuat
$o = new Order(1234);
// [LOG 14:30:15] Order #1234 dibuat
```

### 3.3 Trait dengan Abstract Method

Trait bisa memaksa class menggunakan method tertentu.

```php
<?php
trait Singleton {
    abstract public function getConnection();  // Class wajib punya ini

    private static ?object $instance = null;

    public static function getInstance(): static {
        if (self::$instance === null) {
            self::$instance = new static();
        }
        return self::$instance;
    }
}

class Database {
    use Singleton;

    public function getConnection() {
        return new PDO("mysql:host=localhost;dbname=test", "root", "");
    }
}

$db = Database::getInstance();
```

### 3.4 Conflict Resolution

Jika dua trait punya method dengan nama sama, selesaikan dengan `insteadof` dan `as`.

```php
<?php
trait A {
    public function hello(): string { return "Hello dari A"; }
}

trait B {
    public function hello(): string { return "Hello dari B"; }
}

class C {
    use A, B {
        A::hello insteadof B;        // pakai hello() dari A, bukan B
        B::hello as helloFromB;      // buat alias untuk hello() dari B
    }
}

$c = new C();
echo $c->hello();        // Hello dari A
echo $c->helloFromB();   // Hello dari B
```

### 3.5 Mengubah Visibility Trait

```php
<?php
trait Helper {
    public function rahasia(): string {
        return "data rahasia";
    }
}

class User {
    use Helper {
        Helper::rahasia as private;  // ubah jadi private dari luar class
    }

    public function aksesRahasia(): string {
        return $this->rahasia(); // bisa diakses dari dalam
    }
}

$u = new User();
// echo $u->rahasia();  // ❌ Error — private
echo $u->aksesRahasia();  // ✅ data rahasia
```

## 4. Namespace

### 4.1 Mengapa Namespace?

Tanpa namespace, semua class harus punya nama unik global. Konflik terjadi saat pakai library pihak ketiga.

```text
Tanpa Namespace             Dengan Namespace
─────────────────           ─────────────────────────
class User {}               namespace App\Models;
                            class User {}

class User {}   ❌           namespace App\Admin;
                            class User {}   ✅ Bisa
```

### 4.2 Mendeklarasikan Namespace

```php
<?php
// File: src/Models/User.php
namespace App\Models;

class User {
    public function __construct(private string $nama) {}

    public function info(): string {
        return "User: {$this->nama}";
    }
}
```

```php
<?php
// File: src/Admin/User.php
namespace App\Admin;

class User {
    public function __construct(private string $nama, private string $role) {}

    public function info(): string {
        return "Admin User: {$this->nama} ({$this->role})";
    }
}
```

### 4.3 Menggunakan Class dari Namespace

```php
<?php
// File: index.php

// Cara 1: Pakai fully qualified name (\Awal)
$u1 = new \App\Models\User("Budi");
$u2 = new \App\Admin\User("Admin", "superadmin");

// Cara 2: use statement (paling sering dipakai)
use App\Models\User as ModelUser;
use App\Admin\User as AdminUser;

$u1 = new ModelUser("Budi");
$u2 = new AdminUser("Admin", "superadmin");

// Cara 3: use di awal file
use App\Models\User;       // User = App\Models\User
use App\Services\Logger;   // Logger = App\Services\Logger

$u = new User("Budi");
$logger = new Logger();
```

### 4.4 Konvensi PSR-4

PSR-4 adalah standar autoloading yang dipakai Composer. Aturannya: **namespace harus cocok dengan struktur folder**.

```text
Namespace                File Path (relative to src/)
─────────────────────────────────────────────────────────
App\Models\User          src/Models/User.php
App\Models\Order         src/Models/Order.php
App\Services\Logger      src/Services/Logger.php
App\Controllers\Auth     src/Controllers/Auth.php
App\Admin\User           src/Admin/User.php
```

> [!IMPORTANT]
Class `User` di namespace `App\Models` **WAJIB** ada di file `src/Models/User.php`. Kalau struktur folder salah, autoloader Composer tidak akan menemukan class tersebut.

### 4.5 Konstanta & Function di Namespace

```php
<?php
namespace App\Utils;

const VERSION = "1.0.0";

function formatRupiah(int $nilai): string {
    return "Rp" . number_format($nilai, 0, ',', '.');
}

// Akses dari luar namespace
echo \App\Utils\VERSION;
echo \App\Utils\formatRupiah(50000);
```

## 5. Autoloading

### 5.1 Manual Autoloading (`spl_autoload_register`)

Sebelum ada Composer, kita nulis autoloader manual.

```php
<?php
// autoload.php
spl_autoload_register(function (string $class) {
    // Konversi namespace ke path file
    $prefix = "App\\";
    $baseDir = __DIR__ . "/src/";

    // Cek apakah class pakai prefix kita
    if (strncmp($class, $prefix, strlen($prefix)) !== 0) {
        return;
    }

    // App\Models\User → Models/User.php
    $relativeClass = substr($class, strlen($prefix));
    $file = $baseDir . str_replace('\\', '/', $relativeClass) . ".php";

    if (file_exists($file)) {
        require $file;
    }
});

// Sekarang tidak perlu require manual
$user = new App\Models\User("Budi");
// Saat baris ini dieksekusi, autoloader akan load: src/Models/User.php
```

### 5.2 Composer Autoloading (Rekomendasi ⭐)

Buat file `composer.json` di root project:

```json
{
    "name": "budi/toko-online",
    "description": "Aplikasi toko online dengan PHP OOP",
    "type": "project",
    "autoload": {
        "psr-4": {
            "App\\": "src/",
            "Tests\\": "tests/"
        }
    },
    "require": {
        "php": ">=8.0"
    }
}
```

Jalankan perintah ini di terminal:

```bash
composer install
# atau jika belum ada composer:
# composer dump-autoload
```

Composer akan membuat folder `vendor/` yang berisi autoloader. Tinggal pakai:

```php
<?php
require_once "vendor/autoload.php";

// Sekarang semua class dengan namespace App\ bisa dipakai langsung!
$user    = new App\Models\User("Budi");
$logger  = new App\Services\Logger();
$product = new App\Models\Product\DigitalProduct();
```

### 5.3 Struktur Folder PSR-4 Lengkap

```text
toko-online/
├── composer.json
├── vendor/
│   └── autoload.php         ← di-generate composer
├── src/
│   ├── Models/
│   │   ├── User.php          namespace App\Models;
│   │   ├── Product.php       namespace App\Models;
│   │   └── Product/
│   │       └── Digital.php   namespace App\Models\Product;
│   ├── Services/
│   │   ├── Logger.php        namespace App\Services;
│   │   └── Mailer.php        namespace App\Services;
│   ├── Repositories/
│   │   └── UserRepository.php  namespace App\Repositories;
│   └── Controllers/
│       └── AuthController.php  namespace App\Controllers;
├── public/
│   └── index.php
└── tests/
    └── UserTest.php          namespace Tests;
```

## 6. Dependency Injection (DI)

### 6.1 Apa itu DI?

Class tidak membuat dependensinya sendiri (tidak pakai `new` di dalam), melainkan menerima dari luar. Ini membuat kode **mudah di-test & fleksibel**.

```php
<?php
// ❌ Tanpa DI: class terikat erat ke implementasi konkret
class UserServiceBuruk {
    private $logger;
    private $mailer;

    public function __construct() {
        $this->logger = new FileLogger();      // hardcoded!
        $this->mailer = new SmtpMailer();       // ganti mailer harus ubah class ini
    }
}

// ✅ Dengan DI: class terima dependency dari luar (lewat parameter)
class UserService {
    public function __construct(
        private LoggerInterface $logger,    // bisa FileLogger, DbLogger, dll.
        private MailerInterface $mailer
    ) {}

    public function register(string $email): void {
        $this->logger->log("Registrasi user baru: $email");
        $this->mailer->kirim($email, "Selamat datang");
    }
}

// Penggunaan
$service = new UserService(
    new FileLogger(),
    new SmtpMailer("smtp.gmail.com", 587)
);
$service->register("budi@example.com");
```

### 6.2 DI via Constructor (Rekomendasi)

```php
<?php
interface DatabaseInterface {
    public function query(string $sql, array $params = []): array;
}

class MySQLDB implements DatabaseInterface {
    public function query(string $sql, array $params = []): array {
        // implementasi MySQL
    }
}

class SQLiteDB implements DatabaseInterface {
    public function query(string $sql, array $params = []): array {
        // implementasi SQLite
    }
}

class ProductService {
    public function __construct(private DatabaseInterface $db) {}

    public function getAll(): array {
        return $this->db->query("SELECT * FROM produk");
    }
}

// Fleksibel — bisa ganti database tanpa ubah satupun kode di ProductService
$svcMySQL  = new ProductService(new MySQLDB());
$svcSQLite = new ProductService(new SQLiteDB());
```

## 7. Contoh Project Mini (Blogging App)

### 7.1 Struktur

```text
mini-blog/
├── composer.json
├── src/
│   ├── Models/
│   │   └── Post.php
│   ├── Repositories/
│   │   └── PostRepository.php
│   └── Services/
│       ├── PostService.php
│       └── Logger.php
└── public/
    └── index.php
```

### 7.2 `composer.json`

```json
{
    "autoload": {
        "psr-4": { "App\\": "src/" }
    }
}
```

### 7.3 `src/Models/Post.php`

```php
<?php
namespace App\Models;

class Post {
    public function __construct(
        private ?int $id = null,
        private string $judul = "",
        private string $konten = "",
        private ?string $createdAt = null
    ) {}

    public function getId(): ?int { return $this->id; }
    public function getJudul(): string { return $this->judul; }
    public function getKonten(): string { return $this->konten; }

    public function toArray(): array {
        return [
            'id'        => $this->id,
            'judul'     => $this->judul,
            'konten'    => $this->konten,
            'createdAt' => $this->createdAt,
        ];
    }
}
```

### 7.4 `src/Services/Logger.php`

```php
<?php
namespace App\Services;

trait Loggable {
    public function log(string $pesan): void {
        echo "[LOG] " . date('Y-m-d H:i:s') . " — $pesan\n";
    }
}

class Logger {
    use Loggable;
}
```

### 7.5 `src/Repositories/PostRepository.php`

```php
<?php
namespace App\Repositories;

use App\Models\Post;
use PDO;

class PostRepository {
    public function __construct(private PDO $pdo) {}

    public function find(int $id): ?Post {
        $stmt = $this->pdo->prepare("SELECT * FROM posts WHERE id = ?");
        $stmt->execute([$id]);
        $data = $stmt->fetch();

        if (!$data) return null;

        return new Post(
            $data['id'],
            $data['judul'],
            $data['konten'],
            $data['created_at']
        );
    }

    public function all(): array {
        $stmt = $this->pdo->query("SELECT * FROM posts ORDER BY id DESC");
        $rows = $stmt->fetchAll();

        return array_map(fn($r) => new Post(
            $r['id'], $r['judul'], $r['konten'], $r['created_at']
        ), $rows);
    }

    public function save(Post $post): int {
        if ($post->getId() === null) {
            $stmt = $this->pdo->prepare(
                "INSERT INTO posts (judul, konten) VALUES (?, ?)"
            );
            $stmt->execute([$post->getJudul(), $post->getKonten()]);
            return (int) $this->pdo->lastInsertId();
        }
        // Update logic...
        return $post->getId();
    }
}
```

### 7.6 `src/Services/PostService.php`

```php
<?php
namespace App\Services;

use App\Models\Post;
use App\Repositories\PostRepository;

class PostService {
    public function __construct(
        private PostRepository $repo,
        private Logger $logger
    ) {}

    public function createPost(string $judul, string $konten): Post {
        $post = new Post(null, $judul, $konten);
        $id = $this->repo->save($post);
        $this->logger->log("Post baru dibuat: ID $id — $judul");

        return new Post($id, $judul, $konten);
    }

    public function getPost(int $id): ?Post {
        return $this->repo->find($id);
    }

    public function getAllPosts(): array {
        return $this->repo->all();
    }
}
```

### 7.7 `public/index.php`

```php
<?php
require_once __DIR__ . "/../vendor/autoload.php";

use App\Services\PostService;
use App\Services\Logger;
use App\Repositories\PostRepository;

$pdo = new PDO("mysql:host=localhost;dbname=mini_blog", "root", "");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);

// Dependency Injection manual
$service = new PostService(new PostRepository($pdo), new Logger());

// Buat post baru
$newPost = $service->createPost("Belajar OOP", "PHP OOP itu asik!");
echo "Post ID: {$newPost->getId()}\n";

// Ambil semua
foreach ($service->getAllPosts() as $p) {
    echo "- {$p->getJudul()}\n";
}
```

## 8. Composer Package Management

Selain autoloading, Composer dipakai untuk manajemen *package* pihak ketiga.

### 8.1 Memasang Package

```bash
# Pasang package dari packagist.org
composer require monolog/monolog

# Pasang versi spesifik
composer require monolog/monolog:^3.0

# Pasang sebagai dev dependency (hanya untuk development/testing)
composer require --dev phpunit/phpunit
```

### 8.2 `composer.json` Lengkap

```json
{
    "name": "budi/toko-online",
    "description": "Aplikasi toko online OOP",
    "type": "project",
    "license": "MIT",
    "authors": [
        { "name": "Budi Santoso", "email": "budi@example.com" }
    ],
    "require": {
        "php": ">=8.1",
        "monolog/monolog": "^3.0",
        "vlucas/phpdotenv": "^5.5"
    },
    "require-dev": {
        "phpunit/phpunit": "^10.0"
    },
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    },
    "autoload-dev": {
        "psr-4": {
            "Tests\\": "tests/"
        }
    }
}
```

### 8.3 Menggunakan Package

```php
<?php
require_once "vendor/autoload.php";

use Monolog\Logger;
use Monolog\Handler\StreamHandler;

// Pakai package pihak ketiga
$log = new Logger('toko');
$log->pushHandler(new StreamHandler('app.log', Logger::WARNING));
$log->warning('Stok menipis');

// Pakai class sendiri
use App\Models\User;
$user = new User("Budi");
```

## 9. Best Practices OOP Modern

| Praktik | Penjelasan |
| :--- | :--- |
| **1 Class 1 File** | 1 file PHP = 1 class, nama file = nama class |
| **Gunakan Type Hinting** | Tipe parameter & return value wajib jelas |
| **Property Private** | Default `private`, buka via getter/setter |
| **Dependency Injection** | Jangan `new` di dalam class, terima dari luar |
| **Interface untuk Kontrak** | Tipe parameter pakai interface, bukan concrete class |
| **Namespace PSR-4** | Struktur folder sesuai namespace |
| **Composer Autoload** | Jangan tulis `spl_autoload_register` manual |
| **Immutable Object** | Pakai `readonly` ketika memungkinkan |
| **Final Class** | Tandai `final` jika tidak perlu di-extend |
| **Single Responsibility** | 1 class = 1 tugas spesifik |

### Contoh Kode Modern (PHP 8.2+)

```php
<?php
namespace App\Services;

use App\Repositories\Contracts\UserRepositoryInterface;
use App\Services\Contracts\LoggerInterface;

final class UserService {
    // Constructor promotion + readonly + interface type hint
    public function __construct(
        private readonly UserRepositoryInterface $userRepository,
        private readonly LoggerInterface $logger
    ) {}

    public function register(string $email, string $password): int {
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            throw new \InvalidArgumentException("Email tidak valid");
        }

        $this->logger->log("Registering user: $email");

        $id = $this->userRepository->create([
            'email'    => $email,
            'password' => password_hash($password, PASSWORD_DEFAULT),
        ]);

        return $id;
    }
}
```

- [ ] Bisa membuat interface dengan multiple inheritance (interface extends interface)
- [ ] Bisa membuat trait dan menggunakannya di class

- [ ] Memahami namespace dan dapat mengorganisir class dengan struktur folder
- [ ] Bisa menggunakan `use` untuk import class dari namespace lain
- [ ] Mengerti konvensi PSR-4 dan dapat membuat `composer.json`
- [ ] Bisa mengkonfigurasi Composer autoloading
- [ ] Bisa menggunakan `vendor/autoload.php` di project
- [ ] Memahami konsep Dependency Injection dan kenapa penting
- [ ] Bisa melakukan constructor injection & method injection
- [ ] Bisa membangun struktur project mini OOP lengkap (Models, Services, Repositories)
