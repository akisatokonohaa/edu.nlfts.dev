# Penanganan Form
Menerima, memvalidasi, dan mengamankan data yang dikirim pengguna melalui form HTML ke server PHP.

---

## 1. Alur Kerja Form dengan PHP
┌──────────────────────┐
│ FORM HTML │
│ (Browser/User) │
│ │
│ <form method="POST" │
│ action="proses.php">│
│ <input name="..."> │
│ <button>Submit</button>│
└──────────┬───────────┘
│
│ HTTP Request (POST body)
▼
┌──────────────────────┐
│ SERVER PHP │
│ proses.php │
│ │
│ $_POST["nama"] │ ← Ambil data
│ Validasi │ ← Cek kebenaran data
│ Sanitasi │ ← Bersihkan dari bahaya
│ Proses │ ← Simpan DB, kirim email, dll.
│ Response │ ← Tampilkan hasil/redirect
└──────────────────────┘

## 2. `GET` vs `POST`

| Aspek | `GET` | `POST` |
| :--- | :--- | :--- |
| **Data dikirim di** | URL (query string) | Body HTTP (tidak terlihat) |
| **Batas panjang** | ~2000 karakter | Tidak ada batas praktis |
| **Keamanan** | Rendah (terlihat di URL) | Lebih baik |
| **Bisa di-bookmark** | ✅ Ya | ❌ Tidak |
| **Cache** | Bisa di-cache | Tidak di-cache |
| **Idempoten** | ✅ Ya (aman diulang) | ❌ Tidak (bisa bikin duplikat) |
| **Tipe data** | Hanya teks | Teks + file upload |
| **Superglobal** | `$_GET` | `$_POST` |
| **Cocok untuk** | Pencarian, filter, pagination | Login, registrasi, upload, form data |

### 2.1 Kapan Pakai Apa?
`GET` → Ambil data (search, filter, pagination, navigasi)
`POST` → Ubah data (insert, update, delete, upload, login)

> [!TIP]
**Aturan praktis**: Jika aksi tidak mengubah data di server, pakai `GET`. Jika mengubah data, pakai `POST`.

## 3. `$_GET` — Menerima Data via GET
Data dikirim melalui **query string** di URL: `?key1=value1&key2=value2`

### 3.1 Form `GET`
```html
<!-- form_get.html -->
<form method="GET" action="proses_get.php">
    <label>Nama:</label>
    <input type="text" name="nama" required>

    <label>Kota:</label>
    <input type="text" name="kota">

    <button type="submit">Cari</button>
</form>
```
```php
<!-- proses_get.php -->
<?php
$nama = $_GET["nama"] ?? "";
$kota = $_GET["kota"] ?? "";

echo "Nama: $nama<br>";
echo "Kota: $kota<br>";
```
Saat disubmit, URL akan berubah menjadi:
```text
proses_get.php?nama=Budi&kota=Jakarta
```

### 3.2 Membuat Link `GET` Manual
Tidak selalu butuh form — bisa langsung buat link:

```php
<?php
$halaman = 1;
$keyword = "laptop";
$sort = "harga-asc";

$url = "produk.php?hal=$halaman&q=" . urlencode($keyword) . "&sort=$sort";
echo "<a href='$url'>Lihat Produk</a>";
// produk.php?hal=1&q=laptop&sort=harga-asc
```
**`urlencode` dan `urldecode`**
```php
<?php
// Spasi dan karakter khusus harus di-encode
$keyword = "laptop gaming murah";
$encoded = urlencode($keyword);
echo $encoded;           // laptop+gaming+murah

$decoded = urldecode($encoded);
echo $decoded;           // laptop gaming murah

// rawurlencode — menggunakan %20 bukan +
echo rawurlencode("hello world");  // hello%20world
```

## 4. `$_POST` — Menerima Data via POST
Data dikirim di **body HTTP**, tidak terlihat di **URL**.

### 4.1 Form POST
```html
<!-- form_post.html -->
<form method="POST" action="proses_post.php">
    <label>Nama Lengkap:</label>
    <input type="text" name="nama" required>

    <label>Email:</label>
    <input type="email" name="email" required>

    <label>Pesan:</label>
    <textarea name="pesan" rows="4" required></textarea>

    <button type="submit">Kirim</button>
</form>
```
```php
<!-- proses_post.php -->
<?php
$nama  = $_POST["nama"]  ?? "";
$email = $_POST["email"] ?? "";
$pesan = $_POST["pesan"] ?? "";

echo "<h2>Pesan Diterima</h2>";
echo "<p><strong>Nama:</strong> $nama</p>";
echo "<p><strong>Email:</strong> $email</p>";
echo "<p><strong>Pesan:</strong> " . nl2br(htmlspecialchars($pesan)) . "</p>";
```
> [!WARNING]
Saat menggunakan POST, jika user me-*refresh* halaman hasil, browser akan menampilkan peringatan "*Confirm Form Resubmission*". Ini normal dan justru melindungi dari pengiriman ganda.

## 5. `$_REQUEST` — Hindari
`$_REQUEST` menggabungkan data dari `$_GET`, `$_POST`, dan `$_COOKIE`. Jangan gunakan karena:
```php
<?php
// ❌ Jangan — tidak jelas sumber datanya
$data = $_REQUEST["nama"];

// ✅ Gunakan sumber yang spesifik
$data = $_POST["nama"];   // jelas dari POST
$data = $_GET["nama"];    // jelas dari GET
```
| Masalah | Penjelasan |
| :--- | :--- |
| **Ambiguitas** | Tidak tahu apakah data dari GET, POST, atau COOKIE |
| **Keamanan** | Cookie bisa menimpa data GET/POST |
| **Kontrol** | Sulit menentukan metode yang diharapkan |

## 6. Menentukan Metode Request
Seringkali satu file PHP menangani baik tampilan form maupun proses datanya:

```php
<?php
$isPost = $_SERVER["REQUEST_METHOD"] === "POST";
$isGet  = $_SERVER["REQUEST_METHOD"] === "GET";

if ($isPost) {
    // Proses data form
    $nama = $_POST["nama"] ?? "";
    echo "Halo, $nama!";
} else {
    // Tampilkan form
    ?>
    <form method="POST">
        <input type="text" name="nama" required>
        <button type="submit">Kirim</button>
    </form>
    <?php
}
```

## 7. Jenis Input HTML dan Cara Menerimanya

### 7.1 Input Teks
```html
<input type="text" name="username">
<input type="password" name="password">
<input type="email" name="email">
<input type="tel" name="telepon">
<input type="url" name="website">
<input type="search" name="cari">
<input type="hidden" name="token" value="abc123">
```
```php
<?php
$username = $_POST["username"] ?? "";
$password = $_POST["password"] ?? "";
$email    = $_POST["email"] ?? "";
```
> [!WARNING]
`type="email"`, `type="url"`, dll. hanya validasi di sisi browser (HTML5). User bisa mem-bypass dengan menonaktifkan JavaScript atau mengirim request manual. Validasi server tetap wajib.

### 7.2 Textarea
biasanya digunakan untuk mengisi alamat
```html
<textarea name="alamat" rows="4" cols="50"></textarea>
```
```php
<?php
$alamat = $_POST["alamat"] ?? "";
echo nl2br(htmlspecialchars($alamat));  // nl2br: \n → <br>
```
### 7.3 Select (Dropdown)
```html
<select name="kota">
    <option value="">-- Pilih Kota --</option>
    <option value="jkt">Jakarta</option>
    <option value="bdg">Bandung</option>
    <option value="sby">Surabaya</option>
</select>
```
```php
<?php
$kota = $_POST["kota"] ?? "";
$label = match ($kota) {
    "jkt" => "Jakarta",
    "bdg" => "Bandung",
    "sby" => "Surabaya",
    default => "Tidak dipilih"
};
echo "Kota: $label";
```

### 7.4 Radio Button
Hanya satu yang bisa **dipilih** dalam satu grup (`name` sama).
```html
<input type="radio" name="gender" value="L"> Laki-laki
<input type="radio" name="gender" value="P"> Perempuan
```
```php
<?php
$gender = $_POST["gender"] ?? "";
$label = $gender === "L" ? "Laki-laki" : ($gender === "P" ? "Perempuan" : "Tidak dipilih");
echo "Gender: $label";
```

### 7.5 Checkbox (Satu Nilai)
```html
<label><input type="checkbox" name="setuju" value="yes"> Saya setuju</label>
```
```php
<?php
// Checkbox yang TIDAK dicentang TIDAK akan dikirim
$setuju = isset($_POST["setuju"]) ? true : false;

if ($setuju) {
    echo "User menyetujui";
} else {
    echo "User tidak menyetujui (atau tidak mengirim)";
}
```

### 7.6 Checkbox (Multi-Value)
Untuk mengirim beberapa nilai, gunakan `name[]` (tanda kurung).
```html
<label><input type="checkbox" name="hobi[]" value="baca"> Membaca</label>
<label><input type="checkbox" name="hobi[]" value="olahraga"> Olahraga</label>
<label><input type="checkbox" name="hobi[]" value="musik"> Musik</label>
<label><input type="checkbox" name="hobi[]" value="gaming"> Gaming</label>
```
```php
<?php
// $_POST["hobi"] adalah array (jika ada yang dicentang)
$hobi = $_POST["hobi"] ?? [];

if (empty($hobi)) {
    echo "Tidak ada hobi dipilih";
} else {
    echo "Hobi: " . implode(", ", $hobi);
    // Contoh: Hobi: baca, gaming
}

// Validasi: pastikan hanya nilai yang diizinkan
$hobiValid = ["baca", "olahraga", "musik", "gaming"];
$hobiAman = array_filter($hobi, fn($h) => in_array($h, $hobiValid, true));
```

### 7.7 Select Multiple
Sama seperti checkbox multi, gunakan `name[]` dan atribut `multiple`.
```html
<select name="bahasa[]" multiple size="4">
    <option value="php">PHP</option>
    <option value="js">JavaScript</option>
    <option value="py">Python</option>
    <option value="java">Java</option>
</select>
```
```php
<?php
$bahasa = $_POST["bahasa"] ?? [];
echo "Bahasa: " . implode(", ", $bahasa);
```

### 7.8 Tabel Ringkasan Input
| Input HTML | `name` | Diterima PHP sebagai | Checkbox tidak dicentang? |
| :--- | :--- | :--- | :--- |
| `<input type="text">` | `"nama"` | `string` | — |
| `<input type="radio">` | `"gender"` | `string` (satu nilai) | Tidak dikirim |
| `<input type="checkbox">` | `"setuju"` | `string` (satu nilai) | **Tidak dikirim** |
| `<input type="checkbox" name="hobi[]">` | `"hobi[]"` | `array` | **Tidak ada di array** |
| `<select>` | `"kota"` | `string` | — |
| `<select multiple name="x[]">` | `"x[]"` | `array` | Bisa kosong `[]` |
| `<textarea>` | `"alamat"` | `string` | — |
| `<input type="file">` | `"file"` | `array` (file info) | Tidak dikirim |

## 8. Validasi Data
Validasi memastikan data yang diterima sesuai harapan sebelum diproses.

### 8.1 Validasi Wajib (Required)
```php
<?php
$errors = [];

$nama = trim($_POST["nama"] ?? "");
if ($nama === "") {
    $errors[] = "Nama wajib diisi";
}

$email = trim($_POST["email"] ?? "");
if ($email === "") {
    $errors[] = "Email wajib diisi";
}

if (empty($errors)) {
    // Lanjut proses
} else {
    // Tampilkan error
    foreach ($errors as $error) {
        echo "<p style='color:red'>$error</p>";
    }
}
```

### 8.2 Validasi Format
```php
<?php
// Email
$email = $_POST["email"] ?? "";
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $errors[] = "Format email tidak valid";
}

// URL
$website = $_POST["website"] ?? "";
if ($website !== "" && !filter_var($website, FILTER_VALIDATE_URL)) {
    $errors[] = "Format URL tidak valid";
}

// Angka
$umur = $_POST["umur"] ?? "";
if (!is_numeric($umur)) {
    $errors[] = "Umur harus berupa angka";
} elseif ((int) $umur < 0 || (int) $umur > 150) {
    $errors[] = "Umur harus antara 0-150";
}

// Panjang string
$password = $_POST["password"] ?? "";
if (strlen($password) < 8) {
    $errors[] = "Password minimal 8 karakter";
}

// Regex — kustom
$telepon = $_POST["telepon"] ?? "";
if (!preg_match('/^[\d\-\+\s]{8,15}$/', $telepon)) {
    $errors[] = "Format telepon tidak valid";
}

// Hanya huruf dan spasi
$nama = $_POST["nama"] ?? "";
if (!preg_match('/^[a-zA-Z\s]+$/', $nama)) {
    $errors[] = "Nama hanya boleh berisi huruf dan spasi";
}
```

### 8.3 Fungsi `filter_var` Lengkap
```php
<?php
// Validasi integer
$umur = filter_var("25", FILTER_VALIDATE_INT);           // 25
$umur = filter_var("abc", FILTER_VALIDATE_INT);          // false
$umur = filter_var("25", FILTER_VALIDATE_INT, [
    "options" => ["min_range" => 0, "max_range" => 150]
]);  // 25

// Validasi float
$harga = filter_var("99.99", FILTER_VALIDATE_FLOAT);     // 99.99

// Validasi boolean
$aktif = filter_var("yes", FILTER_VALIDATE_BOOLEAN);     // true
$aktif = filter_var("0", FILTER_VALIDATE_BOOLEAN);       // false
$aktif = filter_var("", FILTER_VALIDATE_BOOLEAN);        // false

// Sanitasi string
$input = "<script>alert('xss')</script>Hello";
$bersih = filter_var($input, FILTER_SANITIZE_STRING);    // Hello (tag dihapus)

// Sanitasi integer
$input = "25abc";
$bersih = filter_var($input, FILTER_SANITIZE_NUMBER_INT); // 25

// Sanitasi email
$input = "budi(email)@example.com";
$bersih = filter_var($input, FILTER_SANITIZE_EMAIL);     // budiemail@example.com

// Sanitasi URL
$input = "https://example.com/?q=<test>";
$bersih = filter_var($input, FILTER_SANITIZE_URL);       // https://example.com/?q=test
```

### 8.4 Whitelist Validation
Cara paling aman: bukan memeriksa apakah data "salah", tapi memeriksa apakah data "termasuk yang diizinkan".

```php
<?php
$role = $_POST["role"] ?? "";
$roleValid = ["admin", "editor", "user"];

if (!in_array($role, $roleValid, true)) {
    $errors[] = "Role tidak valid";
}

$kota = $_POST["kota"] ?? "";
$kotaValid = ["jkt" => "Jakarta", "bdg" => "Bandung", "sby" => "Surabaya"];

if (!array_key_exists($kota, $kotaValid)) {
    $errors[] = "Kota tidak valid";
}
```

## 9. Sanitasi Data
Sanitasi membersihkan data dari karakter berbahaya sebelum disimpan atau ditampilkan.

### 9.1 XSS Prevention — `htmlspecialchars()`
XSS (Cross-Site Scripting) terjadi ketika input user yang mengandung JavaScript ditampilkan langsung tanpa di-escape.

```php
<?php
// ❌ BAHAYA — XSS vulnerability!
$nama = $_POST["nama"];
echo "<h1>Selamat datang, $nama</h1>";

// Jika user menginput: <script>alert('hack')</script>
// Maka browser akan menjalankan JavaScript tersebut!

// ✅ AMAN — escape output
$nama = $_POST["nama"];
echo "<h1>Selamat datang, " . htmlspecialchars($nama, ENT_QUOTES, 'UTF-8') . "</h1>";

// Hasil: &lt;script&gt;alert('hack')&lt;/script&gt;
// Ditampilkan sebagai teks biasa, bukan dijalankan sebagai kode
```
**Parameter `htmlspecialchars`:**
| Parameter | Nilai | Keterangan |
| :--- | :--- | :--- |
| `flags` | `ENT_QUOTES` | Escape `'` dan `"` (direkomendasikan) |
| `flags` | `ENT_HTML5` | Mode HTML5 |
| `encoding` | `'UTF-8'` | Encoding yang digunakan |

### 9.2 `trim()` — Hapus Spasi Berlebih
```php
<?php
$input = "   Ryn   ";
$bersih = trim($input);  // "Ryn"
```

### 9.3 `stripslashes()` — Hapus Backslash
```php
<?php
// Jika magic_quotes_gpc aktif (PHP lama), quote otomatis di-escape
$input = "Budi\'s Laptop";
$bersih = stripslashes($input);  // "Budi's Laptop"
```

### 9.4 Sanitasi Kustom
```php
<?php
function sanitizeInput(string $input): string {
    $input = trim($input);
    $input = stripslashes($input);
    $input = htmlspecialchars($input, ENT_QUOTES, 'UTF-8');
    return $input;
}

// Gunakan saat MENAMPILKAN data
$nama = sanitizeInput($_POST["nama"] ?? "");
echo "<p>Nama: $nama</p>";
```
> [!IMPORTANT]
**Penting**: Sanitasi (escape) dilakukan saat menampilkan output, bukan saat menyimpan ke database. Di database, simpan data apa adanya. Escape saat render ke HTML.

```text
Input User → Validasi → Simpan ke DB (apa adanya) → Ambil dari DB → Escape → Tampilkan
```

## 10. Sticky Form (Menampilkan Nilai Setelah Submit)
Agar form tidak kehilangan nilai yang sudah diisi saat terjadi error validasi:

```php
<?php
// Ambil nilai dari POST, atau kosong jika belum submit
$nama  = $_POST["nama"]  ?? "";
$email = $_POST["email"] ?? "";
$kota  = $_POST["kota"]  ?? "";
$errors = [];

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Validasi
    if (trim($nama) === "") $errors[] = "Nama wajib diisi";
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errors[] = "Email tidak valid";

    if (empty($errors)) {
        echo "<p style='color:green'>Data berhasil disimpan!</p>";
        $nama = $email = $kota = "";  // Reset setelah berhasil
    }
}
?>

<?php if (!empty($errors)): ?>
    <div style="color:red; background:#fee; padding:10px; border-radius:4px;">
        <ul>
            <?php foreach ($errors as $e): ?>
                <li><?= $e ?></li>
            <?php endforeach; ?>
        </ul>
    </div>
<?php endif; ?>

<form method="POST">
    <label>Nama:</label>
    <!-- Nilai sebelumnya tetap ada -->
    <input type="text" name="nama" value="<?= htmlspecialchars($nama, ENT_QUOTES) ?>">

    <label>Email:</label>
    <input type="email" name="email" value="<?= htmlspecialchars($email, ENT_QUOTES) ?>">

    <label>Kota:</label>
    <select name="kota">
        <option value="">-- Pilih --</option>
        <option value="jkt" <?= $kota === 'jkt' ? 'selected' : '' ?>>Jakarta</option>
        <option value="bdg" <?= $kota === 'bdg' ? 'selected' : '' ?>>Bandung</option>
        <option value="sby" <?= $kota === 'sby' ? 'selected' : '' ?>>Surabaya</option>
    </select>

    <button type="submit">Kirim</button>
</form>
```

## 11. Upload File

### 11.1 Form Upload
```html
<form method="POST" enctype="multipart/form-data">
    <input type="file" name="foto" accept="image/*">
    <button type="submit">Upload</button>
</form>
```
> [!IMPORTANT]
**Wajib**: `enctype="multipart/form-data"` harus ada di tag `<form>` untuk upload file.

### 11.2 Memproses Upload
```php
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $file = $_FILES["foto"] ?? null;

    if ($file === null || $file["error"] !== UPLOAD_ERR_OK) {
        $pesan = "Tidak ada file atau terjadi error";
    } else {
        // Informasi file
        $namaAsli  = $file["name"];       // foto_saya.jpg
        $tipe      = $file["type"];       // image/jpeg
        $tmpName   = $file["tmp_name"];   // /tmp/phpXXXXXX
        $ukuran    = $file["size"];       // 245678 (dalam byte)
        $errorCode = $file["error"];      // 0 = sukses

        // Validasi tipe
        $tipeAllowed = ["image/jpeg", "image/png", "image/gif"];
        if (!in_array($tipe, $tipeAllowed, true)) {
            $pesan = "Tipe file tidak diizinkan. Hanya JPG, PNG, GIF.";
        }
        // Validasi ukuran (maks 2MB)
        elseif ($ukuran > 2 * 1024 * 1024) {
            $pesan = "Ukuran file maksimal 2MB";
        }
        else {
            // Buat nama unik untuk mencegah override
            $ekstensi = pathinfo($namaAsli, PATHINFO_EXTENSION);
            $namaBaru = uniqid("foto_") . "." . $ekstensi;
            // Contoh: foto_65a1b2c3d4e5.jpg

            $tujuan = __DIR__ . "/uploads/" . $namaBaru;

            if (move_uploaded_file($tmpName, $tujuan)) {
                $pesan = "File berhasil diupload: $namaBaru";
            } else {
                $pesan = "Gagal memindahkan file";
            }
        }
    }

    echo $pesan;
}
```

### 11.3 Kode Error Upload
| Kode | Konstanta | Keterangan |
| :---: | :--- | :--- |
| `0` | `UPLOAD_ERR_OK` | Berhasil |
| `1` | `UPLOAD_ERR_INI_SIZE` | Melebihi `upload_max_filesize` di `php.ini` |
| `2` | `UPLOAD_ERR_FORM_SIZE` | Melebihi `MAX_FILE_SIZE` di form |
| `3` | `UPLOAD_ERR_PARTIAL` | Hanya terupload sebagian |
| `4` | `UPLOAD_ERR_NO_FILE` | Tidak ada file dikirim |
| `6` | `UPLOAD_ERR_NO_TMP_DIR` | Folder tmp tidak ada |
| `7` | `UPLOAD_ERR_CANT_WRITE` | Gagal menulis ke disk |

### 11.4 Multiple Upload
```html
<input type="file" name="files[]" multiple accept="image/*">
```
```php
<?php
$files = $_FILES["files"] ?? null;

if ($files !== null) {
    $jumlah = count($files["name"]);

    for ($i = 0; $i < $jumlah; $i++) {
        if ($files["error"][$i] === UPLOAD_ERR_OK) {
            $tmpName = $files["tmp_name"][$i];
            $namaAsli = $files["name"][$i];
            $ekstensi = pathinfo($namaAsli, PATHINFO_EXTENSION);
            $namaBaru = uniqid("file_") . "." . $ekstensi;
            move_uploaded_file($tmpName, __DIR__ . "/uploads/" . $namaBaru);
            echo "Uploaded: $namaBaru<br>";
        }
    }
}
```

## 12. Keamanan Form

### 12.1 Selalu Validasi di Server
Validasi HTML5 (`required`, `type="email"`, dll.) **bukan pengganti validasi server.**
```php
<?php
// HTML5 validation bisa di-bypass:
// - User edit HTML di browser
// - Kirim request via Postman/curl
// - Nonaktifkan JavaScript

// Jadi, VALIDASI SERVER WAJIB:
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nama = trim($_POST["nama"] ?? "");
    if ($nama === "") {
        die("Nama wajib diisi");  // Atau handle dengan error message
    }
```

### 12.3 Jangan Percaya type dari `$_FILES`
Tipe **MIME** dari file upload bisa dipalsukan. Validasi dengan `finfo`:
```php
<?php
function getMimeType(string $filePath): string {
    $finfo = finfo_open(FILEINFO_MIME_TYPE);
    $mime = finfo_file($finfo, $filePath);
    finfo_close($finfo);
    return $mime;
}

$tmpName = $_FILES["foto"]["tmp_name"];
$mime = getMimeType($tmpName);  // Cek file sebenarnya, bukan dari $_FILES["type"]
```
